## 1. 做了什么

- **M2a 打一句 → 今天**：倾倒栏打一句，原话马上出现，一两秒后凝结出记录（收据）；本机数据库（原话、记录、改动包、改动历史）；理解服务（排队、断网等着、自动重试、失败能再试）；AI 网关第一版跑在这台 Mac 上（意图识别和整理同时开始，网页版的 Skill 原样）
- **M2b 能改、能撤销、能追溯**：「刚才那个是 32 不是 28」改那一条；5 秒内撤销；点任何一条看原话（对应的那一段荧光标出）和改动历史；追问「…吗？」给「对 / 不对」；左右滑换日子；日子头下一句话总结；真机用配对码连网关
- **M2c 和网页版一样准**：网页版的程序把关一条条搬过来（日期、类别和生活领域、心情、不该记的、去重、钱、回复），每条带测试；网页版的 340 条评测照搬

## 2. 评测：和网页版用同一把尺子

`cd gateway && npm run eval`（340 条，每条一部「假手机」，背景包和写回都照手机的规矩）：

| | 结果 |
|---|---|
| 能全算的句子全对 | **228 / 230（99.1%）** |
| 检查项总体 | **99.73%**（1126 / 1129；网页版同一套 99.93%） |
| 意图 / 类别 / 时间 / 数值 | 100% / 99.5% / 100% / 99.7% |
| 还没搬的能力（不算对也不算错） | 目标、个人词典、问答、提醒时刻和没说时间的提醒（M4）、学说法、钱的去向、值不值、人情 |

剩下错的两条是 AI 自己的偶发：「接待了二十多个客户 签了两单」多记了一条签单；「买了菜 花了四十多」没写钱（网页版同一份 Skill 也会这样，见网页版 CHANGELOG）。

这一晚的进步：93.2% → 94.9%（去重、背景带前后一天）→ 96.6%（钱的整理、心情的那一刻、「对」删问过的）→ 99.1%（回复的整理、要做的事的日子）。

## 3. 速度和花费

同一次评测，每句从发出到改动包回来（意图识别和整理同时跑）：

| 中位数 | 九成以内 | 最慢 |
|---|---|---|
| 0.95 秒 | 1.3 秒 | 2.2 秒 |

每句输入约 1.26 万 token，命中缓存 97%；约 **¥0.0013 一句**。

## 4. 真的 AI 走一遍（截图在 `M2-截图/`）

`TEST_RUNNER_POUR_REAL_AI=1 xcodebuild test … -only-testing:PourUITests/RealAIUITests`，从空数据库开始说 7 句：

1. 「早上七点跑了五公里，有点累」→ 跑步 5 公里、心情一般 · 有点累
2. 「中午和小王吃了碗牛肉面 28」→ 吃牛肉面 · 小王 ¥28
3. 同一句又发一遍 →「这句话刚才已经说过了，记录都在，没有重复记。」不记两遍
4. 「刚才那个是 32 不是 28」→ 修改 吃牛肉面 ¥32
5. 「昨晚十一点半睡的，今早七点起」→ 睡眠 7 小时 30 分
6. 「下午陪闺女在楼下骑滑板车，看她骑得那么稳，我也挺高兴」→ 陪闺女骑滑板车、心情挺好 · 开心
7. 「明天下午三点开会，记得带电脑」→ 待办 开会，带电脑 · 明天前

## 6. 没做的、已知问题

- **程序写的回复也带着「AI」小标**（例如「这句话刚才已经说过了」）：改动包还分不出回复是谁写的，下一步在契约里加上
- 「开会」这种有钟点的待办，提醒要到 M4（提醒规划器、本地通知）
- 问答、目标、个人词典、钱的去向和值不值、人情往来在后面的模块
- 真机还没装：等你把 iPhone 15 连上这台 Mac（见第 7 节）

## 7. 产品主人怎么看

模拟器「Pour 开发（iPhone 15 · iOS 27）」里的 Pour 已经是最新的，网关在这台 Mac 上开着：

1. 在底下的倾倒栏打 5 句不同的话，看卡片怎么凝结出来
2. 点任何一条，看原话里对应的那一段和改动历史
3. 说「刚才那个是 …不是 …」改一条；5 秒内点「撤销」
4. 左右滑看昨天
5. 同一句话再发一遍，看它不记两遍
