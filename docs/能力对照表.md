# 能力对照表：网页版的每一项，在 iOS 上怎么样

> 红线（[00 提示词](00-提示词.md) 第 4 节）：网页版已上线的每一项能力，iOS 都有对应；有理由的合并或改进可以，**悄悄少做不行**。
> **怎么用**：每个模块开工时，小方案从这里认领自己的条目，并把条目展开到需求文档（网页版仓库的 `docs/prd-*.md`，已冻结）的细项；验收时逐条打勾。「改」「去」的每一条都写了理由，**要产品主人确认**（标「待确认」的）。
> M0 生成（2026-10-17），对照网页版 v1.17.0：SPEC 第四到十三章 + 14 份需求文档。总览见 [01 总体方案](01-总体方案.md) 第 5 节。

**标记**：同 = 规则原样继承、和网页版对拍；升 = 在手机上做得更好；改 = 换了做法；去 = 不再需要。
