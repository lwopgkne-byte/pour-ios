# 02 字体与排版

> 原则：**用字的不同说话的不同**。结构和数字用精确的无衬线；你说的原话用有温度的衬线；大数字用圆润的数字字体。全部跟随系统的动态字体。

## 1. 三种声音

| 声音 | 字体（中文 / 西文和数字） | 用在 | 不用在 |
|---|---|---|---|
| **结构之声** | 苹方 / SF Pro | 所有界面文字：标题、正文、按钮、标签、列表、说明 | — |
| **原话之声** | 宋体 / New York | 你说的原话（收据、记录详情、引用块、搜索结果）、每周新发现的那一句、「你的一年」每屏的大标题 | 按钮、列表标题、任何操作 |
| **数字之声** | SF Pro Rounded（数字） | 统计页的主数字（「¥784」「62 天」「8 次」） | 正文里的数字（用结构之声的等宽数字） |

**规矩**
- 原话之声一屏最多两处；中文衬线 ≥ 17 点（宋体小了发虚）
- 只用系统自带字体：渲染最好、不增加安装包、自动支持动态字体
- 西文用 SF Pro 的自动字距；中文不调字距
- 数字之声在 M1 样张里和 SF Pro 对比后定（备选：主数字也用 SF Pro 半粗）
- **待 M1 定（M0 实测，2026-10-17）**：iPhone **没有预装宋体**（iOS 26.5 只预装了苹方等，宋体要下载），「只用系统自带字体」和「原话用宋体」两条在 iPhone 上不能同时成立。M1 出样张时给产品主人选：① 按需下载系统的宋体（第一次要联网，下载前先用苹方）② App 里内置开源的思源宋体（安装包变大）③ 原话之声换方向。App 的测试 `songtiIsAvailableOnDevice` 把它记成已知问题，解决后会提醒

## 2. 字号阶梯

基准是系统「默认」字号（大）。全部绑定系统文字样式，随动态字体缩放。

| 令牌 | 声音 | 系统样式 | 默认：字号 / 行高 / 字重 | 最大缩放（AX5） | 用在 |
|---|---|---|---|---|---|
| `displayXL` | 数字 | 随 largeTitle | 56 / 60 / 半粗 | 封顶 72 | 「你的一年」的大数字 |
| `display` | 数字 | 随 largeTitle | 44 / 48 / 半粗 | 封顶 60 | 统计页、角度卡的主数字 |
| `titlePage` | 结构 | largeTitle | 34 / 41 / 粗 | 系统 | 标签页的大标题（今天、回顾、关于我、钱） |
| `title1` | 结构 | title1 | 28 / 34 / 粗 | 系统 | 详情页的标题（「一样东西」那一页） |
| `titleSection` | 结构 | title3 | 20 / 25 / 半粗 | 系统 | 页内分节标题 |
| `quoteLead` | 原话 | 随 title3 | 20 / 30 / 常规 | 系统 | 新发现那一句、你的一年每屏的标题 |
| `headline` | 结构 | headline | 17 / 22 / 半粗 | 系统 | 卡片标题、列表主标题、按钮文字 |
| `body` | 结构 | body | 17 / 22 / 常规 | 系统 | 正文 |
| `bodySerif` | 原话 | 随 body | 17 / 27 / 常规 | 系统 | 原话（行高 1.6 倍，读起来不挤） |
| `callout` | 结构 | callout | 16 / 21 / 常规 | 系统 | 卡片里的说明、轻提示 |
| `meta` | 结构 | subheadline | 15 / 20 / 常规 | 系统 | 次要信息、列表的副标题 |
| `caption` | 结构 | footnote | 13 / 18 / 常规 | 系统 | 日期、时间、来源、图注 |
| `micro` | 结构 | caption2 | 11 / 13 / 常规 | 系统 | **只用于图表的坐标和刻度** |

**字重只用四种**：常规（400）、中（500，只用于胶囊标签）、半粗（600：标题、按钮、句中的强调）、粗（700：只用于页标题）。不用细体（中文细体在手机上看不清）。

## 3. 中文排版

| 规矩 | 怎么做 |
|---|---|
| 中西文间距 | **程序拼的句子**（总结、回顾、收据、发现）在中文和数字、西文之间加空格：「跑了 5 公里」「¥28」「iPhone 13」。由 `PourCore` 的排版函数统一做。**你的原话不动**（原样显示你怎么说的） |
| 标点 | 全角中文标点；引用用直角引号「」；数字范围用「–」（「3–5 次」）；省略号用「……」 |
| 行长 | 正文一行不超过 32 个汉字（大屏也一样，靠边距控制）；原话不超过 28 个 |
| 段落 | 段间距 = 0.6 倍行高；不首行缩进 |
| 截断 | 列表标题一行、末尾省略；列表里的原话预览最多两行；**详情页的原话永远完整显示** |
| 换行 | 不在数字和单位之间断行（用不断行空格）；不在「¥」和数字之间断行 |
| 混排对齐 | 同一行里有不同字号时按基线对齐 |

## 4. 数字、单位、金额

| 规矩 | 例子 |
|---|---|
| 表格、卡片、统计里的数字一律**等宽**（tabular），上下对齐 | `¥  28.00` / `¥ 128.50` |
| 数字和中文单位之间空一格；百分号、货币符号不空 | 「5 公里」「32 分钟」「34%」「¥28」 |
| 金额：整数不带小数；有零钱带两位；一万以上加千分位 | 「¥28」「¥28.50」「¥12,800」 |
| 时长：分钟、小时说人话 | 「45 分钟」「1 小时 20 分」「14 小时 21 分」 |
| 大数：一万以上可以用「万」 | 「1.2 万段」 |
| 小于 1% 的写「不到 1%」，不写「0%」 | 「醒着的时间里不到 1%」 |
| 心情不写分数，写说法 | 「挺好」「在一般和挺好之间」，不写「3.4」 |

日期和时间的写法见 10 文案与格式。

## 5. 文字颜色怎么配

| 文字 | 颜色 |
|---|---|
| 标题、正文、原话 | `ink` |
| 次要信息（日期、单位、说明、副标题） | `inkSecondary` |
| 占位、装饰 | `inkTertiary` |
| 认出的人和地方、「Pour 认识的」 | `qing` |
| 「落后」「等你回答」 | `attention` |
| 链接 | `action`（墨色 + 下划线，只在段落里；列表里的链接不加下划线，靠右侧箭头） |

**一行里最多两种文字颜色。**
