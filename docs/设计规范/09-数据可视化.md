# 09 数据可视化

> 原则：**一句结论在上，图是证据**。结论由程序写；图克制、精致、能点；点进去永远能回到那几天、那几句原话。

## 1. 通用规矩

| 方面 | 规矩 |
|---|---|
| 结论 | 每张图上方一句程序写的结论（「这 9 周你说得最多的是工作和饮食」）；没结论的图不放 |
| 颜色 | 最多两种颜色加灰：`chartPrimary`（你，青）、`chartSecondary`（对比，灰）；按领域分的图用领域色；不加别的彩色 |
| 标注 | **直接标在图上**，不用图例；数字等宽、`micro` 或 `caption` |
| 坐标 | 能不画就不画；要读数的图只画必要的刻度，放在右侧或下方 |
| 网格线 | 默认不画；要画用 `chartGrid`（墨 6%） |
| 空值和零 | 没记的不画（断开）；记了是 0 的画在底线上——两者不能混 |
| 数据不够 | 不画假的；显示「还在攒」和还差多少（「再记 9 天」） |
| 交互 | 点一个点 / 一根柱：上方出现数值（`surfaceRaised` 小标签）；拖动经过数据点有选择触感；「点进那几天」进列表，再点回原话 |
| 动效 | 07 第 2 节（长出来、画出来；减少动态效果时直接出现） |
| 无障碍 | 每张图提供图表描述（系统 `AXChartDescriptor`）：标题、坐标含义、数据序列；支持系统的「音频图表」；旁白先读结论 |
| 工具 | Swift Charts；时钟、星图、方块图、心情像素、年度格子用 `Canvas` 自绘 |

## 2. 每种图

### 2.1 方块图（你的生活由什么组成）
- 每块一个生活领域，**面积 = 说到它的段数**（图上方小字写明，不是花的时间）
- 块：领域浅底 + 领域文字色写名字和百分比；圆角 `radius.md`；块间 4
- 前两块占第一行（大），其余第二行；最小块宽 64，放不下的并进最下面一条「还在攒的：宠物 · 健康」
- 点一块进那个领域的页面

### 2.2 时间去向
- 一根横条（高 12、胶囊），按领域分段、领域实色；下面每个领域一行：色点、名字、时长（等宽）、百分比
- 小字写明「只算说了时长的事」

### 2.3 迷你曲线（「你没注意到的变化」、统计卡）
- 线 2 点、`chartPrimary`；不画坐标；**两头标起点和终点的数**（和曲线一致，曲线画的是三周平均）
- 高 40；宽占满

### 2.4 一周七天
- 七根柱，宽是间距的 1.5 倍、顶部圆角 4；下方「一 二 三 四 五 六 日」
- 要说「哪天最低 / 最高」时，那一根用 `chartSelected`（墨）并在上方写字；**不用警示色**

### 2.5 对比横条（发现卡）
- 两根：「这些日子」`chartPrimary`、「别的日子」`chartSecondary`；高 8、胶囊；左边名字、右边百分比（等宽）

### 2.6 配方圆点（好日子的配方）
- 每样东西一排 10 个圆点（直径 10、间距 6）：亮的个数 = 10 天里有几天有它；好日子一组、差日子一组

### 2.7 心情像素墙
- 每天一格 14 点、间距 3、圆角 3；一列一周
- 月份只在月初那一列上方写「8月」「9月」
- 有心情填五档色、没记画虚线空格（01 第 3.2 节）；点一格到那天的回顾

### 2.8 一年每天一格（手机重新设计，不照搬网页的横长条）
- 网页版是 53 列 × 7 行的长条，手机上要横着滚。手机版改成 **12 个月的小日历，3 列 × 4 行**，一屏看完一年
- 每个小日历 7 列，格子 11 点、间距 2；月名 `caption` 在上方
- 着色按选择的指标（记录量用墨的深浅、心情用心情五档、某个领域用那个领域色的深浅）
- 点一个月放大成那个月的日历

### 2.9 说话的时钟
- 24 根放射状的柱，0 点在正上方；画布 400 × 400 按屏幕缩放，字号按缩放系数换算（网页版踩过「字特别大」的坑）
- 内圈半径 96；柱长按该钟点说的段数；说得最多的那一段用 `chartPrimary`，其余 `chartSecondary`
- 只标 0、6、12、18 点；圆心写总段数和「最常在 21 点」

### 2.10 人际星图
- 你在圆心；三个扇区：家人、工作、朋友和其他
- 离圆心越近 = 说到越多；点的大小 = 有几天说到；每个点都写名字
- 点一个人进他的详情

### 2.11 趋势折线（领域页「这些数的变化」、心情和精力）
- 主线 2 点 `chartPrimary`；移动平均虚线 `chartSecondary`；目标是一条 `ink` 30% 的虚横线并在右端写「目标 7.5 小时」
- 横轴只标头尾和中间一个；纵轴在右侧、最多 3 个刻度
- 日 / 周 / 月 / 年用分段控件切换

### 2.12 钱的月历
- 7 列日历；每天一格写当天花了多少（`caption` 等宽）；格子底色用墨的深浅表示多少（6%–14%，不用彩色——钱不是生活领域；原写 20%，M1 实测亮色 20% 的底上日期只有 4.40:1，封顶 14%）
- 今天墨色细圈；点一天进「一天的钱」
- 金额遮住时全部换成「•••」

### 2.13 目标进度
- 见 08 组件「进度条」：领域色填充，落后用 `attention` 文字说，不变色
