# 12 交互模式与页面

> 前 11 份规定「东西长什么样」，这一份规定「东西怎么用、页面怎么组织」。

## 1. 交互模式

| 模式 | 怎么做 |
|---|---|
| **倾倒** | 倾倒栏常驻在标签栏上方；点一下打字，**按住说话**、松开发送；也能从别的 App 分享进来、从锁屏小组件、Siri、快捷指令进来——全部走同一条流程 |
| **发送之后** | 100 毫秒内原话出现在时间轴、标「整理中」；整理完凝结成卡片 + 成功触感；没网标「等网络」，联网自动整理（07 第 3 节） |
| **收据** | 一行一件事；撤销条 5 秒；追问一次一个，点选项或直接再说一句 |
| **纠正** | 两条路都行：点卡片改；或者直接说「刚才那个是 38 不是 28」 |
| **原话追溯** | 任何卡片、数字、发现，点开都能看到它来自哪句原话，对应的那一段荧光高亮 |
| **撤销而不是确认** | 删除、改动都给撤销；只有不可恢复的（删除账号）才二次确认，并说清后果 |
| **空状态** | 告诉你「说一句什么就会出现在这」，给一个能照着说的例子 |
| **加载** | 本机数据直接显示，不出加载；等网络的用内容形状的微光占位；超过 2 秒说明在等什么 |
| **出错** | 平实说明 + 你能做什么 + 「再试一次」 |
| **离线** | 不弹横幅；需要网络的地方就地说明「联网后整理」 |
| **权限** | 用到时才问：第一次按话筒才问麦克风；第一次看完回顾才问通知；先用一句话说为什么 |
| **手势** | 左右滑换日子；左滑删记录（有撤销）；长按出菜单；下拉面板关闭——**每个手势都有看得见的替代** |

## 2. 信息架构

```
标签栏（Liquid Glass，4 个 + 搜索）
├─ 今天     时间轴 · 一句话总结 · 目标进度（点进目标页）· 右上角头像（设置）
├─ 回顾     今天的回顾 · 往前翻 · 周报 · 月报
├─ 关于我   方块图 · 时间去向 · 新发现 · 换个角度 · 配方 · 变化 · 说的和做的 · Pour 认识的 · 你的一年
│           └ 领域页 · 心情 · 人 · 你说的话
├─ 钱       本月 · 月历 · 留意的 · 值不值 · 人情往来
└─ 搜索     搜原话（关键词 + 按意思）· 全部原话 · 好时刻 · 感悟 · 问 Pour

倾倒栏：常驻在标签栏上方，所有标签页都在
设置（从「今天」右上角头像进）：账号 · 通知 · 隐私中心 · 数据导出 · Face ID · 越来越懂你 · 关于（含 AI 服务公示）
```

- 顶层 4 个内容标签 + 搜索（Hick 定律：≤ 5）
- 目标不单独占标签：进度在「今天」顶部（每天看），详情在目标页
- 问答两个入口：倾倒栏里直接问（AI 识别出是问题）；搜索里点「问 Pour」

## 3. 关键页面

每个页面先写它回答的问题（宪法第一条）。

### 今天 —— 「我今天过得怎么样」

```
┌────────────────────────────────┐
│ 今天                      (头像)│  titlePage；左右滑换日子
│ 10月17日 周五 · 早起跑了 5 公里，│  meta + 一句话总结（AI 标识）
│ 午饭 28，晚上和儿子拼了拼图 [AI] │
│ ▬▬▬▬▬▬▭▭ 今年跑 500 公里 · 101  │  目标进度（最多 3 条，领域色）
│                                │
│ 07:10 ● 跑步 5 公里 · 32 分     │  时间轴：时间 · 领域色点 · 一行
│ 12:30 ● 午饭 · 和小王    ¥28    │  认出的「小王」是青色
│ 15:00 ◐ 心情 不太好             │
│ 20:00 ● 陪儿子拼拼图            │
│       「七点半到八点半…」        │  原话（原话之声），点开看全部
├────────────────────────────────┤
│ ⌒ 今天做了什么？         🎙    │  倾倒栏（玻璃）
│ 今天   回顾   关于我   钱   🔍  │  标签栏（玻璃）
└────────────────────────────────┘
```

### 收据（发出一段话后，就地出现在时间轴上）
原话（原话之声）→ 记录行逐张凝结 → 追问条（如果有）→ 撤销条在底部 5 秒。

### 回顾 —— 「昨天 / 这周过得怎么样」
上面一句值得说的（AI 写、程序核对、带标识）→ 程序算的几个数（等宽大数字）→ 「比平时」的对比（工作日和周末分开比）→ 往前翻。

### 关于我 —— 「我是个什么样的人」
方块图 → 时间去向 → 这周的新发现（青色浅底的卡）→ 换个角度（心情、人、钱、你说的话四张小卡）→ 好日子的配方 → 你没注意到的变化 → 说的和做的 → Pour 认识的 → 「你的 2026」。

### 钱 —— 「我的钱去哪了」
本月一个大数字 → 钱的月历 → 花在哪（按领域）→ 留意的 → 值不值 → 人情往来。金额随时可以遮住。

### 搜索 —— 「我说过……」
搜索框常驻 → 实时结果（关键词 + 按意思，命中的字荧光）→ 下面是浏览：全部原话（按日子）、好时刻、感悟 → 「问 Pour」。

### 你的一年 —— 「我这一年」
像一本年度小册子：每一屏一件事（记了多少天、一年每天一格、说得最多的、和谁在一起最多、心情最好的那个月、第一句和最近一句）；每屏的大标题用原话之声。

### 第一次打开
三步：① 一屏演示「倾倒 → 凝结」；② 「说第一句话吧」（真的整理，马上看到收据）；③ 或者「看看示例」（逛一个人的 9 周，随时退出，不混进你的数据）。权限用到时再问。

### 设置
系统分组列表；第一组是「越来越懂你」的数字（每 100 段话要你改几次、追问几次）；隐私中心用大白话列出什么存在哪、发给了谁。
