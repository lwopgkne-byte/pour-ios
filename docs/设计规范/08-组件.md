# 08 组件

> 每个组件写清：**用途 · 样子 · 状态 · 行为 · 无障碍**。数值全部引用令牌（01–07）。
> 组件按原子设计分层：原子（按钮、标签、头像……）→ 分子（倾倒栏、收据行、记录卡……）→ 组织（收据、时间轴、方块图……，组织级的图表见 09）。
> 每个组件在设计画廊里展示全部状态：默认、按下、加载、空、出错、离线、禁用 × 亮暗 × 默认字号和 AX5。

## 原子

### 按钮

| 种类 | 用途 | 样子 |
|---|---|---|
| **主要** | 一个页面最多一个：发送、「说第一句话」、保存 | `action` 底（墨）、`onAction` 字、`headline`；胶囊；高 50（大）/ 44（常规）；左右内边距 20 |
| **次要** | 主要旁边的另一个选择、追问的选项 | `actionSoft` 底、`ink` 字、`headline`；胶囊；高 44 |
| **文字** | 低调的操作：「看全部」「再试一次」「撤销」 | 无底、`ink` 字半粗；可点范围补到 44 |
| **危险** | 不可恢复的操作（删除所有数据） | `critical` 字（系统红）；只出现在面板和菜单里，前面有说明 |
| **图标** | 工具栏、卡片角上的操作 | 符号 `icon.large`、`ink`；可点 44 × 44；必须有旁白名字 |
| **玻璃** | 浮在内容上的操作（返回顶部、浮动发送） | 系统玻璃按钮；主要的用「突出」玻璃，着色 `action` |

| 状态 | 样子 |
|---|---|
| 按下 | 底色换 `actionPressed` / 加深；缩到 0.97 |
| 禁用 | 底 `fillPressed`、字 `inkSecondary`（M1 改：原为 `inkDisabled`，读不清是什么按钮；淡墨约 6.9:1，和能点的墨底白字一眼分开）；**说明为什么不能点**（旁边一行小字或旁白） |
| 加载 | 文字换成系统转圈，宽度不变；不能再点 |

不要：两个主要按钮并排；按钮里放长句子；用图标按钮做危险操作。

### 胶囊标签

| 种类 | 样子 | 行为 |
|---|---|---|
| **信息** | 领域色点（8）+ 名字，`meta`，`surfaceSunken` 底，胶囊，高 28 | 不能点 |
| **筛选** | 名字，`meta` 中，未选：`actionSoft` 底 `ink` 字；选中：`action` 底 `onAction` 字；高 32（可点 44） | 点一下切换；一行放不下横向滚动 |
| **AI** | 「AI」，`caption`、`inkTertiary`、`line` 描边，高 18 | 不能点（标识用） |

### 头像

见 04 第 3 节。

### 色点、心情格

- 领域色点：直径 8（时间轴上 10），领域实色
- 心情格：圆角 3；有心情 → 心情五档填色；没记 → `lineStrong` 虚线空格；点一格出字（日子 + 说法）

### 进度条

- 高 6，胶囊；底轨 `fillSelected`；填充用**目标所在领域的实色**（数据）
- 落后时进度条不变色，右侧文字「落后 34%」用 `attention`
- 完成：填满，右侧「完成」+ 对勾符号；不放礼花

## 分子

### 倾倒栏（全 App 最重要的组件）

**用途**：唯一的记录入口。常驻在标签栏上方，所有标签页都在。

**样子**
- Liquid Glass 胶囊（单行）/ 圆角 20（多行）；收起高 52；左右离屏幕边缘 12
- 左：输入区，`body`、`ink`；占位文字轮换示例（「今天做了什么？比如：8 点跑了 5 公里」），`inkSecondary`
- 右：没字时是话筒（`mic`，`icon.large`，`inkSecondary`）；有字时变成发送键（墨色圆底 32、白色 `arrow.up`），两者玻璃融合变形

| 状态 | 样子和行为 |
|---|---|
| 空闲 | 一行，占位示例 |
| 聚焦 | 键盘弹起，栏贴在键盘上方 8；占位示例保留到输入第一个字 |
| 输入中 | 随内容长高，最多 6 行，之后内部滚动；中文拼音候选时不跳高度 |
| 录音（按住话筒） | 栏变宽成录音条：实时声波（`ink`）+ 计时 + 「松开发送 · 上滑取消」；开始时中冲击触感；上滑超过 60 点变「松开取消」+ 警告触感 |
| 发送中 | 发送键变转圈 0.2 秒内完成（本机保存很快），然后清空 |
| 离线 | 不在栏上显示（离线不影响记录）；原话在时间轴上标「等网络」 |
| 滚动内容时 | 收起成一个话筒玻璃按钮（系统标签栏附件的收起行为），点一下展开 |

**行为**
- 回车键是换行；发送只靠发送键（防止输入法确认时误发）
- 按住话筒说话；点一下话筒也能开始（再点停止），给不方便按住的人
- 也接收：分享扩展、小组件、Siri 和快捷指令送进来的文字（同一条流程）

**无障碍**：旁白名字「说点什么」；话筒「按住说话，或轻点两下开始录音」；发送「发送」；录音中实时播报「正在录音，3 秒」。

### 收据

**用途**：一段话整理完，就地显示它被整理成了什么。出现在「今天」时间轴上这段原话的位置。

**结构**（从上到下）
1. 原话行：时间（`caption`、`inkSecondary`）+ 原话（`bodySerif`、`ink`）
2. 记录行若干：领域色点 + 一件事（`body`）+ 右侧数字（`body` 等宽、`inkSecondary`）；认出的人和地方用 `qing`
3. 追问条（有追问时）

| 状态 | 样子 |
|---|---|
| 整理中 | 原话下两行微光占位 + 「整理中」小字（时间变化见 07 第 3 节） |
| 等网络 | 原话下一行「等网络，联网后自动整理」，`inkSecondary` + `wifi.slash` 小图标 |
| 整理好 | 记录行逐张凝结（07 第 3 节） |
| 待确认 | 那一行虚线描边 + 「待确认」 |
| 没整理成 | 「没整理成 · 再试一次」（文字按钮） |
| 只是提问 | 不出记录行，直接接问答的回答 |

**追问条**：`surfaceSunken` 底、圆角 12、左侧 3 点 `attention` 细条；问题一行（`callout`）+ 选项（次要按钮，最多 3 个）；也可以直接在倾倒栏里回答。一次只问一个。

### 撤销条、轻提示

- Liquid Glass 胶囊，高 44，倾倒栏上方 12；`callout` 文字 + 右侧文字按钮
- 撤销条：「已记下 3 件事 · 撤销」，5 秒后自己消失；往下滑可以提前关
- 同一时间只有一条；新的来了替换旧的
- 旁白自动播报内容

### 记录卡

**用途**：一条记录在列表、详情里的样子。底 `surface`、圆角 20、内边距 16。

| 种类 | 主行 | 副行 |
|---|---|---|
| 事件 | 领域色点 + 名字（`headline`）+ 右侧时长或数量（等宽） | 时间段 · 和谁（认出的人用 `qing`）· 地方 |
| 钱 | 名字 + 右侧金额（`headline` 等宽）；报销、借出加一个信息标签 | 时间 · 给谁 · 值不值的原话（原话之声，一行） |
| 心情 | 心情格（14）+ 说法（「挺好」）| 说出的感受 · 那一刻（原话之声） |
| 感悟 | `lightbulb` + 标题（`headline`） | 原话（原话之声，最多 3 行） |
| 待办 | 圆圈 / 对勾 + 内容 | 到期日；完成的划线、`inkSecondary` |

**状态**：按下（`fillPressed`）、待确认（虚线）、刚凝结 / 刚改过（高亮 1.2 秒）、已删除（不显示；撤销期间显示删除线）

**行为**：点一下进详情（原话、改、删、版本历史）；长按出菜单（改、删、看原话、复制）；左滑删除（有撤销）

**无障碍**：整张卡读成一句「跑步，5 公里，32 分钟，早上 7 点 10 分」；改、删、看原话做成旁白的自定义操作。

### 原话块

- 原话之声 `bodySerif`、`ink`；左侧 2 点 `line` 竖线；上方一行来源（「10 月 3 日 周五 21:40 · 语音」，`caption`）
- 对应这条记录的那一段：`marker` 底（03 第 2 节）
- 详情里永远完整；列表里最多两行
- 点一下复制；长按出菜单（复制、在笔记里看全部）

### 发现卡

- 底 `qingSoft`、圆角 20、内边距 16
- 那一句（`quoteLead` 原话之声）→ 两根对比横条（「这些日子 / 别的日子」，主系列 `chartPrimary`、对比 `chartSecondary`，右侧百分比等宽）→ 根据（`caption`：「9 周里 12 天 · 前后两段都是这样」）→ 反馈一排（「说中了 · 早知道 · 没意思 · 不对」文字按钮，高 44，选中的加粗）
- 点卡片（不是按钮）进那几天
- 旁白：读那一句 + 数字；四个反馈是自定义操作

### 统计卡（「换个角度」的小卡）

- 两列；底 `surface`、圆角 20、内边距 16
- 标题（`meta`、`inkSecondary`）→ 主数字（`display`）→ 一句结论（`callout`）→ 迷你图（高 40）
- 整张卡可点

### 列表行

- 高 52 / 64；左：图标或色点（宽 28 的位置）；中：标题 `body` + 副标题 `meta`；右：数值（等宽）或系统箭头
- 分割线从文字起点开始
- 按下 `fillPressed`；选中 `fillSelected`

### 分节标题

- `titleSection`、`ink`；上方 32、下方 12
- 右侧可选一个文字按钮（「全部」）；不放图标

### 分段控件

- 用系统分段控件（`surfaceSunken` 底）；选项最多 4 个、每个最多 4 个字
- 用于切换同一份数据的看法（日 / 周 / 月 / 年；7 天 / 30 天 / 90 天）

### 搜索框

- 用系统搜索框（在搜索标签里常驻）；占位「搜你说过的话」
- 输入时实时出结果（≤ 100 毫秒）；命中的字荧光

### 空状态

- 位置：内容区上三分之一（不在整屏正中）
- 符号（`icon.display`、`inkTertiary`）→ 一句话（`headline`）→ **一个说法的例子**（原话之声：「比如说『中午吃了碗牛肉面 28』」）→ 可选的文字按钮
- 「还在攒」的空状态写清还差多少：「再记 9 天，能看到你的好日子有什么共同点」

### 加载占位（骨架）

- 和真实内容同样的形状：`surfaceSunken` 块，圆角 `radius.sm`；微光扫过（07）
- 超过 2 秒说明在等什么；数据在本机的页面不应该出现骨架（直接显示）

### 出错

- 一句话说清发生了什么 + 你能做什么 + 「再试一次」文字按钮
- 不用红色、不用感叹号、不用错误码（错误码只进日志）

## 组织

### 时间轴（「今天」）

- 左：时间列宽 52（`caption` 等宽、`inkSecondary`，右对齐）
- 中：1 点竖线（`line`）+ 领域色点（10）
- 右：记录卡（紧凑样式：没有卡片底，只有文字）或收据
- 同一段话产生的几条记录归在一起，原话在上
- 没有时间的记录（「今天读了 30 页」）放在「今天还做了」一组，在时间轴下面

### 日子头和切换

- 大标题：「今天」「昨天」「10月14日」（`titlePage`）
- 副标题：「周二 · 一句话总结」（`meta`），总结带「AI」标识
- 左右滑动切换日子（有前一天、后一天的预加载）；点标题弹出日历选日子

### 导航栏

- 标签页的根页面：大标题，滚动时收成小标题（系统行为）；内容滚到栏下时系统自动加一层渐隐（iOS 26 起的滚动边缘效果）
- 详情页：小标题；左边系统返回；右边最多两个图标按钮（玻璃）
- 「今天」右上角是头像按钮（进设置）

### 标签栏

- 系统标签栏（iOS 26 浮动玻璃），4 个内容标签 + 搜索
- 选中的颜色是 App 着色 `action`（墨）
- 倾倒栏放在标签栏上方（底部附件位置，M3 实测，见设计方案）
- 不加角标、不加红点

### 面板

- 系统面板，两档高度（一半 / 全屏）；一半时显示拖动条
- 标题 `headline` 居中；右上「完成」文字按钮；左上「取消」（有改动时才显示，并防误关）
- 面板里的内容在 `surface` 上

### 菜单

- 系统长按菜单 / 下拉菜单；最多 7 项；危险的放最后、系统红、前面加分隔
- 每项有图标（SF Symbols）

### 设置行

- 系统分组列表；左图标（彩底小方块是系统设置的风格，**我们不用**：图标直接用 `ink` 分层渲染）+ 名字 + 右侧当前值（`inkSecondary`）+ 箭头
