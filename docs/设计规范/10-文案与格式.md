# 10 文案与格式

> 原则：**像一个了解你的、安静靠谱的朋友说话**（沿用网页版 `skills/_voice.md`）。说人话、短句、具体；只说事实，不评价、不催、不夸。

## 1. 语气

| 场景 | 语气 | 例子 |
|---|---|---|
| 收据 | 事实，一行一件 | 「跑步 5 公里 · 32 分钟」 |
| 一句话总结 | 平静地概括 | 「早起跑了 5 公里，午饭 28，晚上和儿子拼了拼图」 |
| 回顾、报告的观察 | 引用具体数字，变差了就直说 | 「这周睡得比平时晚 40 分钟，周三最晚」 |
| 新发现 | 只说同时出现，不说因为 | 「和小王在一起的日子，几乎都心情不太好；别的日子一成多」 |
| 通知 | 一句话、可以不看 | 「昨天的回顾好了」 |
| 空状态 | 给一个能照着说的例子 | 「比如说『中午吃了碗牛肉面 28』」 |
| 出错 | 发生了什么 + 你能做什么 | 「没整理成：网络断了。联网后会自动再试」 |
| 隐私说明 | 直白，不绕 | 「整理时，这段话会发给 AI 处理，处理完不保存」 |

**称呼**：用户是「你」；App 和 AI 不自称「我」（回答以内容开头）；不用「亲」「宝」「哦」「呢」。

## 2. 统一叫法（界面上只用左边这个词）

| 用这个 | 不用 | 意思 |
|---|---|---|
| 原话 | 笔记、日记、输入 | 你说的话，原样保存 |
| 记录 | 条目、数据、事件 | 从原话整理出来的一件事 |
| 整理 | 解析、处理、识别 | AI 把原话变成记录 |
| 收据 | 结果、回执 | 一段话整理成了什么 |
| 待确认 | 不确定、低置信 | AI 没把握、等你看一眼 |
| 追问 | 提问、确认框 | AI 问你的一个问题 |
| 今天 / 回顾 / 关于我 / 钱 / 搜索 | 首页、日报、个人中心、账本 | 五个标签 |
| 生活领域 | 分类、类别（界面上） | 运动、饮食…… |
| Pour 认识的 | 用户画像、标签 | 它认识的人、地方、说法 |
| 你的说法 | 词典、别名 | 「老地方 = 公司楼下那家面馆」 |
| 新发现 | 洞察、分析 | 程序找出的规律 |
| 好时刻 | 高光、积极事件 | 让你有感觉的那一刻 |
| 示例 | 演示、Demo | 「看看示例」 |

「倾倒栏」是内部叫法，界面上不出现。

## 3. 日期、时间、数字

| 东西 | 写法 |
|---|---|
| 日子 | 「今天」「昨天」；今年的「10月14日 周二」；往年的「2025年10月14日」 |
| 时刻 | 24 小时制「08:00」「21:40」 |
| 时间段 | 「08:00–09:30」 |
| 相对时间 | 只在通知和「刚才」场景用：「刚才」「2 小时前」；超过一天写日子 |
| 一周、一月 | 「这周」「上周」「10月」；跨年「2025年12月」 |
| 时长 | 「45 分钟」「1 小时 20 分」 |
| 次数、天数 | 「3 次」「12 天」 |
| 金额 | 「¥28」「¥28.50」「¥12,800」（02 第 4 节） |
| 百分比 | 「34%」；不到 1% 写「不到 1%」 |
| 心情 | 说法：「很差 / 不太好 / 一般 / 挺好 / 很好」，平均写「在一般和挺好之间」，不写分数 |
| 倍数 | 「两倍」「三成多」（程序的 `chengWord`、`perWeekWord` 等沿用） |

全部由 `PourCore` 的格式化函数统一产出（和网页版对拍），界面不自己拼。

## 4. 禁用的说法（自动检查）

| 类别 | 不许出现 |
|---|---|
| 责备（沿用 `_voice.md`） | 又没、断了、没坚持、偷懒、又忘了、怎么又、懈怠、半途而废、掉链子 |
| 催促 | 赶紧、快去、别忘了、记得要 |
| 夸张、讨好 | 太棒了、恭喜、厉害、超级、最强、亲、宝 |
| 诊断 | 焦虑症、抑郁、失眠症、强迫（任何医学心理判断） |
| 因果（新发现、报告里） | 因为、导致、造成、所以才、使得 |
| 标点 | 感叹号「！」（任何地方） |

CI 里的文案检查覆盖：界面文字（String Catalog）、通知的固定文字、提醒和报告类 Skill。

## 5. 固定文案的模板

| 场景 | 模板 |
|---|---|
| 没整理成（网络） | 「没整理成：网络断了。联网后会自动再试」 |
| 没整理成（AI） | 「没整理成：AI 这次没有回应 · 再试一次」 |
| 额度用完（免费） | 「这个月的整理次数用完了，原话都存着，下个月 1 号会自动整理」 |
| 等你回答 | 「还有 1 个问题等你回答」（只在收据里，不推送） |
| 隐私中心的第一句 | 「你的原话存在这台手机和你的 iCloud 里」 |
| AI 标识的说明 | 「带『AI』的句子是 AI 根据你的记录写的；数字由程序核对过」 |

## 6. 通知的文案

- 最多两行；第一行说事，第二行可选
- 不用感叹号、不责备、不制造紧迫感
- 好几天没记时：说「想记的时候说一句就好」，不说「你已经 3 天没记了」
- 每类每天最多一条（沿用网页版规矩）
