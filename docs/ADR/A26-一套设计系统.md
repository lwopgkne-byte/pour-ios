# A26 设计系统只留一套：`Theme`

- **状态**：已定（3.0 第 0 步删旧的，第 1–10 步一块一块把 `Web*` 换掉）
- **日期**：2026-10-31

## 决定

- 设计系统只有一套：`PourDesign/Theme/`（生活画布 2.0 起的令牌和组件：颜色、字、间距、圆角、阴影、动效、触感）。3.0 的每一页、每个组件都只用它（[3.0 需求文档](../3.0/01-需求文档.md) 第 3 章、[技术方案](../3.0/02-技术方案.md) 第 4 章）
- **第 0 步**删掉第一阶段的旧系统：`PourColor`、`PourLayout`、`PourMotion`、`PourTypography`、`PourBrandMark`、`Components/`、生成色板的 `palette.py` 和 `PourPalette.swift`，以及只为它存在的设计画廊（`Gallery/`、`GalleryUITests/`、`PourGallery` 方案）
- 还在用的两样留下：`ColorToken`（颜色值和对比度计算，`Theme` 的颜色就是用它定义的）、`PourFlowLayout`（一行放不下换行的排法，挪进 `Theme/`，默认间距换成 `Theme.Space.small`）
- **第 1–10 步**：每重做一块，就把那一块用的 `Web.*` 换成 `Theme`、删掉那一块的 `Web*` 页面；全部做完删掉 `Web.swift`、`WebControls.swift`、`WebParts.swift`。SwiftLint 照旧拦硬编码的颜色、字号、间距、圆角、动画时长（07 开发任务清单 1.3 再加「禁止 `Web.`」）

## 为什么

- 两套（三套）设计系统并存，同一个东西有几种样子，改一处漏一处（[01 现在的 App](../01-现在的App.md) 第 6 节「局限」）
- 旧的 `Pour*` 在 App 里一处都没用了（2026-10-31 逐个类型查过，只有画廊和它自己的测试在用），留着只会被误用
- 设计画廊是第一阶段看样张用的；3.0 的样子以[可交互原型](../3.0/原型/可交互/index.html)和每个组件的 `#Preview` 为准，界面测试截图对照

## 没选的

- **留着画廊当组件目录**：组件的 `#Preview` 在 Xcode 里就能看全部状态，画廊要多维护一个 App、一套界面测试，检查时间多十几分钟
- **一次把 `Web*` 全换掉**：等于一次重做全部页面，出了问题分不清是哪块；按 3.0 的步骤一块一块换

## 后果和什么时候重新看

- 删掉的代码都在 Git 标签 `ios-2.8` 里，要找回去那里找
- 加入苹果开发者计划、要做 App Store 截图时，再看要不要一个专门出样张的目标
