# A33 3.0 关于我：一块一张卡片；Pour 认识的、一个人各自一页；方法说明收进 ⓘ

- **状态**：已定（3.0 第 8 步）
- **日期**：2026-11-03

## 决定

- **主页一块一张卡片**（`App/Sources/About3/`，只用 `Theme`）：你的生活由什么组成换成一行一个领域（名字、条、百分比、›），
  不用方块图；时间去向、这周的新发现（横着滑）、换个角度看你（2×2）、好日子的配方、你没注意到的变化、说的和做的、
  还在攒的、你的 2026。每一节的方法说明收进标题旁的 ⓘ（点了弹出一小段），「只是同时出现」留在卡片上
- **Pour 认识的有自己的一页**（`/about/known`）：主页只放一张六行的卡（作息、常做的事、人和关系、常去的地方、你的说法、
  改过的名字），点一行进那一页、滚到那一块；对话里「记住了」的链接（`/about?item=`、`?find=`）也打开这一页上的那一条。
  原来的几块（`KnownBlock`、`KnownRow`）换成卡片的样子，别的不变
- **一个人一页**（`/about/person/儿子`，服务器 `GET /api/about/person/:name`）：多是做什么（带天数）、那些日子的心情、
  关系（你说过的、哪天说的原话、添加关系）、最近的记录（那段话里说这件事的那一句）、在笔记库看原话、花在他身上的
- **人的星图**照第一期的位置算法，换成同一套颜色，两根手指放大（最多 2.5 倍，放大了能拖，点两下回去），点一个人的圆点进那一页
- **你说的话、你的一年、领域页**沿用原来的页面和数，把共用的部件（`MeHead`、`MePanel`、`MeNote`……）换成新的样子，
  不重写；领域页「这些数的变化」用看板的趋势：按时长算的类别多了次数、距离（说过几公里的才有）
- 关于我的页面用大标题；领域页、一个人、你的一年的名字由页面自己写（拿到才知道）

## 为什么

- 关于我内容多（第一期 1 比 1 搬的网页），一节一节平铺很长；卡片 + ⓘ 让第一屏回答「我的生活由什么组成」
- Pour 认识的是「改」的地方（对 / 不对、加说法、恢复名字），摊在主页上太长，也和「看」的东西混在一起
- 共用部件换样子比一页一页重写快，数和逻辑不动，测试照样能用

## 没选的

- **方块图**（第一期的样子）：小块里的字放大以后放不下；一行一个领域能写名字和百分比
- **一个人的页面在 App 里拼**（人的列表 + Pour 认识的 + 搜原话）：要拿好几样、算法会和服务器不一样；服务器一次给全
- **把你说的话、一年、领域页也放进 About3 重写**：内容和交互没变，换部件的样子就够了
