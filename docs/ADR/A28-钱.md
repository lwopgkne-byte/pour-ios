# A28 3.0 钱：主页一次拿全，记一笔记下的是原话，一天的钱留成一页

- **状态**：已定（3.0 第 3 步）
- **日期**：2026-11-01

## 决定

- **主页一次拿全**：`GET /api/money/home?month=` 回这个月（每一笔、每天、固定的、收入、花在哪）、和上个月同一段比、这个月和上个月每天的累计（画曲线）、预算（钱的「不超过」目标：已用、还能花）、留意的几条（带上按钮办的是哪几笔，`refs`）、发现。数字全部服务器现算，手机只照着画（以前主页要拿月份、总览、发现三次）
- **记一笔（数字键盘）记下的是一句原话**：键盘拼出「午饭 25」「打车 58 能报销」「借给小王 500」「工资 18500 收入」「给儿子买鞋 259」，`POST /api/notes` 带 `context: "money"`，和说一句走同一条整理的路。整理完以前，手机先在大数、月历、那天的每一笔、每一笔里加一行「整理中」（`AppModel.moneyPending`），整理完换成正式的；撤销一起拿掉
- **一笔的详情只列有的**：没说的不写「没说」，放进「补充」点了原地加；改了交给服务器（`PATCH` 整条记录），马上生效
- **一天的钱是推进来的一页**（01 需求文档 5.6 写的是弹层）：第三版原型（06 第 10.2 节）把「那天和谁在一起 · 你说的感受 · 那天你还说了」放到主页月历下面，点一天就看到；「那天 ›」进来的这一页要能再点开一笔的详情，弹层上再弹弹层系统不好管，所以留成一页，右上角 ‹ › 和左右滑到前后有钱的日子
- **每一笔的搜索框在大标题下面**：iOS 26 起默认放在屏幕底部，会被「说一句」挡住；搜的时候「说一句」让开（`AppModel.pageSearching`）
- **打开钱要面容 ID**（设置 → 隐私）：只记在这台手机上；验过一次，这次打开 App 都算数，退到后台再回来重新验（`MoneyLock`）；面容 ID 不行就用手机密码；手机没设密码时锁不了，设置里写明

## 为什么

- 业务规则（什么算日常、预算怎么算、留意哪几条）只放服务器一处；主页一次拿全，打开快、先出缓存也是一整页
- 原话是唯一的源头（00 提示词）：数字键盘也只是帮你说一句，整理、改、撤销都和说的一样
- 系统的搜索框、列表、左滑、长按菜单：手指试起来和别的 App 一样顺手

## 没选的

- **记一笔直接写一条记录、不走整理**：会出现两种来源的钱，改、撤销、评测都要两套
- **一天的钱做成弹层**：点开一笔的详情得先关掉它，来回多一步

## 后果和什么时候重新看

- 记一笔的原话格式写进了评测（`evals/parse-cases.json` 的 `ctx-money-keypad`）；改整理规则时这几条要一起过
- 打开钱要面容 ID 用的是 `deviceOwnerAuthentication`：以后要「只认面容 ID、不让用密码」再改成 `deviceOwnerAuthenticationWithBiometrics`
