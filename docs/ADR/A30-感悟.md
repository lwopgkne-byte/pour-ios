# A30 3.0 感悟：语录 = 收藏的 + 记一句记的；今天重温由服务器挑、记下看过了；分享的图片只在手机上画

- **状态**：已定（3.0 第 5 步）
- **日期**：2026-11-02

## 决定

- **语录 ★ = 收藏的 + 「记一句」记的**（「不放进语录」的除外）：感悟加 `starred`；「记一句」记的本来就算（R4），在它上面取消收藏
  就是「不放进语录」（记录不动，和以前「我的语录」里那个按钮是同一件事）。回顾的「你说过」、小组件「我的语录」从语录里挑
  （以前只从「记一句」的里挑）。`POST /api/insights/:id/star`
- **今天重温由服务器挑**（`GET /api/insights/today`，`?next=1` 换一句）：一个月前、一年前的今天说的 → 收藏的 → 很久没见过的；
  30 天内见过的不挑、今天说的不挑；一天里打开几次都是同一句（换过就是换到的那句）；挑到的记进设置的 `insights.seen`。
  带着你当时说的整段话和以前也说过类似的（翻过来看）；一条感悟 `GET /api/insights/:id` 也是这个样子，不算「看过了」
- **感悟页一次拿全部感悟**（`GET /api/insights`），标签、「语录 ★」在手机上筛（点了马上换，条数跟着点过的星变）；搜才问服务器
  （`?q=`，关键词 + 本地向量按意思找）
- **点星、改字、删除先改界面再发**（写操作队列，01 3.3）：服务器的单子拿回来、和它一样了才不再记着；删除、改字轻提示能撤销
- **记一句记下的是一句原话「记一句：……」**，带 `context: "insights"` 走整理；感悟页最上面马上多一张「整理中」，整理好的那张亮一下
- **分享成图片只在你点分享时、在这台手机上画**（`ImageRenderer`，300 点宽 × 3.6 = 1080 像素，字号固定、长句往下长不截断）；
  预览就是那张图片本身；存到相册只要「添加照片」的权限
- **笔记库的「感悟」一栏搬走**：`/library?view=insights` 这个旧地址打开感悟页；画布感悟卡的标题点进感悟页

## 为什么

- 语录只有一个说法：收藏和「不放进语录」是同一个开关的两面，不会出现「收藏了却不在语录里」
- 挑哪一句要记得「看过了」，放在服务器上才跨手机、跨重装都算数；规则写成纯函数（`pickRevisit`）好测
- 感悟一个人一年也就几百条，一次拿全在手机上筛最快；按意思搜要本地向量，只能问服务器

## 没选的

- **列表按标签分页问服务器**（`?tag=&cursor=`，01 7.5 原来写的）：点胶囊要等网络，条数也不能跟着星马上变；服务器的 `?tag=`、
  `?starred=1` 留着给别处用
- **分享图片在服务器上画**：要把那句话发出去、还要字体；手机上画不上传

## 后果和什么时候重新看

- 感悟多到几千条时，一次拿全会慢：那时候再按月分页
- 分享出去的图片在 iPhone 相册里「字不糊、不截断」要装到手机看（模拟器上量了 1080 像素宽、长句往下长）
