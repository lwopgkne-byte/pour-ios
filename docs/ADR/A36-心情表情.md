# A36 心情的五个表情用 Material Symbols 的字形（和原型一样），不自己画

- **状态**：已定（3.0.1，产品主人 2026-11-05：「心情的表情还是太粗糙」）
- **日期**：2026-11-05

## 决定

- 五档心情（很差 · 不太好 · 一般 · 挺好 · 很好）的脸用 Google Material Symbols Rounded 的
  `sentiment_very_dissatisfied` … `sentiment_very_satisfied`（实心、粗细 500、24 号）——可交互原型用的就是这一套。
  官方 SVG 的路径原样放进 `PourDesign/Theme/MoodGlyph.swift`（`MoodGlyph` 是一个 `Shape`，App 里自己读路径，
  不带字体、不加库）。一张实心的脸，眼睛和嘴是挖空的，透出底下这一档的粉色
- 颜色照原型 `MOOD_BG / MOOD_FG`，为了看得清改三处（`ThemeColorTests` 量）：「一般」的脸用深色（原型白脸在那个粉上
  只有 2:1）；「挺好」「很好」的底各深一点点（白脸到 3:1、写在上面的白字到 4.5:1）。写在心情底色上的字另有一组
  更深的颜色（`Theme.Mood.label`）
- 许可：Apache License 2.0。「关于 Pour」里写一行致谢

## 为什么

- 自己用线条画的脸（两个点、一条弧）和原型放在一起看很粗糙；原型的字形是成熟的图标，形状、粗细、留白都调过
- 只要五个字形：照搬路径比带一个图标字体（几 MB、还要处理可变字体的轴）简单

## 没选的

- **SF Symbols 的表情**：只有笑脸（`face.smiling`），没有五档
- **带上 Material Symbols 字体**：只用五个字，不值得

## 后果和什么时候重新看

- 新的地方要画心情，用 `MoodBadge`（带颜色的圆 + 脸），不要再自己画
- 要换样子时，换 `MoodGlyph.data` 里的路径（从官方 SVG 拷，`MoodGlyphTests` 量外框和挖空）
