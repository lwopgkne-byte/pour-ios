# A29 3.0 心情：记心情也是一句原话；心情页一次拿全；晚上问一句是手机自己排的通知

- **状态**：已定（3.0 第 4 步）
- **日期**：2026-11-01

## 决定

- **记心情（心情页的五个表情、「我的」的快捷、画布心情卡、按住图标、小组件、晚上那一问）记下的都是一句原话**：
  「心情挺好」「心情不太好，烦躁，因为方案又改了」，`POST /api/notes` 带 `context: "mood"`，和说一句走同一条整理的路。
  点的情绪词胶囊就是你「说」的，「情绪词只写说出来的」（prd-mood）照样成立；只点一档就只发「心情挺好」——整理时不编那一刻、
  不编情绪词（评测 `ctx-mood-*` 五条管着）
- **心情页一次拿全** `GET /api/mood/page?month=`：今天的每一刻、这个月说到心情的每一天和那天的每一刻、平均一句、一周里哪天低、
  好时刻、发现、变化；常用情绪词 `GET /api/mood/words`（按这 90 天你说得多的排）
- **五档同一种粉从浅到深**（`Theme.Mood`），表情本身说明好坏：浅的三档脸用深粉色画，深的两档用白色，对比度单元测试量
- **晚上问一句是手机自己排的通知**（`EveningMood`，设置里打开，默认关，只记在这台手机上）：按住通知直接选一档或者「说两句…」，
  不用打开 App；和「晚上的倾倒提醒」合成一种（今天没说过话问「今天过得怎么样」、说过话没说心情问「今天心情怎么样」、说过心情不问）；
  打开它时电脑那边的倾倒提醒自动关，关了再恢复
- **小组件「记心情」**：交互小组件，点一个表情直接发给电脑上的 Pour，连不上先存在手机上，打开 Pour 时再发

## 为什么

- 原话是唯一的源头：一处整理、一处评测；改、撤销、回顾都和说的一样
- 按住通知直接选只有本地通知做得到；两条晚上的提醒会烦人，所以合成一种

## 没选的

- **记心情直接写一条心情记录、不走整理**：会有两种来源的心情，「依据」写不出来，评测也管不到
- **晚上那一问由电脑推**：推送点开只能打开 App，做不到按住直接选

## 后果和什么时候重新看

- 通知上能放几个按钮要在真机上试（现在五档 + 说两句一列排下来）；放不下就照 01 6.4 换成「挺好 · 一般 · 不太好 · 说两句…」
- 小组件、晚上那一问在 App 没开着时发出去的原话，连不上时存进分享的待发（打开 Pour 时发，那时不带 `context`）
