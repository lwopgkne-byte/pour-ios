# A05 数据库：SQLite + GRDB；界面观察和同步用 SQLiteData

- **状态**：已定
- **日期**：2026-10-17

## 决定

本机数据库用 SQLite（GRDB），页面直接观察查询。

## 为什么

复杂查询最直接、最快；规则能用数据库约束守住（基础类别不许有上级）。

## 没选的

SwiftData：复杂查询和迁移不可控。
