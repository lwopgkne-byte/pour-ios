# A02 界面：SwiftUI 为主，倾倒栏输入区用 UIKit 包一层

- **状态**：已定
- **日期**：2026-10-17

## 决定

页面、组件、动效用 SwiftUI；倾倒栏的输入框用 UITextView 包一层。

## 为什么

系统组件、Liquid Glass、动效都是 SwiftUI 优先；中文输入法的标记文字（拼音候选）、输入框长高，UIKit 控制更稳（规范 05 第 5 节）。

## 没选的

React Native / Flutter：拿不到最好的原生手感和系统新能力（08 第 4.3 节）。

## 后果和什么时候重新看

M3 做按住说话时实测中文输入法；有问题回到这里改。
