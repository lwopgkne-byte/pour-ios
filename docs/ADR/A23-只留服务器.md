# A23 网页删掉，只留服务器；只能在电脑上做的换成「Pour 设置」

- **状态**：已定（产品主人 2026-10-20 要求）
- **日期**：2026-10-20

## 决定

- 服务器仓库 2.0.0 删掉网页（`web/`、页面测试、网页打包和设计令牌检查）；用浏览器打开服务器地址只说一句「请在 iPhone 上打开 Pour App」
- 以前只能在电脑的网页上做的七样——大模型密钥、推送密钥、PIN、开关 PIN、从备份导入、跑评测、审核员考试——换成电脑上的数字菜单「Pour 设置」（`~/Developer/pour/Pour 设置.command`，或 `npm run settings`）。服务器照旧只认本机来的这几个请求
- 推送点开打开 App：Bark 的推送带 `pour://`；App 认 `pour://open?path=页面地址`（推送、以后的小组件和快捷指令都能用）
- 这个仓库删掉复刻用的东西（网页截图脚本、对照截图的测试、交接说明、还没搬的页面的占位），代码注释里不再写「网页版的哪个文件」；第一阶段的方案文档挪到 `docs/归档/`

## 为什么

产品主人：「整个工程目录清除一切和网页有关的东西除了那个服务器外，因为我后面要根据这个去进行专门的优化成专门 iOS App」。网页的每一页都已经在 App 里，留着网页只会让两边一起改、互相拖累。

## 没选的

- 把这七样搬进 App：密钥要经过 WiFi 传；PIN 在手机上能改，同一个 WiFi 里谁拿着手机都能改——现在的「只认本机」更安全，等上云、有正式的账号以后再看
- 留一个只有设置的小网页：还是两套界面

## 后果和什么时候重新看

- 家里的 Windows 上「Pour 主程序」拉了新版本以后只是服务器，没有网页
- 名字里还带 `Web` 的（`Web.*` 令牌、`WebButton`……）是从网页版搬来的设计系统，第二阶段统一设计系统时改名
- 服务器上云时，「只认本机」要换成正式的身份验证，「Pour 设置」跟着改
