# A25 3.0 外壳：画布首页、一个导航栈、左上角「我」，不要标签栏

- **状态**：已定（产品主人 2026-10-28：「不要底部操作栏，太冗余了……底部只能留语音识别和生活画布，和之前一样」；3.0 第 1 步做）
- **日期**：2026-10-31

## 决定

- **打开就是生活画布**，它是一个 `NavigationStack` 的根；别的页都推进这一个栈，返回按钮写上一页的名字，从左边缘右滑返回，一路返回到底是画布（[3.0 需求文档](../3.0/01-需求文档.md) 第 2 章、[06 交互细节](../3.0/06-交互细节.md) 第 1 节）
- **画布顶上一行**：左「我」（→ 我的 = 全部功能）、中「今天 · 日期 ▾」（展开一周、跳到某一天）、右搜索，放在系统的导航栏工具栏里（不自己盖一层：盖着的那一层在长按菜单用过以后点不动，2026-10-31 界面测试查出来的）。去掉左上角抽屉菜单、每页顶上的搜索和黄色的演示数据横幅
- **底部只有「说一句」**，每一页都在：提示跟着页面变，发出去带上在哪一页说的（服务器 2.9.0 的 `context`）；点了展开对话，上面一排快捷；往下翻收起、往上翻出来。它挂在导航栈外面（换页时不跟着动），量出高度，每一页底下留同样高（滚到底最后一行也点得到）
- **页面地址照旧**：`Route`（`App/Sources/Shell/Route.swift`）把每一种页面地址对上一页，单元测试一条一条对（`RouteTests`）。页面里互相跳推进来一页；同一种页面里翻页（上一天、下个月）换掉最上面那页；要去的页就在下面就退回去；从 App 外面打开（`pour://open?path=`、推送、小组件）是画布在最底下、只推那一页
- 还没重做的页（第 2–10 步一块一块重做）原样推进来，导航栏只放返回按钮，它们自己的大标题先留着

## 为什么

- 产品主人否掉了底部标签栏；不用标签栏的一线 App（手记、Things、微信聊天）首页就是内容，内容本身是入口
- 原来的抽屉菜单 + 每页换掉整个页面：没有返回、没有手势，深一层就回不去；一个导航栈是系统的标准做法，返回、右滑、读屏都是现成的
- 字符串的 `pagePath` 让每一页自己解析、自己清掉，链接一多就对不上；有类型的 `Route` 编译器能查、单元测试能逐条核对

## 没选的

- **底部标签栏**（待办 · 钱 · 我）：产品主人 2026-10-28 否了
- **每一块一个自己的导航栈**：从一块跳到另一块（关于我 → 钱）返回就乱了；一个栈最简单

## 后果和什么时候重新看

- 新页面只用 `Theme`（[A26](A26-一套设计系统.md)），推进来时用系统的大标题；SwiftLint 的 `no_web_in_new_pages` 管着新目录
- 加入苹果开发者计划、有了系统推送以后，推送点开也走 `openLink`
