> 状态：方案；样子在 [生活画布 2.0（页面）](https://claude.ai/artifact/CWtzJsx92kQgR6ptPmPdV7)，产品主人看过点头就开工。

## 0. 这一块的提示词

你是 Pour 的 iOS 设计师兼主力工程师，按 [00 提示词](../00-提示词.md) 的总要求工作。这一块把「照网页搬过来」的生活画布，升级成一线 iOS App 的水准：精美、有艺术感、流畅，动效恰到好处。要深度优化，不是换个颜色。

**产品主人的原话（2026-10-21）**：逐个模块不断地升级优化，首先优化生活画布模块，做的粗糙。希望做一次系统化的升级，包括上面的卡片、输入框、和 AI 对话框的各种状态；要精美的、好看的、艺术的，能体现 iOS 的好看和流畅度，以及动效。方案要系统完整：字体、间距、背景、布局等等，还要考虑我没有想到的。后面准备加上语音识别，先加上，后面我给你对接大模型。现在完全像网页，没有 App 的优美和精致感。要深度优化，不要浮于表面和偷懒。（他发了三类参考截图：iOS 27 控制中心、Manus 的对话和语音输入、华为运动健康的「今日」页。）

**范围**
1. 画布：顶部和大标题、一周条、今天的样子、推进的目标、一天的带子、两列卡片；加载、空的、出错、看别的日子
2. 输入框：平时、打字、斜杠命令、说话、按住说、正在整理、整理好了、没网、没整理成
3. 语音识别：在手机上转中文（SpeechAnalyzer），点一下说、按住说；录音不存不传；做成能换的零件，以后接产品主人给的大模型
4. 对话面板：原生半屏面板；你的话、收据卡、确认、正在回答、记住了、出错、没连大模型、空的时候

不做：底部标签栏（之后「外壳」那一块）、小组件和锁屏、拍照和图片。

**参考，学方法不照抄**：iOS 27 的 Liquid Glass（控制中心）、Manus（输入框和语音、对话、建议）、华为运动健康（今日页：大数字、迷你图、两列卡片）。

**必须做到**
1. 先定设计规范再写界面（第 6 节）；画布只用新规范
2. 层次靠深度不靠线；数字是主角；动是因为有事发生
3. 每个组件的全部状态都设计到：默认、按下、加载、空、出错、没网、待确认、正在整理
4. 数据用服务器现在给的，手机不自己算业务数字；要新数据先在服务器做接口
5. 动效不超过 0.5 秒；「减弱动态效果」时换成渐变；「降低透明度」时玻璃换实色
6. 深色、字号调到最大、读屏都要过；iPhone 15 上滑动和动画 60 帧不掉
7. 文案不责备、不诊断、说人话（「比目标少 40 分」，不写「睡眠不足」）

**怎么做**：分六步（第 8 节）。每一步先写测试再做；跑 `scripts/check.sh --full`；截亮色、深色、最大字号三组图；装到产品主人的 iPhone，给他看改之前和之后。他说不对，就在这一步改，不往下走。

**验收**：产品主人看了说「像 App 了、好看」；每页的界面测试和无障碍审计全过，单元测试只多不少；普通话说完一句 1 秒内出字、准到能直接发；深色、最大字号、读屏、降低透明度、减弱动态效果各有一组截图。

## 1. 现在为什么像网页（对着代码查的）

| 地方 | 现在（代码） | 改成 |
|---|---|---|
| 底和卡片 | 白底（`Web.bg`），卡片 1 点灰线（`Web.line`），圆角 8（`radiusCard`） | 暖灰的底，白卡片浮起来不画线，22 点连续圆角 |
| 字 | 照网页 26 / 18 / 16 / 13，大半是 60–70% 的灰字；数字藏在句子里 | 34 / 20 / 17 / 15 / 13；数字用圆体大字 |
| 顶部 | 48 点白栏 + 两个灰图标（`AppHeader`）；演示数据是整行黄横幅 | 玻璃圆按钮浮在内容上；大标题往上滑缩进顶栏；演示数据是小玻璃胶囊 |
| 目标 | 一摞带边框的长胶囊（`GoalPills`），5 个就占快半屏 | 一排进度环小卡，左右滑 |
| 时间轴 | 1 点细线上的小色块（`TimelineStrip`），「未定时间」堆成好几行 | 36 点高的带子，色块带图标，有「现在」线；没时间的一行左右滑 |
| 卡片 | 每类一张一样的列表卡（`DayCards`），emoji，底下几行灰字；待确认是虚线框 | 两列卡片：大数字 + 迷你图 + 一句状态；线条图标；待确认是一个小按钮 |
| 输入框 | 贴底的灰框 + 分割线，方形浅蓝按钮，没字时 40% 透明（像坏了）；没有语音 | 浮起来的玻璃输入框；一个圆按钮在麦克风和发送之间变；能说话 |
| 对话面板 | 自己画的 55% 高面板，气泡是白框加线，状态是小灰字 | 原生半屏面板；蓝气泡；收据卡；确认按钮；正在回答的光标 |
| 动效、触感 | 只有 0.2 秒的渐变（`Web.panel`），没有触感 | 发出去、整理好、长出来、换一天都有动效和触感 |
| 深色 | `.preferredColorScheme(.light)` 强制亮色 | 深色设计好、测好（什么时候打开见第 9 节） |

## 2. 设计方向：一页会呼吸的日子

每一天是一页会自己长出来的纸：底是安静的，内容浮在上面，今天的心情给它一点颜色。

1. **层次靠深度，不靠线**：底、卡片、浮在上面的玻璃三层；不画分割线和边框
2. **数字是主角，字是配角**：睡了多久、花了多少、推进了多少用大号圆体；说明用小字
3. **动是因为有事发生**：发出去、整理好、长出来、换一天才动；平时安静

从参考里学的：控制中心——玻璃只给浮在内容上的东西（按钮、输入框、面板）；Manus——输入框是一张浮起来的大圆角卡，说话时声波 + 计时 + 取消 / 转文字 / 发送，回答下面给建议；华为运动健康——大标题、最上面一排关键数字、两列卡片（大数字 + 小图 + 彩色状态）。不学：满屏玻璃、黑色大按钮、颜色太满。

## 3. 画布从上到下

1. **顶部**：左边菜单，右边日历、搜索，都是 44 点玻璃圆按钮（`glassEffect(.regular.interactive())`）。大标题：今天、昨天写「今天」「昨天」，别的日子写日期（34 粗）；下面一行「10月21日 周三」（15，次要色）。往上滑大标题缩进顶上居中的玻璃胶囊「今天 · 10月21日」（`onScrollGeometryChange` 算位置），内容滑到玻璃下面时边缘柔和淡出（`scrollEdgeEffectStyle(.soft)`）。看别的日子时，胶囊旁多一个「回到今天」。演示数据是标题下面一个小玻璃胶囊「演示数据 · 回到真实数据」。
2. **一周条**：七天一排（周一到周日），今天蓝色实心圆，选中的别的日子浅灰圆，有记录的日子下面一个小点（要服务器给「这一周哪几天有记录」，见第 8 节）；点一下换到那天，左右滑换一周；以前的「点日期跳」变成日历按钮。
3. **今天的样子**（大卡，28 圆角）：底色是当天心情的淡渐变（`MeshGradient`）：挺好偏暖杏色，一般偏沙色，不太好偏雾蓝，有起有落两种都有；没记心情就是中性暖灰。上面一个「今天的样子」小标签和「心情 · 有起有落」；中间是 AI 一句话（`summary`，19 / 29）；下面三个数字小块：睡眠时长、今天花了多少（日常的）、记了几条，点了滚到那张卡。正在整理时一句话下面一行流光「正在整理刚才那段话…」。空的一天：「今天还是空白。说说你做了什么，这里会自己长出来」+ 一个「说一句」的麦克风按钮。
4. **推进的目标**：区块标题「今天推进的目标 · 3 个」；每个目标一张 160 宽的小卡：进度环（状态色，`pct`）、右上角今天推进了多少（`delta`，状态色的浅底标签）、目标名、一行进度（`headline`）。左右滑；点了用缩放转场打开目标详情。
5. **一天的带子**：区块标题「一天的时间 · 现在 21:48」。0 到 24 点一条 36 点高的带子：色块是类别色，宽度够（≥ 28 点）写白色图标；大块下面写名字和时长；今天有一根蓝线指着现在。跨零点的睡眠从左边开始。点色块打开那条记录，长按预览。没说时间的放在带子下面一行小胶囊（类别色圆点 + 名字），左右滑，不再堆好几行。
6. **两列卡片**（22 圆角，卡片间 12）：
   - 半宽（一个数）：**睡眠**（时长大字、几点到几点、夜里刻度条、离目标多少）；**花了**（今天日常花的总数、几笔、按类别分段的一条、等报销的几笔）；**心情**（这一天的样子一个词、一天里几次心情的小曲线、「AI 推测」）；**身体数据**（血压、体重这类：数值大字、几点量的、有最近几次就画小折线）；**运动**（时长或距离大字）；一个类别里只有一两件事的也放半宽（名字 + 钱或时长 + 等报销这类小标签）
   - 整行（一串）：**待办**（圆圈勾选，提醒时间带铃铛，勾掉有动画和触感，左滑删除）、**感悟**（原话用宋体引用）、事情多的类别
   - 排的规则：半宽两两成对，单出一张拉满一行；字号调到辅助功能那几档时全变一列
   - 卡片标题：28 点圆角小方块里一个线条图标（类别色 15% 底）+ 类别名 + 右边的数（「还有 1 件」「4 笔」）；底部是相关目标的一行（小环 + 名字 + 进度）
   - 待确认：不用虚线框；那一行旁边一个「确认一下」小按钮，点了出「对 / 改一下」
   - 交互：按下缩到 0.97；点了用缩放转场打开详情（`navigationTransition(.zoom)`）；长按出原生菜单（修改、看原话、删除）带预览
7. **加载、出错**：拿数据时是和卡片同形状的灰块，慢慢明暗；换日子不白屏（先留着上一天，新的到了再换）；连不上时今天的样子那张卡写原因和「重试」。

## 4. 输入框和语音

**样子**：浮在内容上，离两边 12、离底 8（在 Home 条上面），56 高，28 圆角，玻璃。左边「对话」按钮（打开对话面板，也可以在输入框上往上滑）；中间输入；右边一个 44 点圆按钮：没字时麦克风，有字时发送（`contentTransition(.symbolEffect(.replace))`，强调色实心）。最多长到 6 行。

| 状态 | 看到什么 |
|---|---|
| 平时 | 提示语按时间换：早上「早上吃了什么？」，白天「今天做了什么？比如：跑步1小时」，晚上「今天哪一刻觉得挺好？」 |
| 打字 | 跟键盘一起弹起；麦克风变成发送，轻碰一下 |
| 斜杠命令 | 输入「/」在上方浮出一张玻璃卡，每个命令一行带例子，第一行是选中的样子 |
| 说话（点一下） | 输入框长高成录音卡：红点「正在听」、计时、声波、说的字一边说一边出（还没定的字浅色）；✕ 取消、✓ 转成文字再改、↑ 直接发 |
| 按住说 | 按住麦克风说，松开发送，往上滑取消；中间一张玻璃卡「松开发送 / 手指往上滑，取消」 |
| 正在整理 | 输入框上方浮一条玻璃小条：呼吸的图标 +「正在整理：（那段话）」，字上一道流光；点了打开对话停在那段话 |
| 整理好了 | 小条变成「记下了 2 条 · 牛肉面 ¥28、拿铁」+「撤销」，成功的触感；画布上新卡片从 0.96 长到 1、亮一下；数字滚动（`numericText`） |
| 没网 | 「没网，先存在手机上 · 连上自动发」，云朵划线图标 |
| 没整理成 | 红色浅底「没整理成：（原因）」+「重试」，错误的触感 |

**语音识别**
- 引擎：`SpeechAnalyzer` + `SpeechTranscriber`（`zh_CN`，带「还没定下来的」中间结果），声音来自 `AVAudioEngine`；2026-10-21 在这台 Mac 上查过，`SpeechTranscriber` 支持 `zh_CN`、`zh_HK`、`zh_TW`、`yue_CN`。第一次用时 `AssetInventory` 下载中文模型，麦克风上一个进度环
- 声波：每 1/30 秒取一次音量，46 根竖条；不说话时平
- 最长 2 分钟，1 分 50 秒轻震；没听到声音：「没听清，再说一次」
- 权限：第一次点麦克风先出一张说明（只在手机上转文字，录音不存不传），再请系统权限（`NSMicrophoneUsageDescription`、`NSSpeechRecognitionUsageDescription`）；拒绝了：输入框上方一行「要用语音，去设置里打开麦克风」+ 按钮
- 能换的零件：`protocol VoiceInput { func start() async throws -> AsyncStream<VoiceEvent>; func stop() async -> String; func cancel() }`（`VoiceEvent`：音量、中间文字、定下来的文字、出错）。现在是 `OnDeviceVoice`；以后产品主人给大模型，加一个云端的实现，或者在转出来的字发出去之前让大模型理顺（去掉「嗯、那个」、改同音字）。界面只认这个接口
- 告诉服务器这是说的话：发原话时带 `source: "voice"`（服务器加一个可选字段），整理时对口语和同音字更宽容
- 隐私：录音只在内存里，不落盘；说话时系统会显示橙色小点

## 5. 对话面板

- **容器**：原生 `sheet`，两档高度（约 0.6、几乎全屏），往下拖收起；0.6 那档后面的画布不压暗、还能滑（`presentationBackgroundInteraction(.enabled(upThrough:))`），能看着卡片长出来；输入框跟着移进面板底部；右上角关闭
- **你的话**：右边，柔和的蓝底气泡（20 圆角，右下角小一点）；下面一行时间 + 状态图标（时钟、流光、对勾、红色感叹号），状态变了图标替换
- **Pour 的回复**：左边，不用气泡：
  - 收据卡：「✓ 记下了 2 条」+ 右上角「撤销」；每条一行：类别小方块、名字、数字；待确认的那条带「确认一下」
  - 确认：一句问话 +「对」「改一下」两个按钮（「对」确认那条记录，「改一下」打开详情）
  - 正在回答（问问题时）：一段一段淡入，末尾蓝色光标；来源编号是小标签，点了看原话；图表卡照现在的
  - 记住了：一行小字「记住了：老地方 = 公司楼下的面馆」，点了到「关于我」那一条
  - 提醒和回顾（系统消息）：一张小卡，图标 + 标题 + 一句话
- **其他状态**：正在整理（气泡下一行流光「正在整理…」，图标呼吸）；没整理成（红色小图标 + 原因 +「重试」，错误触感）；还没连大模型（「说的话都先存着；在电脑上用 Pour 设置填好密钥就开始整理」）；没网（顶上一条「没网：说的话先存在手机上」）
- **空的时候**：中间一句「说说今天」+ 三个例子（「8点跑了5公里」「午饭花了35」「这周睡得怎么样」），点一下填进输入框
- **翻历史**：翻到上面自动加载更早的；离开底部时右下角浮一个「回到最新」玻璃圆按钮；按天分隔是居中的小胶囊「昨天 · 10月20日」
- **长按气泡**：复制、改这段话、删除（和笔记库一样）

## 6. 设计规范（这一块定下来，之后全 App 沿用）

新建 `Packages/PourKit/Sources/PourDesign/Theme/`：一个 `Theme` 命名空间放颜色（亮、暗）、字、间距、圆角、阴影、动效、触感（不叫 `Color`、`Font` 这种和 SwiftUI 撞名的名字）。第一阶段旧的 `Pour*` 令牌只剩设计画廊在用，这一块一起清掉。画布全用新的；别的页面改到时再换过去，最后删掉 `Web.*`。SwiftLint 的令牌检查跟着认新的。

### 6.1 字

系统字体（SF + 苹方），全部跟着动态字体（`relativeTo:`）。数字用圆体（`.fontDesign(.rounded)`）、等宽（`monospacedDigit`）。

| 用在 | 字号 / 行高 | 字重 | 备注 |
|---|---|---|---|
| 日子大标题 | 34 / 41 | 粗 | `.largeTitle` |
| 今天的样子（AI 一句话） | 19 / 29 | 常规 | 中文多给行距 |
| 区块标题 | 20 / 25 | 半粗 | `.title3` |
| 正文（记录、对话） | 17 / 23 | 常规 | `.body` |
| 卡片标题 | 15 / 20 | 半粗 | `.subheadline` |
| 卡片大数字 | 30 / 36 | 半粗、圆体 | 单位 15 中等、次要色 |
| 今天的样子里的数字 | 21 / 27 | 半粗、圆体 | |
| 注释、时间 | 13 / 18 | 常规 | `.footnote` |
| 刻度、角标 | 11 / 16 | 中等、圆体 | `.caption2` |
| 你说的原话（引用） | 17 / 26 | 常规、宋体 | 原话的身份 |

### 6.2 间距和尺寸

4 点为单位：4 · 8 · 12 · 16 · 20 · 24 · 32。屏幕两边 16；卡片里 14–16；卡片之间 12；区块之间 28–32；大标题上 4 下 16。能点的至少 44 × 44；输入框 56 高。

类别色沿用九种颜色名（服务器存的是名字），每种两档：紫 `8F6FD0` / `A58BE6`、橙 `E8873A` / `F29A55`、金 `C9962A` / `E0B04A`、粉 `D7699A` / `E883AE`、红 `E0605A` / `F07A72`、棕 `A67A5E` / `C0957A`、蓝 `3D8BD9` / `5FA5EE`、绿 `46A56E` / `5CC48B`、灰 `8E8C86` / `9C9A94`。图标底用 15% 的浅色。正文和底的对比度 ≥ 4.5:1，审计照旧查。

心情的颜色（今天的样子的底）：挺好 暖杏 `FFB78C`，一般 沙 `E8DCC8`，不太好 雾蓝 `A9C2E8`；亮色 40–55% 不透明，深色 25–30%。

### 6.4 圆角、阴影、玻璃、图标

- 圆角（都是连续圆角）：今天的样子 28，卡片 22，目标小卡 20，输入框 28，气泡 20，收据卡 18，图标底 8，按钮正圆或胶囊
- 阴影（只在亮色）：卡片 `y1 blur2 4%` + `y6 blur20 5%`；深色不用影子，卡片比底亮一档，边上 0.5 点白 6%
- 玻璃：只给浮在内容上的东西（顶上的按钮和胶囊、输入框、浮条、对话面板）；挨着的几个放进一个 `GlassEffectContainer`，麦克风和发送用 `glassEffectID` 变形；「降低透明度」时换成卡片色
- 图标：SF Symbols；类别图标在 28 点圆角小方块里；粗细跟着字重

### 6.5 动效

| 名字 | 参数 | 用在 |
|---|---|---|
| 快 | `.snappy(duration: 0.2)` | 按下、按钮状态、图标替换 |
| 标准 | `.smooth(duration: 0.35)` | 展开、收起、换一天、浮条出现 |
| 强调 | `.spring(duration: 0.5, bounce: 0.2)` | 新卡片长出来、发出去 |

- 数字变化：`contentTransition(.numericText())`；图标：`symbolEffect(.bounce)`（发出去、整理好）、`.breathe`（正在整理）
- 换一天：整页跟手滑过去，一周条上的圆跟着移
- 往上滑：大标题缩进胶囊；卡片滑到边上时轻微缩小（`scrollTransition`，0.98）
- 「减弱动态效果」：全换成 0.2 秒渐变，不缩放不位移

### 6.6 触感

| 时刻 | 触感（`sensoryFeedback`） |
|---|---|
| 发出去 | `.impact(weight: .light)` |
| 整理好了 | `.success` |

## 7. 你可能没想到的

深色模式；字号调到最大（两列变一列、带子收起文字）；读屏（每张卡、每个图念得出意思）；降低透明度、增强对比度；加载时和卡片同形状的灰块；空的一天；看别的日子时「回到今天」；整理好以后自动滚到新长出的卡片（你没在往上翻时）；iPhone 15 是 60 帧的屏，滑动和动画一帧不掉、玻璃不叠太多层；不说话时马上关麦克风；录音不落盘；文案检查照旧（「比目标少 40 分」不写「睡眠不足」）；所有能点的至少 44 × 44；输入框做成独立零件，以后小组件、锁屏、快捷指令「倒一句」都用它。

## 8. 分几步做

| 步 | 做什么 | 产品主人看到 | 估计 |
