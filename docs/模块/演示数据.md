# 演示数据：所有功能都看得到（2026-10-27）

## 要什么（产品主人原话）

> 我连接手机了，我期望你能够在生活画布里面有演示数据，方便我能够向别人介绍功能，上所有的，以一个人为，产品经理背景，包含有所有的功能

## 原来有什么、缺什么

- 服务器早就有「演示数据」（SPEC 第十三章）：一个 34 岁的产品经理连续 9 周的生活，单独一个数据库（`demo.db`），不碰真实数据；App 的「设置 → 数据 → 切换到演示数据」能切过去，画布顶上一个胶囊「演示数据 · 回到真实数据」
- 缺的是产品优化（`docs/模块/产品优化.md`）以后加的：健康、我的卡片、我的语录、说到的改名字和不再显示、补记、问待办、今天的待办（小组件、锁屏）、日历
- 还有两处演示时会露出你自己的东西：**日历**是手机自己读的（演示时待办卡里会出现你真实的日程）；**健康**是手机读了送过去的（演示时你的步数、睡眠会送进演示数据）。还有一处会打扰你：演示里那个人的待办「10:00 给客户回电话」，手机会照样排成你手机上的系统通知

## 怎么做的

**服务器 2.8.0**（服务器仓库 SPEC 第十三章、CHANGELOG 2.8.0）

- 还是那个产品经理、故事一天不差，加上：手表的步数、睡眠、锻炼（说了的和手表记的只算一次，没说的晚饭后散步单独一条，忘了说睡眠的两晚用手表的，瑜伽课没说几点补上手表的时间，「每天走 8000 步」）；说一句建的三张卡片（今年看的书、每周跑了多少、这个月陪儿子，后来把书单挪到最前面）；「记一句」的五句语录（回顾最后的「你说过」、小组件从这五句里挑）；「媳妇就是老婆」「以后别显示同事」；翻到两天前补记的两句；今天的两件待办（10:00 给客户回电话、17:30 把会员改版的 PRD 发给研发）和睡前问的「明天要做什么」
- 演示的日程 `GET /api/demo/calendar`：每周的周会、需求评审、和领导 1:1、用户访谈、版本复盘，周日上午儿子的篮球课；今天还有全天的结婚纪念日、和待办同一件的「给客户回电话」
- 演示数据时手机送来的健康数据不收、断开也不删
- **每次从真实数据切到演示数据都重新生成到此刻**：演示里的「今天」就是今天（还没到的事不提前出现）；服务器重启时演示数据要是以前哪天生成的，也重新生成
- 电脑一直停在演示数据、过了一天（服务器 2.8.1，装到手机以后补的）：App 一打开（要 `/api/meta`）就按现在重新生成，服务器重新启动、App 自己接上，两三秒；小组件不触发。手机上第一次看到演示数据时发现的：原来停着过一天，「今天」那页是空的

**App**

- 演示数据时日历不读这台手机的，待办卡里放演示的日程（`CalendarLink.useDemo`、`loadDemo`）；换了真实 / 演示数据，看过的日程都不留着
- 演示数据时不排系统通知（你自己已经排好的照常响）；接上健康、接上日历的小卡不出现；换了数据小组件、锁屏马上重新拿
- 设置 → 数据里的说明：「一个产品经理连续 9 周的生活……每次切过来都生成到此刻；演示时不发提醒和推送，待办里的日程、健康的数据也是演示里那个人的，你的不会露出来」

**顺手修的**（演示里看到的，真实数据也一样会遇到）

- 目标「每天走 8000 步」写成「实际 4992.5 步 · 差 3007.5 步」：上千的数不带小数（服务器 `fmtNum`、App `Show.fmtNum` 同一个规矩）
- 画布上目标小卡右上角「今天 3946…」被截断：放不下一行时字缩小一点

## 怎么用（给产品主人）

- 要给别人看：画布左上角菜单 → 设置 → 数据 → 「切换到演示数据」（每次切过去都是到此刻为止的最新一天）
- 看完：点画布最上面的「演示数据 · 回到真实数据」（或者设置 → 数据 → 回到真实数据）。演示时说的话记在演示数据里，不进你的真实数据；下次切过去会重新生成
- 一直停在演示数据也行：第二天打开 Pour 会自己按新的一天重新生成（前一天演示时说的话随之清掉）；同一天里想补到此刻，设置 → 数据 →「重新生成」
- 演示时你自己的提醒和推送暂停（服务器在演示模式），手机上已经排好的提醒照常响；演示完记得切回来
- 演示「夜里自动检查」：菜单 → 回顾 → 昨天那篇，最下面查出「下午三点记成了凌晨 3 点」，点「确实错了」就改好（画布上昨天的「开会」会从 3:00–4:00 变成 15:00–16:00）
