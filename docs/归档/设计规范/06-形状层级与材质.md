# 06 形状、层级与材质

> 原则：**层级靠表面的明暗区分，不靠阴影**；系统的浮动控件用 Liquid Glass，内容一律是实的。

## 1. 圆角

全部用**连续圆角**（苹果的平滑曲线，不是普通圆弧）。

| 令牌 | 值 | 用在 |
|---|---|---|
| `radius.xs` | 3 | 荧光高亮、心情像素 |
| `radius.sm` | 8 | 卡片里的小块（骨架占位、迷你图） |
| `radius.md` | 12 | 输入框、分段控件、图片缩略 |
| `radius.lg` | 20 | 卡片、列表组 |
| `radius.full` | 胶囊 | 按钮、胶囊标签、倾倒栏（单行时） |
| 面板 | 系统 | 弹出面板（系统的圆角，随设备屏幕圆角变化） |

**同心圆角**：里面元素的圆角 = 外面的圆角 − 两者之间的间距（卡片圆角 20、内边距 12 → 里面的块 8）。算出来小于 8 的一律取 `radius.sm`（8），太小的圆角看起来像直角、反而不协调。卡片套卡片不再加阴影和描边。

## 2. 层级

| 层 | 是什么 | 亮色 | 暗色 |
|---|---|---|---|
| 0 底 | 页面 | `canvas` 纸 | `canvas` |
| 1 卡 | 卡片、列表组 | `surface` 白，**无阴影、无描边** | `surface` + **1 点描边**（`line`，白 10%） |
| 2 浮 | 菜单、弹出层 | 系统材质和阴影 | 系统材质 |
| 3 玻璃 | 标签栏、工具栏、倾倒栏、浮动按钮、轻提示 | Liquid Glass | Liquid Glass |
| 遮罩 | 面板背后 | `scrim` | `scrim` |

- 亮色的「纸」和「卡」靠白和米白区分，不用线、不用阴影——干净
- 暗色模式表面越往上越亮（底 → 卡 → 浮），这是暗色的通例

## 3. 描边和虚线

| 场景 | 样子 |
|---|---|
| 列表分割线 | `line`，1 像素 |
| 输入框 | `lineStrong`，1 点；聚焦时 `action` 1.5 点 |
| 暗色卡片 | `line`，1 点 |
| 待确认 | `lineStrong`，1 点**虚线**（实 4、空 3） |
| 没记心情的日子 | `lineStrong`，1 点虚线空格 |
| 其他 | 不加描边 |

## 4. 阴影

- **内容不用阴影**（卡片、按钮都没有）
- 只有系统的浮层（菜单、弹出层、拖动中的卡片）用系统阴影

## 5. Liquid Glass（iOS 26 起的系统材质）

**用在**：标签栏、导航栏和工具栏的按钮、倾倒栏、浮动按钮、轻提示和撤销条、系统面板。全部用系统提供的玻璃效果。

**不用在**：卡片、列表、图表、任何内容区——内容一律是实的（宪法第七条）。

| 规矩 | 怎么做 |
|---|---|
| 不染色 | 玻璃不染青、不染领域色；墨色的主要按钮放在玻璃上时用系统的「突出」玻璃样式，着色为 `action` |
| 会变形的一组放进同一个容器 | 倾倒栏里「话筒 ↔ 发送」切换时用玻璃的融合变形 |
| 文字可读 | 自己放在玻璃上的文字（倾倒栏里的字）用 `ink`；iOS 27 用户可以把玻璃调到「更透明」或「更有色调」，两种都要截图检查 |
| 减少透明度 | 系统设置打开时，玻璃自动变成实色 `surfaceRaised`（系统处理 + 自定义玻璃要跟着处理） |
| 不叠玻璃 | 玻璃上不再放玻璃 |
