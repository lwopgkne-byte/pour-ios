# 07 动效与触感

> 原则：**动效表达因果和去向**——东西从哪来、到哪去、发生了什么。不炫技、可打断、能关掉。触感是动效的另一半：每个有意义的结果都能「摸」到，但一次操作最多一下。

## 1. 令牌

| 时长令牌 | 值 | 用在 |
|---|---|---|
| `motion.instant` | 0.1 秒 | 按下的回应 |
| `motion.fast` | 0.2 秒 | 小元素出现、消失、切换 |
| `motion.standard` | 0.3 秒 | 大多数过渡 |
| `motion.emphasized` | 0.45 秒 | 图表生长、展开 |
| `motion.signature` | 0.7 秒 | 只有「倾倒 → 凝结」（不含等 AI 的时间） |

| 弹簧令牌 | 手感 | 用在 |
|---|---|---|
| `spring.snappy` | 快、不回弹 | 按下、开关、切换 |
| `spring.smooth` | 稳、不回弹 | 绝大多数过渡、列表增删、面板 |
| `spring.lively` | 带一点点回弹 | **只用于**收据凝结完成落定的那一下 |

单个过渡不超过 0.45 秒；全部可以被新的操作打断。

## 2. 每种交互的动效

| 交互 | 动效 |
|---|---|
| 按下按钮、卡片 | 缩到 0.97、`motion.instant`；松手 `spring.snappy` 回来 |
| 页面前进后退 | 系统导航动画（不自定义） |
| 点卡片进详情（发现卡、一天、一样东西） | 系统的**缩放过渡**：从卡片放大成页面，返回时缩回原位 |
| 弹出面板 | 系统面板动画 |
| 切换标签 | 系统（不加自定义动画） |
| 列表新增 | 淡入 + 从下方 8 点移入，`spring.smooth` |
| 列表删除 | 高度收起 + 淡出，`motion.fast` |
| 数字变化 | 逐位滚动（系统 `numericText`） |
| 加载占位 | 微光从左到右扫过，1.2 秒一圈 |
| 心情像素出现 | 按日子顺序淡入，每格间隔 8 毫秒，总长不超过 0.4 秒 |
| 图表出现 | 柱子从底部长出、线从左往右画，`motion.emphasized`，柱间隔 20 毫秒 |
| 轻提示、撤销条 | 从下方 12 点滑入 + 淡入，`spring.smooth`；消失反过来 |
| 出错 | **不抖动**（不礼貌）；用文字说明，配错误触感 |
| 下拉刷新 | 不需要（数据在本机） |

## 3. 招牌动效：倾倒 → 凝结

把产品理念演出来：你倒出一段话，它凝结成结构。

| 时刻 | 画面 | 触感 |
|---|---|---|
| 0 毫秒 | 按发送 | 轻冲击 |
| 0–250 | 文字从倾倒栏升起、缩小，落进「今天」时间轴的位置（同一个元素的位移变形） | — |
| 250 | 原话就位，下面出现两行微光占位，旁边小字「整理中」 | — |
| （等 AI） | 超过 2 秒：小字变「还在整理」；超过 15 秒：「网络慢，整理好了会自己出现」，可以离开 | — |
| 收到结果 0 | 微光淡出 | 成功 |
| 0–300 | 卡片逐张出现：透明 → 不透明、0.96 → 1 倍、下移 6 点归位，每张间隔 40 毫秒，最后一张用 `spring.lively` 落定 | — |
| 300–1500 | 每张新卡片的 `qingSoft` 底色淡出（「刚凝结的」高亮） | — |
| 没整理成 | 微光停止，原话下面一行「没整理成 · 再试一次」 | 错误 |

总长（不含等 AI）不超过 0.7 秒加逐张间隔。

## 4. 减少动态效果

系统设置「减少动态效果」打开时：

| 原来 | 换成 |
|---|---|
| 位移、缩放、变形 | 淡入淡出（0.2 秒） |
| 缩放过渡 | 淡入淡出 |
| 逐张、逐格出现 | 一起出现 |
| 微光扫过 | 静止的占位块 |
| 数字滚动 | 直接换 |
| 刚凝结的淡出 | 静止的浅底 2 秒后消失 |

## 5. 触感

| 时刻 | 触感 |
|---|---|
| 发送 | 轻冲击 |
| 收据凝结完成 | 成功 |
| 没整理成、出错 | 错误 |
| 开始录音 | 中冲击 |
| 上滑取消录音 | 警告 |
| 切换、选择、拖动排序吸附 | 选择 |
| 在图表上拖动经过数据点 | 选择（每秒最多 15 次） |
| 长按出菜单 | 系统默认 |
| 开关 | 系统默认 |

**规矩**：一次操作最多一下；滚动时不响；跟随系统的「系统触感」开关；不用声音。
