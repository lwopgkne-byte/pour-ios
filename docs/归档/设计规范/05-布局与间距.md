# 05 布局与间距

> 原则：**用间距分组，不用线**（格式塔：接近）。间距只取令牌里的几档；常用的操作在拇指够得着的地方（Fitts）。

## 1. 间距令牌

基数 4 点。

| 原始 | `space.1` | `space.2` | `space.3` | `space.4` | `space.5` | `space.6` | `space.8` | `space.10` | `space.12` | `space.16` |
|---|---|---|---|---|---|---|---|---|---|---|
| 点 | 4 | 8 | 12 | 16 | 20 | 24 | 32 | 40 | 48 | 64 |

| 语义令牌 | 值 | 用在 |
|---|---|---|
| `space.inline` | 6 | 图标和文字之间（例外：6 点是 SF Symbols 和文字的标准间距） |
| `space.tight` | 4 | 标题和它的副标题之间 |
| `space.related` | 8 | 一组里相关的元素之间（一行里的标签） |
| `space.element` | 12 | 卡片和卡片之间、列表组之间 |
| `space.card` | 16 | 卡片内边距 |
| `space.group` | 24 | 一节里的两组之间 |
| `space.section` | 32 | 节和节之间 |
| `space.page` | 20（屏宽 ≥ 390 点）/ 16（屏宽 ≤ 375 点） | 屏幕左右边距 |
| `space.pageEnd` | 64 | 标签页最后一段内容到底部浮动栏（标签栏、倾倒栏）之间。浮动的玻璃栏往上有一段投影（M1 截图实测：亮色约 24 点、暗色约 36 点），最后一条要完整地停在投影以外，看着也不贴着栏 |

## 2. 尺寸

| 东西 | 尺寸 |
|---|---|
| 可点范围 | **至少 44 × 44**（看起来小的胶囊、分段按钮用透明区域补够） |
| 列表行 | 一行 52；两行 64 |
| 按钮 | 大 50、常规 44、小 32（小按钮的可点范围仍补到 44） |
| 倾倒栏 | 收起 52；输入时随内容长到 6 行，之后内部滚动 |
| 胶囊标签 | 看起来 32 高，可点 44 |
| 色点 | 领域色点 8；时间轴的色点 10 |
| 心情格 | 日历 32；像素墙 14（间隔 3） |
| 内容最大宽度 | 600（iPad 上居中；iOS 27 起 iPhone 应用在 iPad 上会自动缩放显示） |

## 3. 版面

- **单列为主**；只有「换个角度」的四张小卡是两列（间隔 12）
- 标签页：大标题 → 8 → 页面摘要（一行）→ 32 → 第一节
- 详情页：小标题（导航栏里）→ 内容从 16 开始
- 对齐：文字左对齐；**数字右对齐**；同一行不同字号按基线对齐
- 第一屏要回答页面的问题：「今天」在 iPhone 13（默认字号）上第一屏看得到——标题、一句话总结、目标进度、至少 4 条时间轴

## 4. 拇指区（单手握持）

```
┌──────────────────┐
│ 只看：标题、日期   │  上三分之一：信息，少放按钮
│                  │
│ 看和点：内容、卡片 │  中间：内容
│                  │
│ 常点：倾倒栏、标签 │  下三分之一：最常用的操作
└──────────────────┘
```

- 倾倒栏、标签栏、主要按钮都在下三分之一
- 设置等低频入口放右上角（头像）
- **危险操作不做成常驻按钮**：放在菜单或面板里，离常用操作远

## 5. 键盘

- 倾倒栏贴在键盘上方，间隔 8；内容区自动让出键盘和倾倒栏的高度
- 往下拖内容可以把键盘一起收起（交互式收起）
- 键盘弹起时当前的输入目标不被挡住
- 中文输入法打字时（有拼音候选，即「标记文字」）不触发任何自动操作（不发送、不搜索、不改高度跳动）

## 6. 列表

- 记录、钱、原话这类内容用**自己的懒加载列表**（性能和样式可控）；设置用系统的分组列表（大家熟悉）
- 分割线只在列表里用：`line` 色、1 像素，从文字起点开始（左边让出图标）
- 列表组用卡片承载（`surface` + 圆角 20），组和组间隔 12
