# 11 深色、无障碍与适配

> 原则：深色模式是**重新设计**的一套，不是把颜色反过来；系统的每个辅助设置打开时，Pour 都要正常好用。

## 1. 深色模式

| 规矩 | 怎么做 |
|---|---|
| 表面越往上越亮 | 底 `#0C0B0A` → 卡 `#1A1917` → 浮 `#21201E`（01） |
| 卡片加描边 | 暗色卡片 1 点 `line`（白 10%），亮色不加 |
| 颜色换档，不是同一个色 | 青用 `qing.300`、领域实色用暗色那一列、琥珀用 `amber.300`（01 已经给出每个令牌的暗色值） |
| 心情五档反过来 | 暗色下心情越好越亮（`qing.900` → `qing.300`） |
| 不用纯黑纯白 | 底 `#0C0B0A`、字 `#F6F4F0`：长时间看不刺眼，滚动时不拖影 |
| 图片和图表 | 图表跟随令牌自动换；以后的照片不调暗 |
| 跟随系统 | 默认跟随系统；设置里可以固定亮或暗 |

## 2. 系统的辅助设置

| 设置 | Pour 怎么跟 |
|---|---|
| **动态字体**（最小到 AX5） | 所有文字跟随；AX 档时：两列变一列、行内的「标签 + 数值」变上下两行（组件 `PourTitleValueRow`）、时间轴的时间列移到卡片上方、一组胶囊和按钮放不下就换行（`PourFlowLayout`）、图上方格子里放不下的标注改到图上方一整行；不截断、不重叠、能滚动。**放字的地方不用固定宽度、固定偏移**（M1 自验收：固定 64 点宽的「这些日子」在 AX5 被挤成一个字一行；用固定偏移盖在右上角的「待确认」压住了内容）——要对齐就用 `Grid` 或跟着字号变的宽度（`@ScaledMetric`） |
| **旁白（VoiceOver）** | 每个元素有名字；卡片读成一句话，改、删做成自定义操作；图表先读结论再读数据；顺序和视觉一致；收据凝结时播报「记下了 3 件事」 |
| **增强对比度** | `inkSecondary` 加深一档、`line` 加倍、领域实色加深一档、玻璃变得更实（系统） |
| **减少动态效果** | 07 第 4 节 |
| **减少透明度** | 玻璃变实色 `surfaceRaised`（06 第 5 节） |
| **粗体文本** | 跟随系统（系统字体自动加粗） |
| **按钮形状** | 文字按钮加下划线（系统） |
| **差异化而非仅颜色** | 本来就不只靠颜色：领域有名字、心情有说法、待确认有字 |
| **语音控制** | 每个按钮的名字就是它显示的字，说「点 发送」能用 |
| **切换控制、全键盘控制** | 焦点顺序合理，焦点环用 `focusRing` |

**验收**：每个模块跑一次自动无障碍审计（0 问题，`scripts/check.sh --full` 一屏一屏地审）+ 一次旁白全程走查 + **AX5 截图逐张看**（审计查不出挤成一个字一行、标注折开这类版面问题，M1 是看截图发现的）。

## 3. 屏幕和设备

| 情况 | 怎么做 |
|---|---|
| iPhone 宽度 375–440 点 | 两种宽度都截图审查；375 点边距 16、其余 20 |
| 竖屏 | 第一版 iPhone **只做竖屏**（记录和阅读都是竖着的，少一倍的布局要维护） |
| iPad | 第一版用 iPhone 布局运行（iOS 27 起系统会自动缩放显示）；内容最大宽度 600 |
| 动态岛、刘海、圆角 | 遵守安全区；招牌动效不碰动态岛区域 |
| 不同语言（以后） | 文字全部进 String Catalog；按英文比中文长 30% 预留空间 |

## 4. 安卓的对应（以后做安卓时用）

宪法十二条原样适用；令牌值不变，对应到 Material 3：

| iOS | 安卓（Material 3） |
|---|---|
| `canvas` / `surface` / `surfaceRaised` | surface / surfaceContainerLowest / surfaceContainerHigh |
| `ink` / `inkSecondary` | onSurface / onSurfaceVariant |
| `action` | primary（墨色）|
| `qing` / `qingSoft` | tertiary / tertiaryContainer（「懂你」） |
| `attention` / `critical` | 自定义 / error |
| Liquid Glass 浮动控件 | 色调层级（tonal elevation）的底部栏和导航栏 |
| 标签栏 + 搜索 | NavigationBar + SearchBar |
| SF Symbols | Material Symbols（圆角风格、粗细对应） |
| 动态字体 | 系统字号缩放（sp） |
| 苹方 / 宋体 / SF Pro Rounded | 思源黑体 / 思源宋体 / Google Sans Flex 圆角 |
| 触感表 | HapticFeedbackConstants 按同样语义对应 |
