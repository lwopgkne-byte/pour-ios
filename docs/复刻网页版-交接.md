## 3. 做一个页面的步骤

1. **读网页版**：`~/Developer/pour/web/src/pages/<页面>/`（tsx 和 css），用到的数据类型在 `~/Developer/pour/shared/src/`，接口在 `~/Developer/pour/web/src/lib/queries.ts`
2. **接口和数据**：在 `PourAPI/` 加一个文件（比如 `Money.swift`）放这一页的数据类型（照 shared 的类型一字不差）和 `APIClient` 的方法
3. **测试**：从演示服务器拿真的回复存成 `Tests/PourAPITests/Fixtures/<名字>.json`（`curl -s 127.0.0.1:5199/api/... | python3 -m json.tool --no-ensure-ascii`），写解码测试
4. **界面**：`App/Sources/<页面>/` 下照网页版写 SwiftUI，只用 `Web.xxx` 令牌和 `Show.xxx` 写法；手机那一档（网页版 css 里 `max-width: 767px`、`pointer: coarse` 的规则）为准
5. **在 `Pages.swift` 里换掉那一页的 `LaterPage`**
6. **对照**：网页版截图（`node scripts/web-shot.mjs <路径> <名字>`，iPhone 15 的尺寸，存在 build/web-shots/）和 iOS 截图（`AppUITests/WebDemoShots.swift` 加这一页，`TEST_RUNNER_POUR_SHOTS=1` 跑，连 5199 演示数据）并排放，一处一处对齐
7. **检查**：`swiftlint lint --strict`、`xcrun swift-format lint --strict -r ...`、`swift test`、这一页的界面测试（假服务器 `App/Sources/StubServer.swift` 里加这一页的接口）
8. **提交**：说清楚照网页版的哪个文件做的；结尾带 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
