## 二、做法（每一步都一样）

1. **开分支**：从最新的 `main` 开 `feature/3.0-step<N>-<名字>`（App 在 `~/Developer/pour-ios-3`，服务器在 `~/Developer/pour-3`，第 0 步建好）
2. **小方案**：`docs/3.0/步骤/第N步.md`，写这一步做哪几项、改哪些文件、怎么验；产品主人不看方案，自己决定
3. **先服务器**：接口和规则 → `npm run check` → 改了 AI 规则跑评测 → 演示数据补上 → `npm run demo:check`
4. **再 App**：照 06 交互细节和可交互原型；只用设计系统 3.0；把这一块原来的 `Web*` 页面删掉
5. **自验收**：[04 验收标准](04-验收标准.md) 逐条过；附录 A 里这一块的对照表；`scripts/tour-shots.sh` 出改之前、改之后的截图
6. **验收申请**：写进 [进度.md](进度.md)，开合并请求（标签 `验收`）
7. **装到手机**（只有开发账号做）：服务器先升级 5188（重启前备份 `~/Developer/pour-phone-data/pour.db*`，照服务器 CLAUDE.md）→ `scripts/install-device.sh` → 用大白话告诉产品主人看哪里
8. **不用等验收就接着做下一步**；设计账号验过、挡发布的问题修完，再合并进 `main`、打标签
9. 每次开工先看 GitHub 上标签 `3.0` 的问题，有 `挡发布` 的先修

**一直要遵守的**：00 提示词第 10 节（密钥、个人数据、高风险先问、不用 `--no-verify`、「今天先到这」= 检查 → 提交 → 推送）。
