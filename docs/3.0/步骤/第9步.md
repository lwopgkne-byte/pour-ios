## 现在是什么样、要变成什么样

内容都有（第一期照网页搬的，`Web.*` 的样子）：笔记库能搜（关键词 + 按意思）、按时间 / 类别 / 人筛，每段原话下面是整理出的记录和状态，能改、能删、能重试；搜索是画布上盖的一层；对话面板有收据和撤销；一条记录是从底下滑出的详情。原型：笔记库按天分组的卡片、组头吸顶「今天 · 10月27日 周二　看这一天 ›」，原话宋体最多两行、下面最多两个胶囊，左滑删除 / 重新整理、按住出菜单，筛选是一个弹层（带条数）；搜索是一页（可以这样问、最近搜过，输入时按组出结果）；对话的收据、追问的现成回答、快捷胶囊；一条记录哪里点都是同一个弹层。

## 做什么、按什么顺序

| 段 | 内容 | 07 |
|---|---|---|
| A 笔记库 | 系统列表（左滑删除 · 重新整理、按住：复制 · 改原话 · 看这一天 · 看整理出的），按天分组吸顶的卡片；原话 · 好时刻；搜索框；筛选弹层（时间、类别、人、状态，带条数）→ 胶囊 + 清除筛选；待确认 / 处理失败；展开后「回答一下 · 重试 · 修改原话 · 看这一天 · 删除」；点小胶囊开那条记录；「意思相近」 | 9.1、9.3a |
| B 搜索页 | 画布右上角进；没输入时「可以这样问」「最近搜过」；输入时分组（回答带来源和图、原话、记录、感悟、目标、日子）；「查看完整报告」 | 9.2、9.3a |
| C 对话 | 收据换成新组件（带撤销，「推进了目标 / 新建了类别 / 记住了」）；来源编号能点；图用 Swift Charts；快捷胶囊；追问带现成回答；加载更早的；补记「记到哪天」；没整理成 + 重试；没网先存 | 9.3、9.3a |

| E 服务器 | 按意思搜：关键词和意思一起排（短问法分不开的问题），拿演示数据量过再定门槛；筛选弹层的条数 | 9.3b |
| F 验收 | 附录 A「笔记库」「搜索、问答、对话」逐条；装到手机等第 10 步做完 | 9.4 |
