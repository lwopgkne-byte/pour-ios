## 几个决定（[ADR A28](../../ADR/A28-钱.md)）

- **主页一次拿全**：以前主页要拿月份、总览、发现三次，现在 `GET /api/money/home` 一次；数字全部是服务器现算的，手机只照着画
- **记一笔记下的是一句原话**：数字键盘拼出「午饭 25」「打车 58 能报销」「借给小王 500」「工资 18500 收入」，走和说一句同一条整理的路（原话是唯一的源头）；整理完以前先显示「整理中」那一行
- **一天的钱还是推进来的一页**（01 写的是弹层）：第三版原型把「那天的事」放到了主页月历下面（点一天就看到），「那天 ›」进来的这一页要能再点开一笔的详情（弹层上再弹弹层，系统不好管），所以留成一页，右上角 ‹ › 到前后有钱的日子
- **每一笔的搜索框放在大标题下面**：iOS 26 起搜索框默认在屏幕底部，正好被「说一句」挡住；搜的时候「说一句」让开，键盘上面只有一个输入框
- **打开钱要面容 ID 只记在这台手机上**：验过一次这次打开 App 都算数，退到后台再回来重新验；手机没设密码时锁不了（设置里写明）

## 做的时候查出来、改掉的

- 数字键盘记的一笔：服务器整理完以前，大数、月历那一格、那天的每一笔先加上（「整理中」），整理完换成正式的；撤销时一起拿掉
- 一笔的详情用假服务器时一片空白（详情去拿整条记录，假服务器那一天没有这一条）：拿不到整条记录时先用这一笔自带的（服务器算好的）
- 每一笔：搜索框在屏幕底部被「说一句」挡住 → 放到大标题下面；搜的时候组头写的是搜到的几笔的和 → 改写那天一共花的（和月历一样）；摘要和筛选胶囊重复写笔数 → 摘要只写这个月一共、筛选时写「这些 N 笔，一共 ¥X」
- 长按「改金额」进详情，点「好」闪退：输入框绑的是 `Binding($金额)` 解开的那一份，改完变回 nil 时强行解开；改成普通的绑定（`MoneyEachUITests.testLongPress` 守着）
- 留意的里借出去那一行：原话、过去几天单独是一个读屏元素，这一行能左滑，审计当它们能点、嫌太小 → 名字、钱、原话、过去几天读成一句，「已经还了」照旧单独
- 「一样东西」买的那天那一行：审计说大字号下可能被截（这行没有行数上限，放不下就换行）→ 竖着能长高、标「能折行」
- 月尺上「今天」那根蓝线压到当天要扣的那一样的名字 → 蓝线从线往下画，指着下面的「今天 20 日」
- 月历下面「那天的事」一开始不出来：挂在空的 `Group` 上的 `.task` 不跑 → 换成 `VStack`
- 日子里被加了空格（「10 月 27 日」，别处是「10月27日」）：中文和数字之间留空（`Show.spaced`）只给你说的内容（名字、原话）；服务器写好的句子原样显示（服务器自己在数字两边留好了空）
- 连 5288 截全部页面时看出来：主页「每个月固定的」那张卡的月尺是另一种画法 → 和「留意的」用同一把（`MoneyMonthRuler`），以前的月份不画「今天」；新用户、以前的月份的说法；没有上个月的线时图例还写「上个月同日」
- 验收第 4 条「刚开始用 3 天」演示数据造不出来（演示数据从 8 月底开始）：假服务器加了启动参数 `-moneyEarly`（10月18日才开始记）；新用户连一台临时起的空服务器（临时目录，截完删掉）
- 旧的钱的页（月份、留意的、固定的、人情、一样东西、一天）和只有它们用的部件删掉；「关于我」还在用的几样旧部件搬到 `About/AboutLegacyParts.swift`，`Money/` 整个目录不再有 `Web.`（SwiftLint 管着）；从钱里点开固定的那一笔多一行的 `FixedPay` 不再需要（固定的有了自己的详情）
