## 几个决定

- **还没做的页先去最近的地方**：待办页第 2 步才有，这一步「待办」格子回到画布的待办卡；心情 → 关于我 · 心情；感悟 → 笔记库 · 感悟；好时刻 → 笔记库 · 好时刻；坚持、预算 → 目标；健康 → 设置 · 健康；日历 → 跳到某一天；值不值 → 钱；新发现 → 关于我。做到那一步就换成正式的页
- **日期按钮**：点一下照旧展开这一周（08 功能核对：画布不改），展开的一周条右边多一个「跳到某一天」；日历页第 10 步做
- **旧页面的标题**：系统导航栏写这一页的名字（返回按钮用它），页面里原来的大标题先留着，重做那一块时换成系统的大标题
- **链接**：`pour://open?path=` 从外面打开时，画布在最底下、只推那一页；页面里点的链接接着往里推

## 做的时候查出来、改掉的（2026-10-31）

- **画布顶上那一行放进系统的导航栏工具栏**（07 1.5 本来就这么写）：原来是自己盖在画布上的一层，长按菜单用过以后那一层里的按钮（「我」、搜索）一直点不动，要画布重画一次才恢复。系统的工具栏和画布内容是分开的两层，不受影响。界面测试 `ShellUITests.testTopBarAfterContextMenu` 守着
- **每一页底下给「说一句」留出位置**：底部那一整块（轻提示、整理到哪的小条、输入框）挂在导航栈外面，系统不会替里面的页留位置，滚到底最后一行压在它下面、点不到（画布上的「接上日历」、「我的」最后的「设置」）。现在量出它的高度，每一页底下留同样高（`sayBarSpace`）。`ShellUITests.testLastRowAboveSayBar` 守着
- **点「说一句」展开对话，键盘不掉**：对话展开时输入框外面的玻璃、裁圆角是两个不同的视图，切换时输入框被系统重建、焦点丢了，接着打字打不进去。改成同一个视图换参数（玻璃有「透明」这一档）
- **被盖住的页对读屏藏起来**：搜索、对话开着时，后面压暗的页原来在导航栈外面设的「藏起来」传不进去；改成加在每一页自己身上
- **半宽的卡片**：标题、「3 笔」、「＋ 记一笔」挤不下，「钱」字被挤没了；半宽的右上角只放一个「＋」（心情卡的「AI 推测」一直留着）
- **小字按钮能点的范围**：「重试」这类按钮外面加的尺寸不算数，点得到的只有那两个字；新组件 `ThemeTextButton` 把 44 点撑在按钮里面，输入框上面、对话里、画布上的「重试」都换了
- **心情页「烦躁 5」**：数字淡了一档，在黄底上对比度不够，和字一个颜色了
- 界面测试的帮手：去一页走「我」（`openTile`）、返回（`goBack`）、滚到整个露出来（`reveal`：在导航栏下面、在底部那一块上面，拖三分之一屏、没有惯性）；审计不量导航栏、屏幕底边淡出的那一截、被对话面板边裁掉一半的字
- 第 0 步验收时那个早就有的问题（「关于我」里恢复不再显示的名字）：测试滚到「恢复」整个露出来再点，过了
