## 几个决定（[ADR A35](../../ADR/A35-设置反馈小组件.md)）

- 设置用系统的分组列表；每一组的内容沿用原来那几块（`ReminderSettings`、`LlmSettings`……），点一行推一页
- 反馈的截图在点「反馈」那一刻截（「我的」这一页），在哪一页写打开「我的」以前的那一页
- GitHub 令牌和别的密钥一样只能在电脑上填、只给打码的；App 不经手
- 「记一笔」「记心情」的 Siri 打开 App；「今天还有什么待办」不打开 App

## 做的时候查出来、改掉的

- **设置第一屏放不下全部分组**（一行默认 74 点高）→ 一行 44 点、组和组之间紧一点、健康和日历合成一页、局域网访问放进电脑上的 Pour、版本写在最后一组下面
- **组名的系统灰在这个底上对比度不够**（审计）→ 用主题的第二层字色
- **反馈里「我的」这一页的 `UIImage`**：一页文件超过 400 行 → 那个小类型搬进反馈的文件
- 两个界面测试同时跑把模拟器上的测试进程挤掉了（「signal kill」）→ 一次只跑一组
