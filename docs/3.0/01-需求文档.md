## 1. 背景、问题、目标

### 1.1 现在

生活画布 2.0 已经是 iPhone 的样子；其余的页面是 2026-10-20 从网页版 1 比 1 搬过来的，功能很全（钱、心情、关于我的深度在同类产品里少见），但**用起来是一个装在手机里的网页**。

### 1.2 现在的问题（2026-10-27 在模拟器上逐页截图、逐页用过）

**整体**
| # | 问题 | 在哪看到 | 为什么要紧 |
|---|---|---|---|
| P1 | 换一页要点左上角菜单、再点一项；没有「返回」的感觉（左上角是一行小字「‹ 钱」） | 每一页 | 用得越多越烦；不像 App |
| P2 | 每一页都是一长条文档：回顾 12 屏、周报 12 屏、关于我 10 屏、设置 12 屏、心情 8 屏 | 回顾、关于我、设置 | 找不到东西；最有用的埋在中间 |
| P3 | 三套样子混着：画布是暖灰底白卡片，别的页是白底细线，还有米色卡片；图表四五种画法；图标一会儿是 emoji 一会儿是线条 | 全部 | 「不精致」的根源 |
| P4 | 网页式的操作：蓝色文字链接当按钮（「看这一天 →」「全部 ›」「试一下」）、「···」菜单、改时间要打字「10:00」 | 笔记库、设置、详情 | 点不准、不顺手 |
| P5 | 详情是一张表：「开始 没说 / 结束 没说 / 时长 没说 / 给谁 没说……」 | 点一笔钱、一条记录 | 一屏全是「没说」，真正的内容看不到 |
| P6 | 底部输入框浮在每一页上，盖住最后几行 | 每一页 | 最后一条点不到 |
| P7 | 每一块下面都有一两行灰色小字解释（「只统计说了时长的事……」「前后两段都是这样 · 只是同时出现……」） | 关于我、钱、心情 | 诚实，但满屏都是说明 |
| P8 | 设置里摆着开发用的数字：「分类 99.7% · 时间 100%」「通用 365 句 · 你个人的 0 句」「这周 AI 追问 0 → 2 → 0」 | 设置 | 给普通人看是噪音 |
| P9 | 出错时写「看不懂服务器的回复：未能读取数据，因为数据丢失」 | 钱（2.8.2 已修根因） | 用户不知道该怎么办 |
| P10 | 演示数据时每一页顶上一条黄色横幅 | 全部 | 占地方、像警告 |

**高频的四块**
| # | 问题 |
|---|---|
| T1 | **待办没有自己的页面**：只在当天的画布上；以后的、以前没做完的要翻日子找 |
| T2 | **提醒不可靠**：只有 App 打开过那一天、看到过那条待办，才会排提醒——说「下周三提醒我」，这几天没翻到下周三，到点不响 |
| T3 | 通知上没有「完成」「稍后提醒」；改提醒时间要打字；没有重复的待办 |
| M1 | 钱只能说话记：地铁上、会议里不方便开口，打一整句又慢 |
| M2 | 钱的主页是一长条，留意的、花在哪、花给了谁、值不值、钱和你的日子挤在一起；每一笔不能左滑办事 |
| E1 | **心情没有自己的入口**：心情页藏在「关于我」里面；没有「现在心情怎么样」一点就记的地方 |
| E2 | 心情页全是分析图（像素格、柱子、折线、表格），看不到今天的那几刻 |
| I1 | **感悟没有自己的入口**：在笔记库的第二个标签里，一行行小字 |
| I2 | 感悟记下就沉底了：没有收藏、没有重温、不能做成一张好看的卡片分享 |

### 1.3 目标

1. **一线 App 的手感**：系统导航、底部弹层、滑动操作、长按菜单、搜索、日期选择、触感、动效；每个操作 100 毫秒内有回应
2. **高频的四块，每天用十次也不烦**：待办两步内加上、一步完成、一定会响；钱 3 秒记一笔；心情 1 秒记下；感悟记下以后还会再见到
3. **一套精致的样子**：只用设计系统 3.0；每一页都能和 Apple 自带 App、Things、微信、支付宝的同类页面放在一起不掉价
4. **能力只增不减**：附录 A 的每一项都还在

### 1.4 怎么算做到了（产品主人在手机上能感受到的）

| 指标 | 现在 | 3.0 |
|---|---|---|
| 从首页到钱、待办 | 2 次点按（菜单、再点） | 1 次（点画布上的卡片） |
| 加一个「明天下午三点取快递」的待办 | 说一句、等 AI 3–5 秒 | 说一句照旧；或者待办页「+」打字，**打字时就看到「明天 15:00 提醒」**，1 秒加上 |
| 记一笔「午饭 25」 | 说一句（不方便开口时要打整句） | 「记一笔」数字键盘：点 2、5、选「午饭」，3 秒 |
| 记一个心情 | 说一句 | 「我的」或小组件上点一下五档里的一个，1 秒；想说原因再说 |
| 待办提醒 | 只排看到过的那几天 | 所有定了时间的都排上；通知上能完成、能稍后 |
| 打开一页 | 每次转圈等服务器 | 先出上次的内容，再无声刷新 |
| 页面长度 | 回顾 12 屏、设置 12 屏 | 每页第一屏就是最要紧的；长的拆成分段或下一层 |

## 2. 新外壳：画布首页、说一句、「我」全部功能

> 一句话（2026-10-28 第四版）：**不要底部标签栏**。打开就是生活画布；底部只有一条「说一句」，和现在一样；左上角「我」进全部功能；待办、钱、心情这些用得多的，从画布上的卡片直接进、直接记。
> 产品主人 2026-10-28：「1 不要底部操作栏，太冗余了，你钱和待办放在我的里面不就可以了嘛，在底部又显示出来，占地方；2 底部只能留语音识别和生活画布，和之前一样，其它的钱、待办全部你自己想办法，参考行业通用标准放在一个合适的地方」

### 2.1 首页和导航

- **首页 = 生活画布**（内容不动）。顶上一排：左边「我」（圆形头像，没有就是「我」字）→ 我的（全部功能，2.3）；中间「今天 · 10月27日 ▾」→ 日历、跳到某一天；右边 🔍 → 搜索（第 12 章，和现在一样在右上角）
- **没有标签栏**。别的页都从首页推进去：左上角「‹ 上一页的名字」、从左边缘右滑返回，一路返回到底就是画布
- **待办、钱怎么最快到**（参考不用标签栏的 App 的通用做法：Apple「手记」首页一条时间线、底部只有一个「+」；Things 3 首页就是今天的列表、角上一个「+」；微信聊天底部只有输入框和语音。共同点：首页就是内容，内容本身是入口，快速记一下的按钮放在内容旁边；苹果的设计规范也说，只有一个主要页面的 App 用导航和工具栏，不用标签栏）：

| 想做 | 怎么做 | 几下 |
|---|---|---|
| 看待办 | 点画布上待办卡的标题「待办 ›」 | 1 |
| 加一件待办 | 待办卡右上角「＋」；或者直接说「明天三点取快递」 | 1 |
| 看钱 | 点画布上的钱卡 | 1 |
| 记一笔 | 钱卡右上角「＋ 记一笔」→ 数字键盘；或者直接说「午饭 25」 | 2 |
| 记心情 | 心情卡右上角「记心情」；或者直接说 | 2 |
| 别的功能 | 左上角「我」→ 点格子 | 2 |
| 不打开 App | 按住 Pour 的图标（说一句 · 记一笔 · 加待办 · 记心情）、小组件、锁屏、控制中心、Siri | 1–2 |

- 画布上只加这三个小按钮（待办卡「＋」、钱卡「＋ 记一笔」、心情卡「记心情」），卡片标题能点进那一块；画布别的内容不改
- **不打红点、不显示数字**（原则「不要让我烦」；Pour 2026-09-30 定的「回顾不显示数量、没有红点」照旧）
- 去掉：左上角的抽屉菜单（换成「我」）；演示数据的黄色横幅（换成「我的」页头上的一个小标签「演示数据」+ 画布顶上现有的「演示数据 · 回到真实数据」胶囊）

### 2.2 说一句（底部只有它，每一页都在）

- 底部一条「说一句」，和现在一样：左边对话记录、中间「说一句……」、右边麦克风；不加别的按钮
- **点中间**：展开成对话（大半屏，往下拉收起），键盘弹起，输入框上方一排快捷：「记到今天 ▾」（补记以前的日子）「问一句」「记一笔」「定目标」「改一下」「找一找」（就是现在的 `/问 /记 /目标 /改 /找`）
- **点麦克风**：直接开始听（现在的语音识别）；**按住麦克风**：按住说、松开发（像微信）
- **往下翻页时**：收起，往上翻再出来，不挡内容（解决 P6）
- 在画布、「待办」「钱」「心情」「感悟」页里，说一句的提示词跟着变：「今天做了什么？比如：跑步 1 小时」「说一句待办，比如：明天下午三点取快递」「记一笔，比如：午饭 25」……说的话照旧走整理（意图识别会看到当前页作为提示，提高准确率——服务器要做的：`POST /api/notes` 接一个可选的 `context: "todos"|"money"|"mood"|"insights"`，只作参考，不强制）
- 生活画布原来的输入框就是这一条

### 2.3 「我的」= 全部功能

**从上到下**（原型「我的」那一屏）：

1. **头**：圆形头像（没有就是「我」字）、名字（多人账号以后才有，现在写「我」）；下面一行「记了 63 天 · 377 段话」；再一行「Pour 认识你：12 个人 · 8 件常做的事 · 5 个地方 ›」→ 关于我。右上角：设置齿轮
2. **四个快捷大按钮**（支付宝首页「扫一扫、收付款」那一排的位置；高频的「记」）：
   - **记一笔**（钱的数字键盘，5.4）
   - **记心情**（五档一点就记，6.3）
   - **记一句**（感悟、语录，7.3）
   - **加待办**（一行字，4.5）
3. **常用**（支付宝「我的收藏」）：最多 8 个格子，一行 4 个；右上角「管理」进编辑：拖动排序、点 ⊖ 移出、在下面全部功能里点 ⊕ 加进来；没管理过时默认：待办、钱、心情、感悟、回顾、目标、笔记库、日历（待办、钱排在最前面）
4. **全部功能**（分组的格子，一组一张白卡片，组名在卡片左上角小字，照微信「服务」）：

| 组 | 格子 |
|---|---|
| 记录 | 待办 · 钱 · 心情 · 感悟 · 健康 |
| 回看 | 回顾 · 日历 · 笔记库 · 好时刻 · 你的一年 |
| 了解自己 | 关于我 · 人 · 你说的话 · 新发现 |
| 钱 | 每一笔 · 留意的 · 固定的 · 人情往来 · 值不值 |
| 目标 | 目标 · 坚持（坚持类的目标：最近 30 天做到几天、补假）· 预算（说过的「不超过」，9.10） |

5. **最下面三行**（列表样式，不是格子）：设置 · 反馈 · 关于 Pour

**格子的规矩**
- 一个格子：SF Symbol 白色图标在彩色圆角方块里（44×44 点，圆角 12）+ 下面名字（最多 4 个字，一行）；一组一个颜色家族，颜色来自类别色板（附 3.1）
- **角上的字**：有要你处理的事才有，安静的灰底小胶囊写数字（「留意的 2」「回顾 新」），**不用红色**
- 点格子：推入那一页，从格子放大进去（系统的缩放转场）；返回回到「我的」
- 长按格子：菜单「加到常用 / 移出常用」
- 搜功能：「我的」顶上下拉出现一个搜索框，搜「报销」能找到「留意的」（每个格子带几个别名）
- 演示数据时，头上名字旁边一个小标签「演示数据」，点了是「回到真实数据」的确认

**服务器要做的**：`GET /api/me/hub`——一次拿全「我的」页的数：记了几天、几段话、认识几个人和事和地方、每个格子角上的数（留意几条、回顾有没有新的、目标有没有落后的）。常用的顺序存在服务器的设置里（换手机也一样）。

### 2.5 导航的规矩

| 打开的是 | 怎么出现 | 怎么回去 |

| 一个功能的页面（回顾、心情……） | 推入导航栈（大标题） | 左上角系统返回、从左边缘右滑 |

## 3. 设计系统 3.0 和交互规范

> 一句话：以生活画布 2.0 为底子，只留一套，每个组件的每个状态都画到。

### 3.1 视觉

| 项 | 规矩 |
|---|---|
| 底色 | 页面暖灰 `#F3F2EF`，卡片白；**和画布一样**（现在别的页是白底，改掉） |
| 文字 | 主 `#1D1C1A`、次 `#58554F`、辅 `#807C75`；正文用系统字体（苹方），**不用灰色小字写大段说明** |
| 强调 | 蓝 `#1B56B3`（可点的、选中的）；好 `#1A683D`、留意 `#7D5500`、不好 `#AA3831`；心情粉沿用 |
| 数字 | 圆体（SF Pro Rounded），大数 34 点，卡片里的数 22 点 |
| 原话 | 宋体（Songti SC），左边一条细线；只有原话、语录用宋体 |
| 圆角 | 卡片 20，格子图标 12，按钮 12 或胶囊；**一页里只有这几种** |
| 阴影 | 卡片几乎看不出的两层（画布已有）；弹层用系统的 |
| 间距 | 4 的倍数；页面左右 16；卡片内 16；卡片之间 12；组之间 24 |
| 图标 | 只用 SF Symbols（分层或调色板渲染）；**不再用 emoji 当图标**（类别的 emoji 留在用户自己建的类别名字旁边，不当图标用） |
| 颜色 | 一个功能组一个色家族（记录：蓝绿、回看：靛蓝、了解自己：粉紫、钱：琥珀、目标：绿）；类别色板沿用 9 色 |
| 深色 | 只有亮色（产品主人 2026-10-21），令牌写法保证以后加深色只改令牌 |

### 3.2 组件（先做进组件库，再用到页面；每个都有全部状态）

| 组件 | 用在 | 状态 |
|---|---|---|
| 分组列表行（图标、标题、副标题、右值、箭头、开关） | 设置、留意、每一笔 | 默认、按下、禁用、加载中、有角标 |
| 待办行（大圆圈、标题、时间胶囊、标签） | 待办、画布、回顾 | 未完成、完成（划线留在原地）、过期、有提醒、重复、来自日历（只读） |
| 钱的行 | 每一笔、一天的钱 | 日常、固定、收入、等报销（灰）、借出、人情、回来的钱、遮住金额 |
| 原话块 | 详情、感悟、回顾 | 普通、高亮一段、展开收起 |
| 功能格子 | 我的 | 默认、按下、有角标、编辑模式（抖动、⊖⊕）|
| 指标块（大数 + 名称 + 和上次比） | 回顾、钱、目标 | 有数、没数（不出现）、遮住 |
| 进度环 | 目标、我在乎的 | 正轨（绿）、落后（黄：落后多的、不可能的也是黄，不用红和灰）、还谈不上（空心）、暂停（浅灰）、完成（满环+勾）、刚定好时转一下；中间写百分比、「2/4」或「26 天」（9.1） |
| 发现卡（一句话、两根横条、依据、四个反馈） | 关于我、钱 | 默认、点过某个反馈、「不对」以后 |
| 图表卡（Swift Charts） | 全部图表 | 有数、数据少（一句话说还差多少）、拖着看数 |
| 筛选胶囊 | 每一笔、笔记库、感悟 | 选中、未选、带数字 |
| 五档心情 | 记心情、心情行 | 五档、选中、按下 |
| 空状态（一句话 + 一个示例按钮） | 每一页 | — |
| 骨架（第一次没缓存时） | 每一页 | — |
| 出错（大白话 + 「再试一次」） | 每一页 | 没网、服务器没开、太旧要更新、别的 |
| 轻提示（带「撤销」） | 所有能撤销的操作 | — |

### 3.3 交互规范

- **100 毫秒内有回应**：按下有按压态和触感；勾待办、标记已报销、改一行：界面先变，再发服务器，失败了退回并说一句
- **触感**：完成待办 `.success`；滑动操作过阈值 `.impact(light)`；选中五档心情 `.selection`；删除 `.warning`
- **动效**：系统弹簧；完成待办：圆圈填满 + 勾的符号动画 + 文字划线（不跳走）；格子进页面：缩放转场；数字变化：数字滚动（`contentTransition(.numericText())`）；「减少动态效果」打开时全部换成淡入淡出
- **能撤销就不弹确认框**：删一笔、删待办、不做了、移出常用——都是轻提示「已删除 · 撤销」；只有注销账号、清空数据这种不可逆的才确认
- **每个手势都有看得见的替代**：滑动能做的，长按菜单和详情里也能做
- **说明文字收起来**：每一块的方法说明（「只统计说了时长的事……」）收进标题旁的 ⓘ，点了用小弹层说；页面上只留结论（解决 P7）。「只是同时出现，不一定是因为它」这种**关键的诚实提示**留在卡片上，但一行、辅助色
- **出错说人话**：「没连上电脑上的 Pour。家里的 WiFi 连着吗？」「这一页暂时打不开，已经记下了，我们会修」（+ 再试一次）；**不出现「服务器的回复」「数据丢失」这类词**
- **没网**：页面照常显示缓存，顶上一条细条「没连上 · 显示的是 10:32 的」；写操作排队，连上自动发
- **最大字号**：到 xxxLarge（产品主人 2026-10-21 定的上限）每一页都不截字、不重叠

### 3.4 文案（沿用）

- 中文大白话；不责备（「落后」只说事实，不说「你没做到」）；不夸张；数字用程序算好的写法（`Show` 和服务器一字不差）
- 不出现：「AI 推测」以外的技术词、英文、错误码

## 4. 待办和提醒（高频 ①）

> 一句话：待办有了自己的标签页；说的、打字的都能加；**定了时间就一定响**；勾、推迟、删除都是一下。

### 4.1 什么时候用

1. 早上：看今天要做的、以前没做完的；把昨天剩下的带到今天
2. 白天：想起一件事——说一句「下午三点提醒我给王总回电话」，或者在待办页打字
3. 到点：通知响了——在通知上直接「完成」，或者「10 分钟后再提醒」
4. 做完一件：在待办页、画布上、小组件上勾掉
5. 晚上：看明天有什么（现在问「明天要做什么」，AI 照程序查的单子答——保留）

### 4.2 待办页（点画布待办卡的标题进来；我 → 待办）

**从上到下**：
- 大标题「待办」；右上角「+」（加待办）、「···」（显示已完成、按时间 / 按人）
- **以前没做完的**（有才出现）：期限（没期限的是说的那天）在今天以前、还没完成的；标题旁一个「全部带到今天」
- **今天**：今天到期的、今天提醒的、今天说的没期限的；**日历里今天的日程**穿插在里面（只读，左边一个日历色的竖条，写「日历」）；按时间排，没时间的在后面
- **明天**、**这周**（按天分）、**以后**（按月分）
- **已完成**：默认收起，一行「今天完成 3 件 ›」

**一行待办**：左边大圆圈（点按区域 44 点）→ 标题（最多两行）→ 右边时间胶囊（「⏰ 17:30」；过期的「昨天 17:30」用留意色）；第二行辅助色：和谁、东西、地方、「每周一」（重复）

**操作**：
| 做什么 | 手势 | 替代 |
|---|---|---|
| 完成 | 点圆圈；或右滑到底 | 长按菜单、详情里「完成」 |
| 推迟 | 左滑「推迟」→ 一排选择：1 小时后、今晚 8 点、明天 9 点、下周一 9 点、选时间… | 长按菜单、详情 |
| 带到今天 | 「以前没做完的」里左滑「今天」 | 长按菜单 |
| 不做了（删除） | 左滑「删除」，轻提示带撤销 | 长按菜单、详情 |
| 看原话 | 长按菜单「看原话」 | 详情里的原话块 |

- **完成以后留在原地**（产品主人 2026-10-21：「待办完成了怎么跑到下面了，这是 bug」）：圆圈填满、文字划线、变次要色；离开这一页再回来，才收进「已完成」
- 下拉刷新；推送来了自动更新

### 4.3 待办详情（底部弹层）

- 顶上：标题（点了就能改，键盘弹起）
- **原话块**：「10月26日 21:30 你说：明天上午十点提醒我给客户回电话」（宋体），点了到笔记库
- **期限**：系统日期选择（紧凑样式，点开是月历）；「没说」时写「没定」
- **提醒**：开关 + 时间（系统时间滚轮）；常用的几个一点就选：「到期那天 9:00」「提前 1 小时」「今晚 8 点」
- **重复**（新）：不重复 / 每天 / 工作日 / 每周（选星期几）/ 每月（选几号）/ 每年
- 和谁、东西、地方：胶囊，点了能改
- 底部：大按钮「完成」；「删除」在最下面（红字，带撤销）
- 来自健康、日历的：只读，写「在日历里改」

### 4.4 提醒（必须可靠——列为红线）

- **手机把所有定了时间、没完成的待办都排上**：不再只排看到过的那几天。服务器给一张全部的单子（4.7）；手机排最近的 60 条（系统最多 64 条），每次打开、收到推送、后台刷新都同步
- **通知的样子**：标题是待办，正文「你 10月26日说的」；**按钮：完成、10 分钟后、1 小时后、明天早上**——在通知上点了不用打开 App（后台发到服务器，没网就排队）
- **时间敏感**：你定了时间的提醒用「时间敏感」级别（专注模式下也能出现；用户可以在系统设置里关）
- **重复的待办**：完成一次，下一次自动出现（期限、提醒按规则往后排）；「不做了」可以选「只删这一次 / 以后都不要了」
- **以后有了系统推送**（要加入苹果开发者计划）：服务器在提醒时间检查，手机那边没确认排上的推送兜底
- 演示数据时不排（照旧）

### 4.5 加待办

- **说一句**（照旧）：「明天下午三点提醒我取快递」→ AI 整理
- **待办页的「+」/「我的」的「加待办」**：弹层里一个输入框（键盘马上出来），提示「比如：明天下午三点取快递」；**打字时下面就显示认出来的时间**「明天 15:00 · 到时候提醒你」（程序认，不走 AI，100 毫秒内）；可以点那一行改；回车或「加上」就加
  - 打的这行字照样存成一段**原话**（原话是唯一的源头），整理照旧在后台做（补上和谁、东西、地方）；时间以程序认出的为准、你改过的以你为准
  - 认不出时间：照样加，算今天、不提醒
- 输入框旁边一个麦克风：说话也能加

### 4.6 画布、小组件、回顾里的待办

- 画布的待办卡和这里同一套行、同一套操作（勾、长按菜单）；卡片标题「待办 ›」进待办页
- 小组件上勾（已有）；锁屏「下一件」（已有）
- 回顾「还没收尾的」：每一行有「带到今天」（已有），也能左滑

### 4.7 服务器要做的

- `GET /api/todos?view=open|today|upcoming|done&from=&to=`：分好组的单子（以前没做完的、今天、明天、这周、以后、已完成），每条带原话来源；`?reminders=1` 给全部未完成、带提醒的（手机排通知用）
- `POST /api/todos`：快加——`{ text }`，**程序认时间**（「明天下午三点」「下周一」「10月30日9点」「半小时后」「今晚」……写成纯函数 + 单元测试，至少 60 个说法），存原话、建待办、回认出的结果；后台照旧整理补全
- `POST /api/todos/parse`：只认时间不建（给打字时的预览用）
- 待办加字段：`repeat`（重复规则）、`doneAt`（完成的时刻）、`snoozedFrom`（推迟以前的时间，回顾里能说「推迟了 2 次」）；完成重复的待办时生成下一次
- 推迟：`PATCH /api/entries/:id { remind_at }` 已有，加一个 `POST /api/todos/:id/snooze { preset }`（程序算时间，手机和服务器同一套）
- 问答（「明天要做什么」）、早上的回顾、小组件都用同一个查法（现在 `todosBetween`、`openTodosBefore` 已有，收成一处）
- 评测：快加的认时间是程序做的，用单元测试；整理时认出重复（「每周一提醒我交周报」）加评测用例

### 4.8 验收标准

1. 说「10 月 30 日上午 9 点提醒我交报告」，**之后不翻到 10 月 30 日**，到点响（模拟器：查 `pendingNotificationRequests` 里有它；真机：实测记录）
2. 通知上点「10 分钟后」，10 分钟后再响；点「完成」，打开 App 看到已完成，服务器上也是
3. 待办页「+」打「明天下午三点取快递」，打完以前下面已经显示「明天 15:00」；回车 1 秒内出现在「明天」
4. 勾一件，留在原地划线；切走再回来进「已完成」
5. 「每周一提醒我交周报」：完成这周的，下周一的自动出现
6. 没网时勾 3 件、推迟 1 件，连上以后服务器全对上
7. 附录 A「待办」的每一项都在

## 5. 钱（高频 ②）

> 一句话：钱有了自己的标签页；**3 秒记一笔**（不用开口）；主页第一屏回答「这个月花了多少、还剩多少预算、有什么要办」；每一笔左滑就能办事。业务规则全部沿用 `docs/prd-money.md`。

### 5.1 什么时候用

1. 刚付完钱：记一笔（说一句，或者数字键盘）
2. 每天一两次：这个月花了多少、外卖超没超
3. 报销、借钱：看还有哪些没拿回来，办完点一下
4. 月底月初：花在哪、花给了谁、和上个月比
5. 偶尔：值不值、人情往来、钱和你的日子

### 5.2 钱的主页（点画布的钱卡进来；我 → 钱）

**第一屏**：
- 大标题「钱」；工具栏：月份「‹ 10月 ›」（左右滑也能换月）、眼睛（遮住金额）
- **主卡片**：「10月日常花的」大数 ¥9,616（数字滚动）→ 一行「今天 ¥15 · 69 笔」→ 一句和上个月比的话（最多两行，点开看全）
- **预算**（你说过的「不超过」目标才有）：一条一条细进度条，写「还能花 ¥64」（不写「¥236 / ¥300」让人去减）；点了进那个目标；超了写「超了 ¥36」，用留意色（不用红）
- **四个圆按钮**：记一笔 · 每一笔 · 留意的（角上数字）· 人情往来

**往下**（每一块一张卡片，标题右边「›」进完整的一页）：
1. **月历**：每一格直接写那天日常花了多少（产品主人 2026-10-27：「大小圆的，直接显示金额不可以吗」），背景深浅只做辅助；点一天 → 下面直接换成那天的每一笔，不跳页（06 交互细节 3.2）
2. **留意**：最多 3 条（等报销、借出去、7 天内要扣的固定的）；**左滑「都报销了」「已经还了」**；「全部 ›」→ 留意的
3. **花在哪**：一行一个领域，写金额、百分比和一根条（不用方块图）；点一行 → 每一笔（只看这一类）
4. **花给了谁**：横条（留着）
5. **值不值**：横着滑的卡片（东西、你说的话、用了几次、每次多少钱）→ 一样东西
6. **钱和你的日子**：发现卡（和关于我同一种）
7. **固定的**：一条月尺（留着）+ 下一笔哪天扣
8. 页脚一行：「只算你说过的钱」

- 「还在攒的」（不到 20 笔、不到 4 周）：每一块自己说一句还差多少，不单独一大块

### 5.3 每一笔

- 系统搜索框（名目、人、领域、你说的话）；下面一排筛选胶囊：全部 · 日常 · 固定 · 收入 · 等报销 · 借出 · 人情 · 回来的（带笔数）
- 按天分组，组头「10月24日 周六 · 花了 ¥1,978」（吸顶）
- 一行：时间 · 名目（第二行给谁、标签）· 右边金额（等报销、借出的灰色；回来的钱「+¥299」）
- **左滑**：「已报销 / 已还」（对应的才有）、「删除」；**长按**：看原话、改金额、改给谁、不算固定的
- 点一行 → 一笔的详情

### 5.4 记一笔（新，数字键盘）

- 从：钱主页的「记一笔」、「我的」的快捷、小组件、Siri「记一笔」
- **弹层**：上面大大的金额（输入时数字滚动）；下面一行「买了什么」（可以不填）；一排常用的名目胶囊（**你最常买的**：午饭、打车、咖啡、外卖……服务器按最近 30 天算）；一排可选：能报销 · 借给别人 · 收入；最下面数字键盘（自己画，大按键、按下触感）+「记下」
- 记下以后：生成一段原话「午饭 25」（选了能报销就是「打车 58 能报销」），走整理（原话是唯一的源头）；**每一笔里马上出现一行**，右边小字「整理中」，整理完变成正式的一行
- 3 秒能记完：点 2、5，点「午饭」，点「记下」

### 5.5 一笔的详情（底部弹层，解决 P5）

- 顶上：图标 + 名目 + **大金额**；一排标签胶囊（日常 / 等报销 / 固定的 · 每月 5 日 / 人情 · 乔迁）
- **只列有的**：给谁、和谁、地方、时间、你说（值 / 后悔）——**没说的不列**；最下面一行「补充：和谁 · 地方 · 给谁 · 值不值」，点哪个加哪个
- 原话块
- 按钮（对应的才有）：标记已报销 / 已经还了 / 不再算固定的 / 这样东西用了几次 ›
- 「删除这一笔」在最下面，带撤销
- 一段话里好几笔（超市买了洗衣液、面包、葡萄……）：详情顶上是这段话的合计，下面一行一笔，点一行改那一笔

### 5.6 别的页（都沿用现在的内容，换成新组件）

- **留意的**：等你拿回来的（卡片 + 「都报销了」）、固定的（月尺）、买了还没用完的（课时点点）、常买的（多久一次、下次大约哪天）、预算——每一块一张卡片，可以左滑办事
- **一天的钱**（弹层）：那天花了多少、每一笔、和谁在一起、你说的心情、那天还说了什么；左右滑到前后有钱的日子
- **一样东西**：每次多少钱（大字 + 越用越便宜的台阶线，Swift Charts）、你怎么说它、用的那几次
- **人情往来** → **和一个人的来往**：送出、收到、每一次的事由和原话
- **遮住金额**：眼睛点一下，整个钱标签里的数都变「¥•••」；**新：可以设成打开钱标签要 Face ID**（设置 → 隐私）

### 5.7 服务器要做的

- `GET /api/money/home?month=`：主页一次拿全（现在主页要拿月份、总览、发现三次）；预算（「不超过」目标）放进来
- `GET /api/money/quick`：记一笔用的常买名目（最近 30 天最常说的 8 个，带平常的价）
- `POST /api/notes` 带 `context: "money"`（2.2）
- 记一笔生成的原话格式写进 Skill 的例子，加评测用例（「午饭 25」「打车 58 能报销」「借给小王 500」）

### 5.8 验收标准

1. 从钱标签到记完一笔「午饭 25」：秒表 3 秒以内（真机录屏）
2. 每一笔里左滑「已报销」，主页留意那一条马上没了，轻提示带撤销，撤销能恢复
3. 一笔的详情里没有一行「没说」
4. 收到人情的月份、没有钱的月份、刚开始用 3 天、遮住金额——主页都正常（演示数据 + 新用户各截一遍）
5. 附录 A「钱」的每一项都在

## 6. 心情（高频 ③）

> 一句话：心情有了自己的页；**一秒记下现在的心情**，想说为什么再说；先看今天的那几刻，再看规律。业务规则全部沿用 `docs/prd-mood.md`（五档说法、情绪词只写说出来的、那一刻、心情从哪来、只说同时出现）。

### 6.1 什么时候用

1. 心情来了：点一下记下（小组件、我的快捷、心情页）；有空就说两句「因为……」
2. 晚上：回头看今天几种心情、那几刻
3. 隔几天：这周 / 这个月心情怎么样、什么时候好、和谁在一起好

### 6.2 心情页（我的 → 心情；画布心情卡的标题也进这里）

**第一屏**：
- 大标题「心情」
- **现在心情怎么样**：五个圆（很差 · 不太好 · 一般 · 挺好 · 很好），颜色用心情的粉（深浅五档，和现在的刻度一致）；点一个 → 记心情（6.3）
- **今天**：今天的每一刻一行（时间 · 五个小点 · 说法 · 情绪词），下面是那一刻（宋体原话）；点一行 → 那一条心情（弹层，现在的心情详情）

**往下**（卡片，标题右边「›」进心情分析）：
- **这个月**：心情月历，每一格是那天的表情（一眼看出好坏，不只靠深浅）；左右滑换月；点一格 → 下面出现那天的每一刻（06 交互细节 4.3）
- **这周**：七天七个点，一句话（「周三最低」——前后两段都这样才说，沿用）
- **好时刻**：最近的三个好时刻（那一刻的原话）→ 好时刻（全部）
- **发现**：和心情有关的发现卡（「和儿子在一起的日子……」）

**心情分析**（下一层，把现在「关于我 → 心情」的全部搬来，按卡片排好）：一天里什么时候、好时刻多在做什么、醒着的时间花在哪、和谁在一起、你说出过的感受（字越大说得越多）、心情和精力（折线，能拖着看数，日 / 周 / 月 / 年）、变化

### 6.3 记心情（新）

- **弹层**：顶上刚才点的那一档（可以改）；一排**常用的情绪词**胶囊（「开心」「放松」「累」「烦躁」……来自 prd-mood 5.5 的那套说法，按你说得多的排前面），可以多选、可以不选；一个输入框「因为……」（可以不填，旁边麦克风）；「记下」
- 记下：生成一段原话（「心情挺好，放松，因为晚上楼下飘上来烤红薯的香味」），走整理——**情绪词只写说出来的**这条规矩照样成立，因为点的胶囊就是你「说」的
- 只点了一档就记：原话「心情挺好」——整理时不编那一刻、不编情绪词
- 很难受（很差 + 「想死」这类原话）：沿用 prd-mood 5.6 的做法

### 6.4 晚上问一句（选开，默认关）

- 设置 → 提醒 → 「晚上问问心情」，打开以后每天你定的时间（默认 21:30）一条通知「今天心情怎么样？」，**按住通知直接选一档**，点了就记（原话「心情一般」），不用打开 App。系统在通知上能放几个按钮要在真机上试：放得下五个就五档；放不下就「挺好 · 一般 · 不太好 · 说两句…」（最后一个是系统的回复框，打字或说话）
- 和现在「晚上的倾倒提醒」合并：今天没说过话时问「今天过得怎么样」，说过话、没说心情时问心情，都说过了不问

### 6.5 服务器要做的

- `GET /api/mood/page`：心情页一次拿全（今天的几刻、这个月的格子、这周、最近好时刻、和心情有关的发现）；分析那一层用现有的接口（`/api/about/mood`、`/api/board/mood-sources`）
- `GET /api/mood/words`：常用情绪词，按这个人说得多的排
- 记心情的原话格式加评测用例（「心情挺好」「心情不太好，烦躁，因为方案又改了」）：不编那一刻、不编情绪词
- 晚上问心情：和倾倒提醒合成一种提醒（`reminders`）

### 6.6 验收标准

1. 小组件上点「挺好」，打开 App 今天的心情里有一刻「挺好」（1 秒内）
2. 记心情选「不太好」「烦躁」、说「方案又改了」：整理出的心情是 2 级、情绪词只有烦躁、那一刻是「方案又改了」
3. 只点一档：没有那一刻、没有情绪词
4. 心情页第一屏不用翻就看到今天的每一刻
5. 附录 A「心情」的每一项都在（含心情从哪来、好时刻、精力）

## 7. 感悟（高频 ④）

> 一句话：感悟有了自己的页；**记下的话会再见到**（重温）；能收藏成语录、能做成一张好看的卡片。

### 7.1 什么时候用

1. 想明白一件事：说一句，或者「记一句」
2. 隔几天：翻翻以前说过的
3. 某一句特别想留着：收藏成语录（回顾、小组件里会出现）；分享给朋友

### 7.2 感悟页（我的 → 感悟）

- 大标题「感悟」；搜索框（按意思也能找到，沿用本地向量搜索）

- 点一张 → 一条感悟（弹层）：全文、原话块、「以前也说过类似的 3 条」（沿用）、标签（能改）、收藏、分享、删除
- 长按：收藏 / 取消收藏、分享成图片、看原话、删除

### 7.3 记一句

- 「我的」快捷、感悟页右上角「+」、小组件
- 弹层：大输入框（宋体）、麦克风；「记下」→ 原话「记一句：……」，走现在的「我的语录」（R4）：自动收藏成语录

### 7.4 分享成图片（新）

- 一张竖版卡片：暖白底、宋体的那句话、下面「—— 我，2026年10月11日」、右下角小小的 Pour；三种版式可选
- 系统分享面板（存到相册、发微信）；**只有你点分享才生成，不上传**

### 7.5 服务器要做的

- `GET /api/insights?tag=&cursor=`：按月分组的感悟、标签和条数
- `GET /api/insights/today`：今天重温的一句（程序挑：一个月前 / 一年前的今天 → 收藏的 → 很久没出现的；同一句 30 天内不重复；记下「看过了」）
- 收藏：感悟加 `starred`（语录 `saying` 已有，收藏的也算语录）；`POST /api/insights/:id/star`
- 回顾的「你说过」、小组件的语录从收藏里挑（现在从「记一句」里挑，扩大范围）

### 7.6 验收标准

1. 演示数据：感悟页第一屏有今天重温的一句，点「换一句」换别的，30 天内同一句不再出现
2. 收藏一句 → 小组件的语录和第二天回顾的「你说过」有机会挑到它
3. 分享出来的图片在 iPhone 相册里看，字不糊、不截断
4. 附录 A「感悟」的每一项都在

## 8. 回顾

> 一句话：回顾分成「每天 / 每周 / 每月」三个标签；每一篇第一屏就是一句话和四个数；长内容折叠成卡片。规则沿用 `docs/prd-review.md`、`docs/prd-report.md`。

- **回顾页**：大标题「回顾」；分段「每天 · 每周 · 每月」；**「需要留意」**（预警，有才出现）单独放在最上面一张卡片，不混在列表里
- 一行一篇：日期（看过的变次要色，没看过的粗体——不打红点）、一句话、一排小数字胶囊（睡眠 6:50 · 跑步 8.4 公里 · ¥38）
- **每日回顾**：一句话（大字）→ 四个指标块（和平时比）→ 一天的样子（时间轴）→ 做了什么（每个领域一行，带图标）→ 目标（进度环一排）→ 心情和感悟 → 一个观察（单独一张高亮卡）→ **还没收尾的**（待办行，「带到今天」）→ **自动检查发现的**（发现卡：原话、整理成了什么、应该是什么、「确实错了 / 没错」）→ 今天 → 你说过（语录卡）→ 来源（收起）
- **周报 / 月报**：同一套；一周的样子、一个月的样子用 Swift Charts 和心情月历；「试试」的建议一条一张小卡
- 一篇的右上角：分享（生成一张长图，选开）、「看这一天的画布」
- 空的部分不出现（沿用）
- **周报和每周回顾**：周报照旧在这里（周一早上，上周发生了什么）；调目标的**每周回顾**在目标里（周日晚上 8 点，9.8）；周报的目标一页最后一行「去做每周回顾 ›」（还没做时）

**服务器要做的**：`GET /api/review?kind=day|week|month`（分好类的列表，带每篇的几个数）；其余沿用。

**验收**：回顾页第一屏能看到「需要留意」和最近 4 篇；每日回顾第一屏是一句话和四个数；附录 A「回顾」的每一项都在。

## 9. 目标（第五版，2026-10-31 按目标模块方案重做）

> 一句话：**不用打卡，进度自己长出来**；按「我在乎的」分组，每个目标一句人话说在不在正轨；坚持的断一天不崩（每周 2 次补假）；落后了有人陪你想办法（GROW），建目标时可以花 1 分钟想清楚（WOOP），周日晚上 3 分钟回顾一次。
> 来源：[目标模块方案](调研/目标模块方案.md)（产品主人 2026-10-28 最终版）+ 做原型时发现的 20 条（方案最后一节，2026-10-31 都定了）。**交互**一条一条在 [06 交互细节](06-交互细节.md) 第 12 节；**能点的样子**：[可交互原型](原型/可交互/index.html) 的「目标」，截图和怎么点在 [原型/目标/](原型/目标/README.md)；**全部功能点**（45 项，每项的来源、原型、服务器、App、验收）在 [09 总表](09-需求和功能点总表.md) 第三节。业务规则以 `SPEC.md` 第八章为准，要改的地方写在 9.12。

### 9.1 几个说法（全章通用）

| 说法 | 是什么 |
|---|---|
| **我在乎的** | 用户自己的几块（默认 4 个：健康 · 钱 · 成长 · 关系，第一次进来从你说得最多的里挑，点头就行；最多 6 个，能改名、能删）。每块包含几个类别（对照表在 9.9）；每个目标属于一块（按类别猜，能改）；哪块都不属于的放「其他」 |
| **四种目标** | **到一个数**（累计：今年跑 500 公里；平均：平均睡 7.5 小时）· **坚持**（每天达到：每天走 8000 步；每周几次：每周背单词 4 次；每月几次）· **不超过**（每月外卖不超过 300 元）· **做完就算**（读完《人类简史》，可以有几个里程碑）；模糊的大目标（三个月瘦 5 斤）= 几个子目标 |
| **三句话** | 为什么想要 · 最可能拦住我的 · 如果……就……（都可选，AI 从原话里给现成的；「如果就」能变成提醒） |
| **补假** | 只给每天都要做的坚持：每周默认 2 次（能改 0–3）；没做到的那天自动用掉、不算断；不用就作废、不攒到下周；**不算「做到」，单独数**（「30 天做到 26 天、补假 3 天」） |
| **成习惯了** | 连续 8 周每周都做到：每天的坚持是那一周没有「没做到」的天（用了补假也算）；每周几次的是那周够数。到了问一句「放进做到的，还是少提醒一点」 |
| **状态** | 判断规则照 SPEC 8.4 的四档（不落后 · 落后 10% 以内 · 落后超过 10% · 不可能），**界面上只用两种颜色**：正轨绿、落后黄（落后多的、不可能的也是黄，配一句话和「聊聊怎么调」）；**还谈不上**是空心圈（刚定的、还没有记录的、AI 建议还没确认的、没有里程碑的做完就算）；**暂停**是浅灰（不是状态）。不用红色 |
| **落后两周** | 连续 14 天落后或不可能（程序判断）→ 卡片和目标页多一行「落后两周了，聊聊怎么调？」，不弹窗；预警也改成这时候发一次（9.12） |
| **暂停** | 不提醒、不算落后；暂停的天数不算进应达（应达的「已过天数」扣掉暂停的天），周期不延长；「先停一个月」到期自动继续，前一天提醒一句 |

### 9.2 目标首页（我 → 目标；我的常用里也有）

从上到下：
1. **这周一句话**：「这周 7 个目标里 4 个在正轨上；『今年跑 500 公里』落后两周了，聊聊怎么调？」（后半句点了进 GROW；都在正轨就只说前半句）
2. **每周回顾没看时**一行「上周的回顾还没看 · 3 分钟 ›」（看完或到下一个周日晚上就不显示）
3. **我在乎的**：一排小胶囊（4 个一排放得下），每个一个小环（这块目标的总体，颜色按 9.1）、名字、几个目标（「还没有」）；点进领域页（9.9）
4. **进行中**：按「我在乎的」分组，每组两列卡片：进度环（中间写百分比；做完就算写「2/4」；大目标写「1/2」）+ 名字 + **一句人话**（「比应达少 78 公里」「这周平均每晚差 40 分钟」「这个月还能花 ¥64」「看完两部分，到第 220 页」「2 个里 1 个在正轨上」）；只有一个目标的组两两并排；落后两周的那张占整行、多一行「落后两周了，聊聊怎么调？」；有 AI 在等回答的多一行「在等你回答一句 ›」
5. **坚持**：一行一个，左边名字和「30 天做到 26 天 · 这周用了 1 次补假」（成习惯了的带标签），右边最近 14 天的小格子：做到实心、用了补假空心带点、没做到留白；**不用红色**；每周几次的只标做了的天
6. **做到的 · 放下的**：收起，写个数；展开能「改回进行中」「再试试」
- 右上角「＋」定目标；没有目标时是第一次进来的样子（9.5 最后）
- **第一屏**（2026-10-31 定，见 9.14 第 6 条）：iPhone 15 上第一屏看得到这周一句话、我在乎的和至少 5 个目标的状态；7 个以上时坚持在往上推不到半屏的地方。首页的五块按方案原样，不为了挤进一屏去掉哪一块

### 9.3 一个目标（推入）

1. **大环 + 一句状态**：大数（「92.4 / 500 公里」）、一句人话（黄或次要色）、一句预测（9.10）；一排数（到昨天应达 · 实际 · 还剩几天 · 剩下每天）；落后两周时一张「聊聊怎么调」的卡
2. **在等你回答**（有才出现）：AI 拿不准一条记录算不算时，原话 +「算 / 不算」，答了程序记住
3. **三句话**：为什么 · 最可能拦住我的 · 如果就（宋体，点一句改）；下面一行提醒的时间；没写过时是「花 1 分钟想清楚 ›」
4. **图**：到一个数是「应达和实际」两条线 + 今天以后的**预测带**（浅色，慢的时候到快的时候），按住拖动看每一天；平均、每周几次、不超过是按周的柱子 + 目标线；体重这种往下的是一条小曲线；坚持每天的是 30 天的格子（像月历）
5. **什么时候最容易做到**：一周七天 × 早中晚的格子，数从原话的时间来；下面一句话 +「把提醒放在周六 08:00」（第二期）
6. **最近推进它的**：原话一句一句列（宋体），右边「+8.4 公里」；**每一条都能点开那条记录**（同一个「一条记录」弹层）
7. **每个月**：年目标拆到月（点数字改，改过的「已调整 · 恢复自动」，没改的月份自动重新分；当月能展开每一周）
8. **推进的日子和心情**：推进了的日子和没推进的日子，挺好以上各几天（发现卡样式，「只是一起出现」；天数少就说「还少，多做几次再看」）（第二期）
9. **设置**：名称、目标值（**点了就地改**，名称里的数跟着变）、类别、只算（名称里带哪些字）、周期、从哪天算、我在乎的、提醒、补假（每天的坚持，0–3 次）
10. 暂停 / 继续、标记完成、删除这个目标——**都不弹确认框**，底部轻提示带撤销
- 不同种类只出现用得着的块：坚持的有补假和 30 天格子、成习惯了的卡；做完就算的有几个里程碑（最后一步勾掉 = 做完）；大目标列子目标（两列小卡片）和当时说的那句原话

### 9.4 坚持类的特别之处

- 主数字是「最近 30 天做到 26 天」，连续天数降成一行小字（「连续 10 天没断 · 最近 30 天里最长 19 天」）
- 补假按 9.1；补假用掉那天，卡片上写「这周用了 1 次补假」
- 成习惯了按 9.1；每周几次的主数字是「这周 1 次，还差 3 次 · 连续 8 周都做到」（「30 天做到几天」对它没意义）

### 9.5 定目标（弹层）

- 上面一个输入框「说一句你想做到的」+ 麦克风；下面「常用的」（**只列还没有的**，都有了就换成从原话找的建议）；最下面「或者一项一项填」。三条路走到同一张**理解卡**
- **理解卡**：目标的名字；种类和周期；**从哪句话算**（「从你说的『游泳』算，只算和儿子一起的」）；**已经算进去多少**（「这个月已经算进去 2 次」+ 看是哪几句原话）；放进哪个「我在乎的」（按说的话猜，能点着改）；「对」「改一下」（改一下 = 一项一项填，填好的带过去）
- **拿不准才问一句**，下面给现成的回答（「多久一次算『多』？每月 4 次 · 每周 1 次 · 每月 2 次」）
- **模糊的**（「我想变健康」）：先问「最想先改变的是哪一点？」（睡得更好 · 动起来 · 吃得清淡 · 瘦一点），选了拆成具体的几个（能勾掉不要的），已经有的不重复建
- **「不要」的**（「少吃外卖」）：照样理解成「不超过」；已经有了就说已经有了、给「改成每周 1 次 / 不改」；下面多一行「换成『每周自己做饭 4 次』会更容易坚持，要一起加上吗？」
- **已经有的**（SPEC「不重复建」）：说「已经有了」+ 那个目标的状态 +「去看看」；**这次说的数不一样**（「我今年想跑 1000 公里」）就问「要把它改成 1000 公里吗？」
- **自己说的一句**：数和单位不当成要找的词（「每天喝 8 杯水」→ 从「喝水」算，一天够 8 杯算做到）；按说的话猜放进哪个「我在乎的」
- **一项一项填**：种类（到一个数 · 坚持 · 不超过 · 做完就算）、周期、类别（子类别也算）、怎么算、看什么（选了「距离」单位就是公里、「花了多少」是元）、目标值和单位、只算名称里带哪些字、从哪天算、我在乎的；名称按选择自动生成；和已有的是一件事时同上「已经有了」
- 点「对」：**环转一下**、轻触感，写「定好了 · 在『坚持』里 · 我在乎的：关系」；一年的、模糊的大目标问一次「花 1 分钟想清楚？」，别的只留一行入口
- **第一次进来、还没有目标**：「说一句你想做到的」+ 3 个从原话找的建议（「你最近 5 次说想早点睡，要定成『每天 11 点前睡』吗？」，点了直接到理解卡）+ 「我在乎的」点头（对 / 改一下）

### 9.6 花 1 分钟想清楚（WOOP，可选）

- 一屏一问，三屏：做到了最期待的是什么 → 最可能拦住你的（只问你自己的，不问天气、加班）→ 遇到它的时候打算怎么做
- 每屏 2–3 个 AI 从你说过的话里写的回答（宋体），**每个都能点开看是从哪句原话来的**；也能自己说一句
- 最后一屏选提醒：时间（「每个工作日 18:30」「周六 08:00」）或地点（「到家的时候」）或不用提醒；选了就变成这个目标的提醒（9.10）
- 随时「跳过」；从目标页点一句进来时只改那一句

### 9.7 落后了：聊聊怎么调（GROW，2 分钟）

- 入口：卡片上「落后两周了，聊聊怎么调？」、这周一句话、目标页的卡、每周回顾第 2 屏的「细聊」
- 四步，上面一排进度：**还想要吗**（重要 · 没那么重要了）→ **卡在哪**（程序摆事实：「10 月你跑了 3 次，都在周末早上；工作日一次没跑」，能点开是哪几次；再问「你觉得是什么拦住了？」给现成的回答）→ **有哪些办法**（3–4 个，每个写怎么做、**程序算的新日期**、代价）→ **下一步**（选一个马上生效；「从下周一重新开始」开关；新的「如果就」变成提醒）
- 选了以后目标立刻变（目标值、名字、那一句话、提醒），底部能撤销
- **放下**：「放下也是好结果，不算失败」，写一句为什么（可以不写）→ 进「放下的」，能「再试试」

### 9.8 每周回顾（周日晚上 8 点，3 分钟）

- 系统通知「这周的回顾好了，3 分钟」→ 三屏：**这一周**（每个目标一行，走了多少「+8.4 公里」，做到的打勾；一句 AI 写的观察，程序找规律）→ **要调一调的**（落后的一两个，各一个最可能的办法，点了就改；「细聊」进 GROW）→ **下周最重要的一件**（从目标里挑一件，AI 写成下一步，放进待办）
- 没点到通知：目标首页那一行（9.2 第 2 条）
- 和周报的分工：**周报**（周一早上，在回顾里）说上周发生了什么；**每周回顾**（周日晚上，在目标里）调目标、定下周最重要的一件。周报的目标一页最后一行「去做每周回顾 ›」（还没做时）
- 设置 → 提醒和通知：每周回顾的时间（默认周日 20:00）、能关

### 9.9 领域页（我在乎的 · 一块）

- 从首页胶囊、关于我进来；就是「关于我」原来的领域页，**上面加四块**：**我想成为……**（AI 从原话提一句，「对，就这句 / 我自己写」，点头才算）→ **这一块的目标**（一行一个，点进目标）→ **在乎和投入**（你打的分和最近 30 天花的时间，四块并排两条：「关系你打了 9 分，最近 30 天花在上面的时间却最少：10 小时 12 分」）→ **这个季度打几分**（1–10，上个季度几分）；下面是原来那页（每一天、什么时候、心情、这些数的变化……）
- **「我在乎的」和「关于我」领域的对照**（默认，能在领域页「包含哪些」里改）：健康 = 运动、健康、睡眠、称体重（花的时间算运动和冥想，**睡觉不算**）；钱 = 钱（**不算时间**，写这 30 天记了几笔）；成长 = 学习、看书；关系 = 家人朋友。「钱」没有原来那页，下面给一个「钱的明细在『钱』里 ›」
- 这一块没有目标时：「还没有目标。你说过 3 次想多陪儿子，要定成『每周陪儿子出去玩 2 次』吗？」→ 直接到理解卡

### 9.10 别处的目标

- **预测**：中间值照 SPEC 用最近 28 天的速度；预测带是 28 天里前后两个 14 天各自的速度；少于 14 天写「数据还不够」。跟得上的写「照最近的速度，12月18日到 500 公里」，跟不上的写「照最近的速度，年底在 163–193 公里之间」。GROW 的日期写清是照新计划（「照每周 13 公里，12月29日能到」）
- **提醒**：「如果就」变成这个目标自己的提醒（系统通知，按时间或到某个地方）；在目标页三句话下面、设置 → 提醒和通知里看得到、能关；**不进待办**。每周回顾「下周最重要的一件」进待办
- **我的**：目标一组三个格子——目标（首页）、**坚持**（只看坚持的那几行）、**预算**（说过的「不超过」，含子目标）
- **画布**：今天推进的目标（现在的两张环卡）**点了进那个目标**（SPEC 8.5「点开是目标详情」）；画布内容不改
- **钱**：主页的预算一行写「还能花 ¥64」，点了进那个目标；留意的里「你说过的预算」同上
- **回顾**：每日、周报、月报里的目标一行一个（「+8.4 公里」），颜色同 9.1
- **搜索、对话**：搜得到目标（写那一句人话）；说一句建目标走 9.5 同一张理解卡；收据里「推进了目标：……」照旧

### 9.11 AI 和程序怎么分工（照方案「AI 联动」）

- **程序**：每一个数——进度、应达、预测和预测带、补假、30 天做到几天、成习惯了、状态、落后两周、GROW 每个办法的新日期、在乎和投入的时间；AI 写的句子里不能有程序没算过的数
- **AI**：把一句话理解成目标（种类、数、周期、算哪些记录）、拿不准时问哪一句和给哪几个回答、模糊目标怎么拆、WOOP 三问的现成回答（从原话里找，带出处）、GROW 的措辞和办法的说法、每周回顾的那句观察（程序先找规律）、「我想成为」的那句（你点头才算）
- **你**：最后点头；任何字段都能直接改，改了 AI 不再改回去

### 9.12 服务器要做的

- **字段**（目标表）：`care`（属于哪个我在乎的）、`three`（三句话）、`remind`（如果就的提醒：时间或地点）、`paused_from` / `paused_until`、`rest_per_week`（补假 0–3）、`milestones`（做完就算的几步和完成日）、`letgo_at` / `letgo_why`、`ask`（在等回答的那一条）；新表 `care_areas`（名字、图标、顺序、包含哪些类别、每季度的分、我想成为的那句和确认状态）
- **算法**（程序，带单元测试）：每天达到型（每天的量 ≥ 多少算做到）的「30 天做到几天、补假几天、没做到几天」；补假（每周按顺序自动用、作废、不攒）；成习惯了；连续落后 14 天；暂停扣天数；预测带；GROW 办法的新日期；在乎和投入（按对照表合时间、不算睡觉）

- **规则改动**（`SPEC.md` 第八章一起改）：8.2 加「每天达到」；8.4 状态只用两种颜色、「落后 12%」改成「比应达少 78 公里」、预测加预测带；8.5 目标页按我在乎的分组、做完就算可以有里程碑；阶段 7 的预警从「目标变红」改成「连续 14 天落后」时发一次（同一个目标 14 天内不重复）；早上的今日提醒里坚持的说法改成「今天做到就是 30 天里第 27 天」/「这周还有 1 次补假」

### 9.14 验收标准

1. 说一句建一个目标，从开口到建好不超过 15 秒（真机计时）
2. WOOP 三步，每步点现成回答就能过，全程不超过 60 秒；「跳过」一下就走
3. 每周回顾不超过 3 分钟，三屏；没点通知也能从目标首页进
4. 绑定了类别的目标一次打卡都不用；说一句话、整理完，进度马上变，不用刷新
5. 坚持类没做到的那天不出现红色、不显示「断了」，补假自动用
6. **第一屏**：iPhone 15 上第一屏看得到这周一句话、我在乎的和至少 5 个目标的状态，往上推不到半屏看到全部（2026-10-31 定：方案原来写「全部进行中的」，7 个目标时首页五块加起来放不下，宁可多推一下也不去掉哪一块；量法见原型 README）
7. 页面上每个数字都能点回原话或说清怎么算的；AI 写的句子里没有程序没算过的数
8. 删除、暂停、放下、标记完成都能撤销，没有确认框
9. 用手指在真机上试：长按出菜单，松手不误点；左滑和上下滚不打架；长按不选中字（2026-10-31 原型上发现过）
10. 现在的 16 项一项不少（08 功能核对「目标」逐行）；09 总表第三节 45 项逐项
11. 演示数据里每种新状态都看得到（9.13），`npm run demo:check` 全过

- 「做到的」一年回看，放进「你的一年」
- 新起点提醒（周一、月初、生日：「新的一周，要不要重新开始……」）

## 12. 搜索、问答和对话

**搜索（画布右上角的 🔍）**
- 进来就是搜索框和键盘；没输入时：最近搜过的、几个可以问的（「上周花了多少」「上次跑步是什么时候」「谁还欠我钱」）
- 输入时按组出结果：**回答**（像问题的，AI 回答在最上面，带来源编号和图，沿用）、原话、记录、感悟、目标、日子（输日期直接跳那天）
- 点结果：打开对应的页或详情

**对话（说一句展开的）**
- 对话记录按天分组（沿用）；收据（「已记录：午饭 ¥25 · 撤销」）用新组件；回答的来源编号可点、图表用 Swift Charts
- 输入框上方的快捷：问一句、记一笔、定目标、改一下

**验收**：问「这个月外卖花了多少」，回答带来源和图；附录 A「搜索和问答」的每一项都在。

## 附录 A：现在能做的每一件事（2026-10-27，「能力只增不减」的对照表）

> 每一块重做完，在验收申请里逐条写「还在：在哪 / 合并到了哪 / 有意去掉了（产品主人同意过）」。来源：服务器 `SPEC.md` 第七到十三章、`docs/prd-*.md`、App 的代码。

**待办和提醒**
- 说一句建待办，认出期限、提醒时间、和谁、东西、地方；没期限的算说的那天
- 画布待办卡：勾选完成（完成后留在原地）、到点前显示提醒时间、日历的日程穿插（只读，演示时是演示的日程）
- 详情里改内容、期限、提醒、和谁东西地方、完成状态
- 手机本地通知（演示数据时不排）；Bark / Server酱推送；免打扰时段
- 问「今天 / 明天 / 这周的待办」「还有什么没做」，程序查单子、AI 照说
- 每日回顾「还没收尾的」：带到今天；早上的回顾里「今天」那一段
- 小组件：今天、下一件（能勾）；锁屏

**钱**
- 只算说过的钱；花费、收入、能报销、借出去、固定的、回来的钱（退款、AA）、收到的人情（不算收入）
- 主页：日常花的大数、今天、笔数、和上个月同一段比的一句话、月历圆点（面积是钱）、点一天看一天的钱、左右换月
- 每一笔：按天分组、搜索（名目、人、领域、原话）、按种类筛选、标签（收入、等报销、借出、固定、人情、回来的钱）
- 固定的：认出每月扣的（第一次说「每月」就认）、已扣多少、还要扣多少、月尺、不再算固定的
- 收入、人情往来（送出、收到、和一个人的来往、事由、请客）
- 留意：等报销（都报销了）、借出去（已经还了）、7 天内要扣的、在扣钱却很久没说到用它的；留意的那一页：课时、常买的（多久一次、下次大约哪天、比之前贵了多少）、你说过的预算
- 花在哪（方块图，20 笔以后）、花给了谁（3 个月、一家人单独一句）、值不值（你说的、用了几次、每次多少钱）、一样东西的那一页
- 钱和你的日子（发现卡、四个反馈、点开看哪几天）
- 遮住金额；问答问钱、问欠的钱、问课时、问人情；收据里写去向和给谁

**心情**
- 五档说法和刻度、情绪词（只写说出来的）、精力（说到才有）、那一刻（原话一字不差）、AI 推测的标注、你改的标注
- 一天几条心情按时间排、「有起有落」
- 详情里改级别、精力、那一刻、情绪词；「依据」
- 关于我 → 心情：心情像素、一周七天、一天里什么时候、好时刻多在做什么、你说出过的感受、心情和精力曲线（日周月年）、心情从哪来（30 天 / 90 天 / 今年：什么时候、醒着的时间、和谁、常见的心情）、发现、变化
- 笔记库的好时刻；回顾里的心情、连着几天心情不好如实说一句；问答问心情从哪来
- 很难受的时候的做法

**感悟**
- 说一句记下感悟（原话片段、标题、标签）；「记一句」记成语录
- 画布感悟卡（原话、标签、以前也说过类似的几条——收起）
- 笔记库 → 感悟：按标签浏览、按月分组、看原话
- 回顾里的「你说过」、小组件「我的语录」；周报月报里感悟的主题；关于我里「说的和做的」用到感悟

**回顾**
- 每日回顾（一句话、关键数字和平时比、一天的样子、做了什么、目标推进、心情和感悟、一个观察、还没收尾的、今天、你说过、来源；空的部分不出现；数字现算；事实变了重写标「已更新」）
- 周报、月报（同一套，四个数和上期比、一周 / 一个月的样子、做了什么、钱、目标、心情和感悟、观察、这周 / 这个月、顺手整理、来源）
- 预警（「有件事需要留意」）；看过的变次要色、不打红点
- 夜里自动检查查出的（确实错了 / 没错，能撤销）
- 早上画布上「昨天的回顾好了 →」；推送

**目标**
- 说一句建目标（累计、平均、次数、连续天数、不超过、完成型、模糊目标拆子目标）；手动表单
- 年 → 月 → 周拆分、改某个月（锁定、恢复自动）；应达 vs 实际、状态五种颜色、预测完成日期
- 目标详情：曲线、连续的格子、贡献的记录、改名称目标值类别开始日、标记完成；绑定失效时改绑
- 画布上今天推进的目标、卡片底部的进度；问答问进度

**关于我**
- 主页：生活由什么组成（方块图）、时间去向（7/30/90 天）、这周的新发现（四个反馈）、换个角度看你（心情、人、钱、你说的话）、好日子的配方、你没注意到的变化、说的和做的（能藏）、Pour 认识的（关系、说法：能加能改能删）、还在攒的
- 生活领域页、人（星图、一人一行、这个人）、你说的话（时钟、在说什么、小词、连锁反应、主题的起落）、你的一年
- 「不用列出」、「对 / 不对」；地址 `find=`、`item=` 直接打开

**笔记库**
- 全部原话按时间倒序、按日期 / 类别 / 人筛选、关键词 + 按意思搜索（「意思相近」标）
- 每段原话下的整理结果和状态；改原话、删除（能撤销、恢复后重新整理）、失败重试
- 感悟、好时刻两个视图；地址 `?note=`、`?tag=`、`?view=`

**搜索、问答、对话**
- 全局搜索（原话、感悟、目标、输日期跳那天）
- 问问题：来源编号、五种图表、逐字显示、只说同时出现、找不到就说找不到
- 对话：按天分隔、收据（撤销）、追问和回答、斜杠命令（问、记、目标、改、找）、补记（看以前的日子时说的记到那天）、语音识别

**设置**
- 大模型（模型选择、密钥状态、测试连接、用量和花费、每月上限）、自动记下的把握程度、处理日志
- AI 准不准（你改过的、追问、记住的说法、认得出的人和事和地方、检查清单、自动检查、最近一次检查、分开看、没答对的句子、再检查一次）
- 提醒和推送（渠道、每日回顾、晚上的提醒、预警、周报月报、免打扰、试一下）
- 类别（整理建议、改名合并图标颜色删除、层级）、日界线、数据（备份、导出、演示数据）、健康、日历、这台手机（服务器地址、设备）

**系统入口**
- 小组件（说一句、今天、下一件、我的语录）、控制中心、锁屏、分享扩展、Siri「用 Pour 记一句」、`pour://` 链接、健康、日历
