## 1. 背景、问题、目标

### 1.1 现在

生活画布 2.0 已经是 iPhone 的样子；其余的页面是 2026-10-20 从网页版 1 比 1 搬过来的，功能很全（钱、心情、关于我的深度在同类产品里少见），但**用起来是一个装在手机里的网页**。

### 1.2 现在的问题（2026-10-27 在模拟器上逐页截图、逐页用过）

**整体**
| # | 问题 | 在哪看到 | 为什么要紧 |
|---|---|---|---|
| P1 | 换一页要点左上角菜单、再点一项；没有「返回」的感觉（左上角是一行小字「‹ 钱」） | 每一页 | 用得越多越烦；不像 App |
| P2 | 每一页都是一长条文档：回顾 12 屏、周报 12 屏、关于我 10 屏、设置 12 屏、心情 8 屏 | 回顾、关于我、设置 | 找不到东西；最有用的埋在中间 |
| P3 | 三套样子混着：画布是暖灰底白卡片，别的页是白底细线，还有米色卡片；图表四五种画法；图标一会儿是 emoji 一会儿是线条 | 全部 | 「不精致」的根源 |
| P4 | 网页式的操作：蓝色文字链接当按钮（「看这一天 →」「全部 ›」「试一下」）、「···」菜单、改时间要打字「10:00」 | 笔记库、设置、详情 | 点不准、不顺手 |
| P5 | 详情是一张表：「开始 没说 / 结束 没说 / 时长 没说 / 给谁 没说……」 | 点一笔钱、一条记录 | 一屏全是「没说」，真正的内容看不到 |
| P6 | 底部输入框浮在每一页上，盖住最后几行 | 每一页 | 最后一条点不到 |
| P7 | 每一块下面都有一两行灰色小字解释（「只统计说了时长的事……」「前后两段都是这样 · 只是同时出现……」） | 关于我、钱、心情 | 诚实，但满屏都是说明 |
| P8 | 设置里摆着开发用的数字：「分类 99.7% · 时间 100%」「通用 365 句 · 你个人的 0 句」「这周 AI 追问 0 → 2 → 0」 | 设置 | 给普通人看是噪音 |
| P9 | 出错时写「看不懂服务器的回复：未能读取数据，因为数据丢失」 | 钱（2.8.2 已修根因） | 用户不知道该怎么办 |
| P10 | 演示数据时每一页顶上一条黄色横幅 | 全部 | 占地方、像警告 |

**高频的四块**
| # | 问题 |
|---|---|
| T1 | **待办没有自己的页面**：只在当天的画布上；以后的、以前没做完的要翻日子找 |
| T2 | **提醒不可靠**：只有 App 打开过那一天、看到过那条待办，才会排提醒——说「下周三提醒我」，这几天没翻到下周三，到点不响 |
| T3 | 通知上没有「完成」「稍后提醒」；改提醒时间要打字；没有重复的待办 |
| M1 | 钱只能说话记：地铁上、会议里不方便开口，打一整句又慢 |
| M2 | 钱的主页是一长条，留意的、花在哪、花给了谁、值不值、钱和你的日子挤在一起；每一笔不能左滑办事 |
| E1 | **心情没有自己的入口**：心情页藏在「关于我」里面；没有「现在心情怎么样」一点就记的地方 |
| E2 | 心情页全是分析图（像素格、柱子、折线、表格），看不到今天的那几刻 |
| I1 | **感悟没有自己的入口**：在笔记库的第二个标签里，一行行小字 |
| I2 | 感悟记下就沉底了：没有收藏、没有重温、不能做成一张好看的卡片分享 |

### 1.3 目标

1. **一线 App 的手感**：系统导航、底部弹层、滑动操作、长按菜单、搜索、日期选择、触感、动效；每个操作 100 毫秒内有回应
2. **高频的四块，每天用十次也不烦**：待办两步内加上、一步完成、一定会响；钱 3 秒记一笔；心情 1 秒记下；感悟记下以后还会再见到
3. **一套精致的样子**：只用设计系统 3.0；每一页都能和 Apple 自带 App、Things、微信、支付宝的同类页面放在一起不掉价
4. **能力只增不减**：附录 A 的每一项都还在

### 1.4 怎么算做到了（产品主人在手机上能感受到的）

| 指标 | 现在 | 3.0 |
|---|---|---|
| 从首页到钱、待办 | 2 次点按（菜单、再点） | 1 次（点画布上的卡片） |
| 加一个「明天下午三点取快递」的待办 | 说一句、等 AI 3–5 秒 | 说一句照旧；或者待办页「+」打字，**打字时就看到「明天 15:00 提醒」**，1 秒加上 |
| 记一笔「午饭 25」 | 说一句（不方便开口时要打整句） | 「记一笔」数字键盘：点 2、5、选「午饭」，3 秒 |
| 记一个心情 | 说一句 | 「我的」或小组件上点一下五档里的一个，1 秒；想说原因再说 |
| 待办提醒 | 只排看到过的那几天 | 所有定了时间的都排上；通知上能完成、能稍后 |
| 打开一页 | 每次转圈等服务器 | 先出上次的内容，再无声刷新 |
| 页面长度 | 回顾 12 屏、设置 12 屏 | 每页第一屏就是最要紧的；长的拆成分段或下一层 |

## 2. 新外壳：画布首页、说一句、「我」全部功能

> 一句话（2026-10-28 第四版）：**不要底部标签栏**。打开就是生活画布；底部只有一条「说一句」，和现在一样；左上角「我」进全部功能；待办、钱、心情这些用得多的，从画布上的卡片直接进、直接记。
> 产品主人 2026-10-28：「1 不要底部操作栏，太冗余了，你钱和待办放在我的里面不就可以了嘛，在底部又显示出来，占地方；2 底部只能留语音识别和生活画布，和之前一样，其它的钱、待办全部你自己想办法，参考行业通用标准放在一个合适的地方」

### 2.1 首页和导航

- **首页 = 生活画布**（内容不动）。顶上一排：左边「我」（圆形头像，没有就是「我」字）→ 我的（全部功能，2.3）；中间「今天 · 10月27日 ▾」→ 日历、跳到某一天；右边 🔍 → 搜索（第 12 章，和现在一样在右上角）
- **没有标签栏**。别的页都从首页推进去：左上角「‹ 上一页的名字」、从左边缘右滑返回，一路返回到底就是画布；「我的」例外：从下面升上来，往下拉收起（2.3）
- **待办、钱怎么最快到**（参考不用标签栏的 App 的通用做法：Apple「手记」首页一条时间线、底部只有一个「+」；Things 3 首页就是今天的列表、角上一个「+」；微信聊天底部只有输入框和语音。共同点：首页就是内容，内容本身是入口，快速记一下的按钮放在内容旁边；苹果的设计规范也说，只有一个主要页面的 App 用导航和工具栏，不用标签栏）：

| 想做 | 怎么做 | 几下 |
|---|---|---|
| 看待办 | 点画布上待办卡的标题「待办 ›」 | 1 |
| 加一件待办 | 待办卡右上角「＋」；或者直接说「明天三点取快递」 | 1 |
| 看钱 | 点画布上的钱卡 | 1 |
| 记一笔 | 钱卡右上角「＋ 记一笔」→ 数字键盘；或者直接说「午饭 25」 | 2 |
| 记心情 | 心情卡右上角「记心情」；或者直接说 | 2 |
| 别的功能 | 左上角「我」→ 点格子 | 2 |
| 不打开 App | 按住 Pour 的图标（说一句 · 记一笔 · 加待办 · 记心情）、小组件、锁屏、控制中心、Siri | 1–2 |

- 画布上只加这三个小按钮（待办卡「＋」、钱卡「＋ 记一笔」、心情卡「记心情」），卡片标题能点进那一块；画布别的内容不改
- **不打红点、不显示数字**（原则「不要让我烦」；Pour 2026-09-30 定的「回顾不显示数量、没有红点」照旧）
- 去掉：左上角的抽屉菜单（换成「我」）；演示数据的黄色横幅（换成「我的」页头上的一个小标签「演示数据」+ 画布顶上现有的「演示数据 · 回到真实数据」胶囊）

### 2.2 说一句（底部只有它，每一页都在）

- 底部一条「说一句」，和现在一样：左边对话记录、中间「说一句……」、右边麦克风；不加别的按钮
- **点中间**：展开成对话（大半屏，往下拉收起），键盘弹起，输入框上方一排快捷：「记到今天 ▾」（补记以前的日子）「问一句」「记一笔」「定目标」「改一下」「找一找」（就是现在的 `/问 /记 /目标 /改 /找`）
- **点麦克风**：直接开始听（现在的语音识别）；**按住麦克风**：按住说、松开发（像微信）
- **往下翻页时**：收起，往上翻再出来，不挡内容（解决 P6）
- 在画布、「待办」「钱」「心情」「感悟」页里，说一句的提示词跟着变：「今天做了什么？比如：跑步 1 小时」「说一句待办，比如：明天下午三点取快递」「记一笔，比如：午饭 25」……说的话照旧走整理（意图识别会看到当前页作为提示，提高准确率——服务器要做的：`POST /api/notes` 接一个可选的 `context: "todos"|"money"|"mood"|"insights"`，只作参考，不强制）
- 生活画布原来的输入框就是这一条

### 2.3 「我的」= 全部功能（2026-10-28 精简成 12 个）

> 产品主人 2026-10-28：「同一个入口出现 3–4 次（待办 / 钱 / 心情 / 感悟在快捷、常用、记录里各一次……），34 个图标里只有约 22 个不同功能；每个图标一个颜色；钱的子页面被放到了第一层；多处落单的图标让排版很碎」→ 改成 12 个功能、3 组 × 4，同一个入口只出现一次。

**怎么打开、怎么回去**：点画布左上角「我」，「我的」从下面升上来盖住画布（一整页；它是和画布平级的一页，不是画布下面的一层，所以**没有「‹ 今天」**）。顶上一条小横杠，往下拉或点一下收起，回到画布。底部「说一句」照旧在。

**从上到下**：

1. **头**：圆形头像（没有就是「我」字）；「记了 63 天 · 377 段话」，演示数据时旁边一个小标签「演示数据」（点了是「回到真实数据」的确认）；下一行「Pour 认识你 12 个人、8 件事 ›」→ 关于我。**不要右上角的齿轮**（设置在下面的列表里）
2. **全部功能**：3 组 × 4 个，共 12 个，正好 3 整行

| 组 | 格子 | 颜色（类别色板） |
|---|---|---|
| 记录 | 心情 · 感悟 · 健康 · 目标 | 橙 `#DB7438` |
| 回看 | 回顾 · 日历 · 笔记库 · 好时刻 | 蓝 `#5579DC` |
| 了解自己 | 关于我 · 人 · 你说的话 · 新发现 | 紫 `#8667D3` |

3. **列表**（不是格子）：设置 · 反馈 · 关于 Pour
4. 底部「说一句」不变

**格子的规矩**
- 一个格子：白色 SF Symbol 填充图标在圆角方块里（44×44 点，圆角 12）+ 下面名字（最多 4 个字，一行）
- **一组一个颜色**（3 组 3 色，来自类别色板），不是一个图标一个颜色
- **组名在卡片外的上方**（iOS 分组列表的样式：小字、灰色），卡片里只有格子
- **角上的标记只给要你处理的**：新发现写数字（灰底小胶囊，不用红色）；回顾有新的只是一个小圆点（不写「新」）；别的格子什么都不带
- 点格子：推入那一页，从格子放大进去（系统的缩放转场）；返回回到「我的」
- 搜功能：「我的」顶上下拉出现一个搜索框，搜「报销」能找到「留意的」（每个格子带几个别名，挪到钱页里的那几页也搜得到）

**不放在「我的」里的**（能力只增不减，[08 功能核对](08-功能核对.md)「『我的』页改版」逐条写了去哪）：
- **待办、钱**：画布上的待办卡、钱卡（点标题进；卡片右上角「＋」「＋ 记一笔」直接记）
- **每一笔、留意的、固定的、人情往来、值不值、预算**：钱页里（第 5 章）。「留意的」的数字挂在画布钱卡的「钱」旁边（「留意 3」，有要办的才出现），钱页的「留意的」按钮上也有
- **坚持**：目标页里；**你的一年**：回顾页的「每年」，关于我最下面也有
- **快捷四个**（记一笔、记心情、记一句、加待办）：去掉。画布卡片右上角、感悟页右上角「＋」、说一句、按住 Pour 的图标都能直接记
- **「常用」和「管理」**：去掉（3.0 第二版新加的，现在的 App 没有，不算少了功能）

**App 不做的**：原型里每页右上角的「看现在」和最下面虚线框的「原型说明 · 功能核对」只给产品主人对照用，App 里没有（06 交互细节第 11 节）。

**服务器要做的**：`GET /api/me/hub`——一次拿全「我的」页的数：记了几天、几段话、认识几个人和事和地方、新发现几条、回顾有没有新的。画布钱卡上「留意」的条数从钱的接口拿（`GET /api/money/home` 里留意的条数）。

### 2.5 导航的规矩

| 打开的是 | 怎么出现 | 怎么回去 |
|---|---|---|
| 一个功能的页面（回顾、心情……） | 推入导航栈（大标题） | 左上角系统返回、从左边缘右滑 |
| 一条东西的详情（一笔钱、一个待办、一条心情） | **底部弹层**：先半屏，往上拉全屏 | 往下拉、点外面 |
| 要输入的（记一笔、加待办、记心情） | 底部弹层，键盘或键盘区马上出来 | 往下拉；输了一半往下拉要问「不要了？」 |
| 很重的流程（导出、注销） | 全屏 | 「取消」 |

- **链接照旧**：服务器和对话里的链接（`/review/2026-10-18`、`/money/watch`……）和 `pour://open?path=` 都还能打开：换成「从画布推哪几页」
- 从通知、小组件、链接打开某一页：画布在最底下，返回一路回到画布

### 3.3 交互规范

- **100 毫秒内有回应**：按下有按压态和触感；勾待办、标记已报销、改一行：界面先变，再发服务器，失败了退回并说一句
- **触感**：完成待办 `.success`；滑动操作过阈值 `.impact(light)`；选中五档心情 `.selection`；删除 `.warning`
- **动效**：系统弹簧；完成待办：圆圈填满 + 勾的符号动画 + 文字划线（不跳走）；格子进页面：缩放转场；数字变化：数字滚动（`contentTransition(.numericText())`）；「减少动态效果」打开时全部换成淡入淡出
- **能撤销就不弹确认框**：删一笔、删待办、不做了——都是轻提示「已删除 · 撤销」；只有注销账号、清空数据这种不可逆的才确认
- **每个手势都有看得见的替代**：滑动能做的，长按菜单和详情里也能做
- **说明文字收起来**：每一块的方法说明（「只统计说了时长的事……」）收进标题旁的 ⓘ，点了用小弹层说；页面上只留结论（解决 P7）。「只是同时出现，不一定是因为它」这种**关键的诚实提示**留在卡片上，但一行、辅助色
- **出错说人话**：「没连上电脑上的 Pour。家里的 WiFi 连着吗？」「这一页暂时打不开，已经记下了，我们会修」（+ 再试一次）；**不出现「服务器的回复」「数据丢失」这类词**
- **没网**：页面照常显示缓存，顶上一条细条「没连上 · 显示的是 10:32 的」；写操作排队，连上自动发
- **最大字号**：到 xxxLarge（产品主人 2026-10-21 定的上限）每一页都不截字、不重叠

### 3.4 文案（沿用）

- 中文大白话；不责备（「落后」只说事实，不说「你没做到」）；不夸张；数字用程序算好的写法（`Show` 和服务器一字不差）
- 不出现：「AI 推测」以外的技术词、英文、错误码

## 4. 待办和提醒（高频 ①）

> 一句话：待办有了自己的标签页；说的、打字的都能加；**定了时间就一定响**；勾、推迟、删除都是一下。

### 4.1 什么时候用

1. 早上：看今天要做的、以前没做完的；把昨天剩下的带到今天
2. 白天：想起一件事——说一句「下午三点提醒我给王总回电话」，或者在待办页打字
3. 到点：通知响了——在通知上直接「完成」，或者「10 分钟后再提醒」
4. 做完一件：在待办页、画布上、小组件上勾掉
5. 晚上：看明天有什么（现在问「明天要做什么」，AI 照程序查的单子答——保留）

### 4.2 待办页（点画布待办卡的标题进来；我 → 待办）

**从上到下**：
- 大标题「待办」；右上角「+」（加待办）、「···」（显示已完成、按时间 / 按人）
- **以前没做完的**（有才出现）：期限（没期限的是说的那天）在今天以前、还没完成的；标题旁一个「全部带到今天」
- **今天**：今天到期的、今天提醒的、今天说的没期限的；**日历里今天的日程**穿插在里面（只读，左边一个日历色的竖条，写「日历」）；按时间排，没时间的在后面
- **明天**、**这周**（按天分）、**以后**（按月分）
- **已完成**：默认收起，一行「今天完成 3 件 ›」

**一行待办**：左边大圆圈（点按区域 44 点）→ 标题（最多两行）→ 右边时间胶囊（「⏰ 17:30」；过期的「昨天 17:30」用留意色）；第二行辅助色：和谁、东西、地方、「每周一」（重复）

**操作**：
| 做什么 | 手势 | 替代 |
|---|---|---|
| 完成 | 点圆圈；或右滑到底 | 长按菜单、详情里「完成」 |
| 推迟 | 左滑「推迟」→ 一排选择：1 小时后、今晚 8 点、明天 9 点、下周一 9 点、选时间… | 长按菜单、详情 |
| 带到今天 | 「以前没做完的」里左滑「今天」 | 长按菜单 |
| 不做了（删除） | 左滑「删除」，轻提示带撤销 | 长按菜单、详情 |
| 看原话 | 长按菜单「看原话」 | 详情里的原话块 |

- **完成以后留在原地**（产品主人 2026-10-21：「待办完成了怎么跑到下面了，这是 bug」）：圆圈填满、文字划线、变次要色；离开这一页再回来，才收进「已完成」
- 下拉刷新；推送来了自动更新

### 4.3 待办详情（底部弹层）

- 顶上：标题（点了就能改，键盘弹起）
- **原话块**：「10月26日 21:30 你说：明天上午十点提醒我给客户回电话」（宋体），点了到笔记库
- **期限**：系统日期选择（紧凑样式，点开是月历）；「没说」时写「没定」
- **提醒**：开关 + 时间（系统时间滚轮）；常用的几个一点就选：「到期那天 9:00」「提前 1 小时」「今晚 8 点」
- **重复**（新）：不重复 / 每天 / 工作日 / 每周（选星期几）/ 每月（选几号）/ 每年
- 和谁、东西、地方：胶囊，点了能改
- 底部：大按钮「完成」；「删除」在最下面（红字，带撤销）
- 来自健康、日历的：只读，写「在日历里改」

### 4.4 提醒（必须可靠——列为红线）

- **手机把所有定了时间、没完成的待办都排上**：不再只排看到过的那几天。服务器给一张全部的单子（4.7）；手机排最近的 60 条（系统最多 64 条），每次打开、收到推送、后台刷新都同步
- **通知的样子**：标题是待办，正文「你 10月26日说的」；**按钮：完成、10 分钟后、1 小时后、明天早上**——在通知上点了不用打开 App（后台发到服务器，没网就排队）
- **时间敏感**：你定了时间的提醒用「时间敏感」级别（专注模式下也能出现；用户可以在系统设置里关）
- **重复的待办**：完成一次，下一次自动出现（期限、提醒按规则往后排）；「不做了」可以选「只删这一次 / 以后都不要了」
- **以后有了系统推送**（要加入苹果开发者计划）：服务器在提醒时间检查，手机那边没确认排上的推送兜底
- 演示数据时不排（照旧）

### 4.5 加待办

- **说一句**（照旧）：「明天下午三点提醒我取快递」→ AI 整理
- **待办页的「+」/「我的」的「加待办」**：弹层里一个输入框（键盘马上出来），提示「比如：明天下午三点取快递」；**打字时下面就显示认出来的时间**「明天 15:00 · 到时候提醒你」（程序认，不走 AI，100 毫秒内）；可以点那一行改；回车或「加上」就加
  - 打的这行字照样存成一段**原话**（原话是唯一的源头），整理照旧在后台做（补上和谁、东西、地方）；时间以程序认出的为准、你改过的以你为准
  - 认不出时间：照样加，算今天、不提醒
- 输入框旁边一个麦克风：说话也能加

### 4.6 画布、小组件、回顾里的待办

- 画布的待办卡和这里同一套行、同一套操作（勾、长按菜单）；卡片标题「待办 ›」进待办页
- 小组件上勾（已有）；锁屏「下一件」（已有）
- 回顾「还没收尾的」：每一行有「带到今天」（已有），也能左滑

### 4.7 服务器要做的

- `GET /api/todos?view=open|today|upcoming|done&from=&to=`：分好组的单子（以前没做完的、今天、明天、这周、以后、已完成），每条带原话来源；`?reminders=1` 给全部未完成、带提醒的（手机排通知用）
- `POST /api/todos`：快加——`{ text }`，**程序认时间**（「明天下午三点」「下周一」「10月30日9点」「半小时后」「今晚」……写成纯函数 + 单元测试，至少 60 个说法），存原话、建待办、回认出的结果；后台照旧整理补全
- `POST /api/todos/parse`：只认时间不建（给打字时的预览用）
- 待办加字段：`repeat`（重复规则）、`doneAt`（完成的时刻）、`snoozedFrom`（推迟以前的时间，回顾里能说「推迟了 2 次」）；完成重复的待办时生成下一次
- 推迟：`PATCH /api/entries/:id { remind_at }` 已有，加一个 `POST /api/todos/:id/snooze { preset }`（程序算时间，手机和服务器同一套）
- 问答（「明天要做什么」）、早上的回顾、小组件都用同一个查法（现在 `todosBetween`、`openTodosBefore` 已有，收成一处）
- 评测：快加的认时间是程序做的，用单元测试；整理时认出重复（「每周一提醒我交周报」）加评测用例

### 4.8 验收标准

1. 说「10 月 30 日上午 9 点提醒我交报告」，**之后不翻到 10 月 30 日**，到点响（模拟器：查 `pendingNotificationRequests` 里有它；真机：实测记录）
2. 通知上点「10 分钟后」，10 分钟后再响；点「完成」，打开 App 看到已完成，服务器上也是
3. 待办页「+」打「明天下午三点取快递」，打完以前下面已经显示「明天 15:00」；回车 1 秒内出现在「明天」
4. 勾一件，留在原地划线；切走再回来进「已完成」
5. 「每周一提醒我交周报」：完成这周的，下周一的自动出现
6. 没网时勾 3 件、推迟 1 件，连上以后服务器全对上
7. 附录 A「待办」的每一项都在

- 从：钱主页的「记一笔」、「我的」的快捷、小组件、Siri「记一笔」

## 6. 心情（高频 ③）

> 一句话：心情有了自己的页；**一秒记下现在的心情**，想说为什么再说；先看今天的那几刻，再看规律。业务规则全部沿用 `docs/prd-mood.md`（五档说法、情绪词只写说出来的、那一刻、心情从哪来、只说同时出现）。

### 6.1 什么时候用

1. 心情来了：点一下记下（小组件、我的快捷、心情页）；有空就说两句「因为……」
2. 晚上：回头看今天几种心情、那几刻
3. 隔几天：这周 / 这个月心情怎么样、什么时候好、和谁在一起好

### 6.2 心情页（我的 → 心情；画布心情卡的标题也进这里）

**第一屏**：
- 大标题「心情」
- **现在心情怎么样**：五个圆（很差 · 不太好 · 一般 · 挺好 · 很好），颜色用心情的粉（深浅五档，和现在的刻度一致）；点一个 → 记心情（6.3）
- **今天**：今天的每一刻一行（时间 · 五个小点 · 说法 · 情绪词），下面是那一刻（宋体原话）；点一行 → 那一条心情（弹层，现在的心情详情）

**往下**（卡片，标题右边「›」进心情分析）：
- **这个月**：心情月历，每一格是那天的表情（一眼看出好坏，不只靠深浅）；左右滑换月；点一格 → 下面出现那天的每一刻（06 交互细节 4.3）
- **这周**：七天七个点，一句话（「周三最低」——前后两段都这样才说，沿用）
- **好时刻**：最近的三个好时刻（那一刻的原话）→ 好时刻（全部）
- **发现**：和心情有关的发现卡（「和儿子在一起的日子……」）

**心情分析**（下一层，把现在「关于我 → 心情」的全部搬来，按卡片排好）：一天里什么时候、好时刻多在做什么、醒着的时间花在哪、和谁在一起、你说出过的感受（字越大说得越多）、心情和精力（折线，能拖着看数，日 / 周 / 月 / 年）、变化

### 6.3 记心情（新）

- **弹层**：顶上刚才点的那一档（可以改）；一排**常用的情绪词**胶囊（「开心」「放松」「累」「烦躁」……来自 prd-mood 5.5 的那套说法，按你说得多的排前面），可以多选、可以不选；一个输入框「因为……」（可以不填，旁边麦克风）；「记下」
- 记下：生成一段原话（「心情挺好，放松，因为晚上楼下飘上来烤红薯的香味」），走整理——**情绪词只写说出来的**这条规矩照样成立，因为点的胶囊就是你「说」的
- 只点了一档就记：原话「心情挺好」——整理时不编那一刻、不编情绪词
- 很难受（很差 + 「想死」这类原话）：沿用 prd-mood 5.6 的做法

### 6.4 晚上问一句（选开，默认关）

- 设置 → 提醒 → 「晚上问问心情」，打开以后每天你定的时间（默认 21:30）一条通知「今天心情怎么样？」，**按住通知直接选一档**，点了就记（原话「心情一般」），不用打开 App。系统在通知上能放几个按钮要在真机上试：放得下五个就五档；放不下就「挺好 · 一般 · 不太好 · 说两句…」（最后一个是系统的回复框，打字或说话）
- 和现在「晚上的倾倒提醒」合并：今天没说过话时问「今天过得怎么样」，说过话、没说心情时问心情，都说过了不问

### 6.5 服务器要做的

- `GET /api/mood/page`：心情页一次拿全（今天的几刻、这个月的格子、这周、最近好时刻、和心情有关的发现）；分析那一层用现有的接口（`/api/about/mood`、`/api/board/mood-sources`）
- `GET /api/mood/words`：常用情绪词，按这个人说得多的排
- 记心情的原话格式加评测用例（「心情挺好」「心情不太好，烦躁，因为方案又改了」）：不编那一刻、不编情绪词
- 晚上问心情：和倾倒提醒合成一种提醒（`reminders`）

### 6.6 验收标准

1. 小组件上点「挺好」，打开 App 今天的心情里有一刻「挺好」（1 秒内）
2. 记心情选「不太好」「烦躁」、说「方案又改了」：整理出的心情是 2 级、情绪词只有烦躁、那一刻是「方案又改了」
3. 只点一档：没有那一刻、没有情绪词
4. 心情页第一屏不用翻就看到今天的每一刻
5. 附录 A「心情」的每一项都在（含心情从哪来、好时刻、精力）

## 附录 A：现在能做的每一件事（2026-10-27，「能力只增不减」的对照表）

> 每一块重做完，在验收申请里逐条写「还在：在哪 / 合并到了哪 / 有意去掉了（产品主人同意过）」。来源：服务器 `SPEC.md` 第七到十三章、`docs/prd-*.md`、App 的代码。

**待办和提醒**
- 说一句建待办，认出期限、提醒时间、和谁、东西、地方；没期限的算说的那天
- 画布待办卡：勾选完成（完成后留在原地）、到点前显示提醒时间、日历的日程穿插（只读，演示时是演示的日程）
- 详情里改内容、期限、提醒、和谁东西地方、完成状态
- 手机本地通知（演示数据时不排）；Bark / Server酱推送；免打扰时段
- 问「今天 / 明天 / 这周的待办」「还有什么没做」，程序查单子、AI 照说
- 每日回顾「还没收尾的」：带到今天；早上的回顾里「今天」那一段
- 小组件：今天、下一件（能勾）；锁屏

**钱**
- 只算说过的钱；花费、收入、能报销、借出去、固定的、回来的钱（退款、AA）、收到的人情（不算收入）
- 主页：日常花的大数、今天、笔数、和上个月同一段比的一句话、月历圆点（面积是钱）、点一天看一天的钱、左右换月
- 每一笔：按天分组、搜索（名目、人、领域、原话）、按种类筛选、标签（收入、等报销、借出、固定、人情、回来的钱）
- 固定的：认出每月扣的（第一次说「每月」就认）、已扣多少、还要扣多少、月尺、不再算固定的
- 收入、人情往来（送出、收到、和一个人的来往、事由、请客）
- 留意：等报销（都报销了）、借出去（已经还了）、7 天内要扣的、在扣钱却很久没说到用它的；留意的那一页：课时、常买的（多久一次、下次大约哪天、比之前贵了多少）、你说过的预算
- 花在哪（方块图，20 笔以后）、花给了谁（3 个月、一家人单独一句）、值不值（你说的、用了几次、每次多少钱）、一样东西的那一页
- 钱和你的日子（发现卡、四个反馈、点开看哪几天）
- 遮住金额；问答问钱、问欠的钱、问课时、问人情；收据里写去向和给谁

**心情**
- 五档说法和刻度、情绪词（只写说出来的）、精力（说到才有）、那一刻（原话一字不差）、AI 推测的标注、你改的标注
- 一天几条心情按时间排、「有起有落」
- 详情里改级别、精力、那一刻、情绪词；「依据」
- 关于我 → 心情：心情像素、一周七天、一天里什么时候、好时刻多在做什么、你说出过的感受、心情和精力曲线（日周月年）、心情从哪来（30 天 / 90 天 / 今年：什么时候、醒着的时间、和谁、常见的心情）、发现、变化
- 笔记库的好时刻；回顾里的心情、连着几天心情不好如实说一句；问答问心情从哪来
- 很难受的时候的做法

**感悟**
- 说一句记下感悟（原话片段、标题、标签）；「记一句」记成语录
- 画布感悟卡（原话、标签、以前也说过类似的几条——收起）
- 笔记库 → 感悟：按标签浏览、按月分组、看原话
- 回顾里的「你说过」、小组件「我的语录」；周报月报里感悟的主题；关于我里「说的和做的」用到感悟

**回顾**
- 每日回顾（一句话、关键数字和平时比、一天的样子、做了什么、目标推进、心情和感悟、一个观察、还没收尾的、今天、你说过、来源；空的部分不出现；数字现算；事实变了重写标「已更新」）
- 周报、月报（同一套，四个数和上期比、一周 / 一个月的样子、做了什么、钱、目标、心情和感悟、观察、这周 / 这个月、顺手整理、来源）
- 预警（「有件事需要留意」）；看过的变次要色、不打红点
- 夜里自动检查查出的（确实错了 / 没错，能撤销）
- 早上画布上「昨天的回顾好了 →」；推送

**目标**
- 说一句建目标（累计、平均、次数、连续天数、不超过、完成型、模糊目标拆子目标）；手动表单
- 年 → 月 → 周拆分、改某个月（锁定、恢复自动）；应达 vs 实际、状态五种颜色、预测完成日期
- 目标详情：曲线、连续的格子、贡献的记录、改名称目标值类别开始日、标记完成；绑定失效时改绑
- 画布上今天推进的目标、卡片底部的进度；问答问进度

**关于我**
- 主页：生活由什么组成（方块图）、时间去向（7/30/90 天）、这周的新发现（四个反馈）、换个角度看你（心情、人、钱、你说的话）、好日子的配方、你没注意到的变化、说的和做的（能藏）、Pour 认识的（关系、说法：能加能改能删）、还在攒的
- 生活领域页、人（星图、一人一行、这个人）、你说的话（时钟、在说什么、小词、连锁反应、主题的起落）、你的一年
- 「不用列出」、「对 / 不对」；地址 `find=`、`item=` 直接打开

**笔记库**
- 全部原话按时间倒序、按日期 / 类别 / 人筛选、关键词 + 按意思搜索（「意思相近」标）
- 每段原话下的整理结果和状态；改原话、删除（能撤销、恢复后重新整理）、失败重试
- 感悟、好时刻两个视图；地址 `?note=`、`?tag=`、`?view=`

**搜索、问答、对话**
- 全局搜索（原话、感悟、目标、输日期跳那天）
- 问问题：来源编号、五种图表、逐字显示、只说同时出现、找不到就说找不到
- 对话：按天分隔、收据（撤销）、追问和回答、斜杠命令（问、记、目标、改、找）、补记（看以前的日子时说的记到那天）、语音识别

**设置**
- 大模型（模型选择、密钥状态、测试连接、用量和花费、每月上限）、自动记下的把握程度、处理日志
- AI 准不准（你改过的、追问、记住的说法、认得出的人和事和地方、检查清单、自动检查、最近一次检查、分开看、没答对的句子、再检查一次）
- 提醒和推送（渠道、每日回顾、晚上的提醒、预警、周报月报、免打扰、试一下）
- 类别（整理建议、改名合并图标颜色删除、层级）、日界线、数据（备份、导出、演示数据）、健康、日历、这台手机（服务器地址、设备）

**系统入口**
- 小组件（说一句、今天、下一件、我的语录）、控制中心、锁屏、分享扩展、Siri「用 Pour 记一句」、`pour://` 链接、健康、日历
