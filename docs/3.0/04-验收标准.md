## A. 能力只增不减

- [ ] [08 功能核对](08-功能核对.md) 里这一块的每一行（附录 A 是粗的单子）：还在（在哪）/ 合并到了哪 / 有意去掉了（产品主人同意过，附原话）
- [ ] [09 总表](09-需求和功能点总表.md) 里这一步「3.0 新加的」每一项：做在哪（截图）
- [ ] 服务器 `npm run check` 全过（附输出最后几行）
- [ ] 改了 AI 规则的：全量评测整体 ≥ 99.9%，每个维度不下降（附报告）
- [ ] `npm run demo:check` 全过；演示数据里有这一步的新东西（截图）

## B. 用起来（产品经理 + 资深真实用户）

- [ ] 需求文档这一章「什么时候用」的每个场景，走一遍都顺：步数不比需求文档写的多
- [ ] 每个操作按下就有回应（按压态、触感）；等服务器时看得见在做什么
- [ ] 能撤销的没有弹确认框；不可逆的才确认
- [ ] 每个滑动操作，长按菜单或详情里也能做
- [ ] **用手指在真机上试**（不只用模拟器点）：长按出菜单，松手不误点菜单里的项；左滑和上下滚不打架；长按不选中字（2026-10-31 在原型上试出来过）
- [ ] 完成的待办留在原地（这一步碰到待办的话）
- [ ] 打开一页先出缓存，不出现整页转圈（第 1 步以后）
- [ ] 没网：页面有内容、顶上一条细条；写操作排队，连上后对得上
- [ ] 文案：中文大白话；没有「服务器的回复」「数据丢失」「token」这类词；没有责备的说法

## C. 样子

- [ ] 只用设计系统 3.0：SwiftLint 没有警告；仓库里这一块搜不到 `Web.`、硬编码的颜色字号间距圆角
- [ ] 和原型的方向一致；偏离的有理由
- [ ] 卡片、标题、图表、按钮和别的已完成的页一致（并排截图看）
- [ ] 每个状态都截到了：默认、空、加载（骨架）、出错、没网、数据少、遮住金额（钱）、最大字号（xxxLarge）
- [ ] 最大字号不截字、不重叠
- [ ] 图标只用 SF Symbols；没有 emoji 当图标

## D. 稳

- [ ] App 单元测试、改到的页面的界面测试全过（附命令和结果）；数量只多不少
- [ ] 改到的页面跑了无障碍审计
- [ ] 真机（产品主人的 iPhone 15 或同型号模拟器）：冷启动、打开一页、滚动的数字（第 1 步起每步都量）
- [ ] 推送、链接（`pour://open?path=`）、小组件打开的页面都对
- [ ] 提醒（碰到待办的步骤）：定了时间的都排上了（查 `pendingNotificationRequests`）

## E. 隐私和安全

- [ ] 没有读、打印、提交任何密钥文件
- [ ] 原话没有去新的地方；去了的（反馈、日志、推送）写清了、有必要
- [ ] 日志里没有原话、金额
