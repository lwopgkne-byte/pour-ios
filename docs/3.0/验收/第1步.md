- **打「/」时输入框被挤到键盘后面**：第 1 步在输入框上面加了一排快捷（记到今天 · 问一句……），它和斜杠命令列表共用一个「上面那块有多高」。打「/」时快捷收起、命令出来，快捷收起那一下把命令刚量好的高度清成了 0，对话面板没让位，输入框和下面几条命令都到了键盘后面——真用户打「/」也一样。改成两样各量各的。`TodayUITests.testSlashCommands` 守着
