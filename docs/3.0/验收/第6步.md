## 06 交互细节第 6 节、10.4

- **回顾页**：分段「每天 · 每周 · 每月」（记得上次看的是哪段）；「需要留意」黄底卡片在「每天」最上面，同一件事每天再说一遍只写一行，「知道了」收起；一篇一张卡：日期（「昨天 · 11月1日 周日」）、一句话、几个数的小胶囊（睡眠 8:20 · 专注 2:24 · 心情 有起有落）；没看过的粗体带「新」，看过的变浅、带 ›；重写过的「已更新」（`testReviewList`）
- **故事**：全屏，一页一个底色、最后一页暖白；顶上一排进度条，5.5 秒自动翻；点右边下一页、点左边上一页（`testDailyStory`）；按住暂停；往下拉关掉（`testWeeklyStory`）；右上角 ×
  - 每日七页：日期 + 一句话 → 三四个数和平时比 → 一天的样子（几条时间条 + 没说时间的）→ 心情和那一刻（小表情、几点 · 说法 · 情绪词、宋体那一刻）→ 目标（推进了多少）+ 一个观察 → 还没收尾的（「带到今天」）+ 自动检查（「确实错了 / 没错」）→ 你说过 +「看整页」「看完了」
  - 周报七页：一句话 → 几个数和上周比 → 一周的样子（每行一天，前一晚 9 点到半夜，右边那天的心情）→ 做了什么 + 钱（「看 10 月的钱 ›」）→ 目标 → 心情和感悟（几条、好时刻、感悟里的主题）→ 几个观察、这周还有、试试、顺手整理
  - 月报六页：一句话 → 几个数和上个月比 → 一个月的样子（每格那天的表情）+ 每一周的周报（点了打开那一周的故事）→ 钱和目标 → 心情和感悟 → 这个月还有、顺手整理

- **看整页**：三种都能进；整页一块一张卡，原来长页面里的每一块都在（做了什么全部领域、目标全部、今天、来源几段话、看这一天的画布、这一周的周报、一周 / 一个月的样子、每一周的周报、心情从哪来、几个观察、这周还有、顺手整理）；右上角 ‹ › 和左右滑翻上一篇、下一篇（`testDailyStory`、`testWeeklyStory` 每一屏审计）

## 这一步查出来、改掉的

- **App 里的「宋体」一直是黑体**：iPhone 上的宋体是系统按需下载的，没下载时退回黑体 → 打开 App 时请系统下载（`SerifFont`）；「Pour 截图」模拟器上下好了，故事第一页、整页的「你说过」都是宋体了
- 故事里「点右边下一页」点到了目标那一行，故事被关掉 → 故事里只看不点
- 目标进度条画错（比例当成了百分比）；周报最后一页太长；整页一周的刻度叠在一起
- 「关于我」那几页用了回顾的旧分块和外框，回顾换成卡片以后它们的版面跟着乱了（界面测试的审计查出来）→ 给「关于我」留一份原来的（`LegacySection`、`legacyPage`），第 8 步重做时换
- 审计：故事顶上的进度条（读屏能上下轻扫换页）只有 3 点高、「知道了」点按区域小 → 都撑到 44 点；「下一页 / 上一页」两个读屏动作挂在整页上，每个字都被当成能点的 → 只挂在进度条上；故事里的大数字限定一行（字号调大会被截）→ 放不下就换行
- 审计时故事还在自动翻页，审到的不一定是那一页 → 界面测试里不自动翻，另加一个测试专门验 5.5 秒自动翻
- 别的见 [步骤/第6步.md](../步骤/第6步.md)

## 04 通用验收

- **A 能力只增不减**：08 功能核对「回顾」19 项都在——回顾列表（三段，看过的变浅、不打红点）；每日回顾的一句话和关键数字、一天的样子、做了什么、目标、心情和感悟、一个观察、还没收尾的（带到今天、对 / 改）、今天、你说过、来源 / 看这一天的画布 / 这一周的周报（故事 + 整页）；已更新（卡片上）；周报的四个数、一周的样子、做了什么和钱、目标、心情和感悟、几个观察、这周、试试、顺手整理、只有几天有记录；月报的一个月的样子、每一周的周报、收入和最大的一笔（钱那几行）、心情从哪来；预警（需要留意）；自动检查（确实错了 / 没错 / 撤销）；早上画布上「昨天的回顾好了」（点了是故事）。09 总表回-1 到回-4 都做了
- **B 用起来**：一篇第一眼是一句话；故事点哪都是翻页、按住暂停、往下拉关掉；带到今天、确实错了都能撤销，没有确认框；打开先出存下的
- **C 样子**：组件进了设计系统（`ReviewListCard`、`AttentionCard`、`StoryProgress`、`StoryNumbers`、`DayBars`，带预览）；整页和待办、钱、心情同一种卡片
- **D 稳**：上面的测试和审计；`/review/2026-10-18`、`/review/week/…`、`/review/month/…` 照旧打开整页；读屏开着时故事不自动翻
- **E 隐私**：没读、没打印任何密钥文件；宋体是系统的字体，下载由系统做，不经过我们
