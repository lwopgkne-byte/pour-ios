## 08 功能核对「这次补上」的 107 行逐行对过

这 107 行是旧 App 就有、第三版原型才补进去的，3.0 一样不能少。逐行按关键字对代码（加载更早的、回到最新、复制、发送说明、排队、移动平均、目标线、比前一年、完整报告、改意思和删掉说法、断开、以前也说过、能藏能恢复、添加关系、常去的地方、主题的起落点开原话、前一年后一年……）：除了上面第 2、8 条都在。感悟的「改标题」3.0 改成了「大宋体直接改字」（06 这样定的，标题在 3.0 里不显示），不算少了。
