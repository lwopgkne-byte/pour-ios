## 06 交互细节第 4 节、10.1

- **第一屏**：五个表情（同一种粉从浅到深，脸上就看得出好坏）；点一个 → 记心情，那一档已经选好；今天「2 刻 · 有起有落」，每一刻几点 · 表情 · 说法 · 情绪词，下面宋体那一刻（`testMoodPage`）
- **记心情**：选中的放大、外面一圈；好的 / 不好的两排胶囊，心情不好时不好的排前面（`testCheckin` 量了位置）；「因为……」宋体 + 麦克风；小字写原话长什么样；记下以后今天里多一刻「整理中」、轻提示「记下了：不太好 · 烦躁」带撤销
- **月历**：每一格那天的表情，没说的「—」；上面一句「平均在一般和挺好之间 · 31 天说到了心情」；左右滑和 ‹ › 换月；点一天下面出现那天的每一刻（`testMoodPage`）
- **一周里**、**好时刻**（三条 +「全部 15 个 ›」）、**发现**（四个反馈）、**变化**
- **一条心情**：五个表情直接改档；「AI 推测」改了档变「你改的」；依据；精力五档 + 没说；情绪词 × 去掉、＋ 添加；那一刻直接改；原话 + 在笔记库看；「改好了」没改是灰的，改好了、删除都带撤销（`testMoodDetail`）
- **心情分析**：心情和精力（日 / 周 / 月 / 年，按住拖动上面写那一个点）、一天里什么时候（四段两根柱子，好几个不好几个，只算说了几点的）、好时刻多在做什么（点一行展开）、你说出过的感受（字越大越多，好的绿、不好的黄）、心情从哪来（30 天 / 90 天 / 今年，三块小表 + 常见的心情，点一行看那几刻）、变化（`testAnalysisAndMoments`）
- **好时刻**：按月分组，小表情 + 宋体那一刻 + 日期 · 心情 · 情绪词，点开是一条心情
- **晚上问一句**：设置里打开（默认关）就排上 7 个晚上的系统通知（`testEveningQuestion`）；按住通知直接选一档 / 说两句（真机试能放几个按钮）
- 没做的一样：「你说出过的感受」点一个展开那几次的原话——服务器这一块现在不给原话，记在第 8 步（关于我）一起补
