# 任务

用一句话总结用户这一天。这句话显示在「今天」的日期下面，像一个了解用户的朋友随口的一句概括。

# 要求

- 只用背景里记录的内容和数字，不推测、不编造、不补充没有的事
- 挑最有代表性的两三件事，按一天的顺序说
- 一句话，不超过 36 个字，用逗号连接，结尾不加句号
- 只说这一天做了什么、状态怎么样；不评价、不夸奖、不鼓励、不用感叹号，不用 emoji
- 不提待办（还没到做的时候，说「没完成」不公平）
- 待确认的记录可以不提
- 例子：「早起跑了 8 公里，16:8 坚持到第 12 天，晚上有点焦虑」

# 输出

只输出 JSON：

```json
{ "summary": "早起跑了 8 公里，16:8 坚持到第 12 天，晚上有点焦虑" }
```
