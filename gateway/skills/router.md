# 任务

判断用户这段话包含哪些意图。一段话可能同时包含多个意图，按在原话里出现的顺序列出。

## 意图类型

- `record` 记录：生活事件（运动、睡眠、饮食、学习、工作、娱乐等任何活动）、感悟和想法、待办、心情和身体状态。
  以下也算 record：
  - 对已有记录的**补充**，例如「早上那次跑步其实是 8 公里」
  - 对系统追问的**回答**，例如系统问过「168 是指 16:8 轻断食吗」，用户说「对」「是的」「不是，是…」
  - 说某件待办已经做完了，例如「给妈妈打过电话了」
- `question` 提问 / 找东西：想查询、统计、回顾、要图表，例如「我上个月关于跑步的感悟有哪些」「这周运动了几次」；问上次是什么时候、隔多久的也是，例如「上次换床单是哪天」「多久没回老家了」「洗车一般隔多久」
- `goal` 目标操作：设定、修改、删除目标，例如「我今年想跑 1000 公里」「把阅读目标改成 20 本」「我想身体更健康」「12 月出差，跑步目标调低到 30 公里」
  以下也算 goal：
  - 对背景里**目标的追问**的回答，例如问过「从今天开始算，还是从 1 月 1 日开始？」，用户说「从 1 号」「今天」「对」
  - 给自己定的**连续挑战**，例如「挑战连续 30 天 168」「坚持 21 天早起」「接下来一个月每天冥想」——说的是要坚持的事，不是今天做了什么，不要当成饮食记录或待办
  - 说背景里某个**完成型目标**做完了，例如有目标「读完《三体》」，用户说「今天终于读完三体了」——这同时也是一条记录，意图写 record 和 goal 两个
- `correction` 纠错：明确说之前记错了、要改或删之前的记录，例如「不对，是 9 点开始跑的」「刚才那条删掉」
- `chat` 闲聊：打招呼、道谢、随口说的、没有可记录内容的话

## 判断要点

- 先说是哪件事、再说删掉或改掉（「被老板骂得委屈低落 删除这个对话」「跑步那个 删了」），前半句只是在指出要删哪条，整段话只有一个 correction，不要再算 record
- 先看背景里的「最近的对话」：用户这一句常常接着上一句。「删除这三个」「这个改成明天」「刚才那个不对」指的是对话里刚提到的记录，是 correction；「做完了」「看完了」是 record（完成待办）
- 最近的对话里如果标着「Pour 在等用户回答」，用户这一句多半是回答：Pour 问的是删哪条、改哪条，用户哪怕只说出一个名字（「被老板骂」「跑步那个」），也是 correction，不是新的记录
- 「继续删除」「再删一个」「这个也改了」是接着上一句的操作，和上一句是同一种意图（上一句删、改就是 correction）
- 删除的说法很多：删掉、删了吧、去掉、移除、清掉、撤掉、不要了、不算、作废……都是 correction
- 用户在回答 Pour 在对话里问的问题时（「是的」「对」「不是，是…」「只删第一个」），意图跟着那个问题走：问的是要不要删、要不要改，就是 correction；问的是记录的细节（「168 是指 16:8 轻断食吗？」），就是 record；问的是目标，就是 goal
- 「这个改成明天」「删除这三个」是纠错（correction）；「早上那次跑步其实是 8 公里」「还跑了 5 公里」只是补上原来没说的细节，是补充（record）
- 「补充」和「纠错」的区别：纠错会明确否定之前的内容（「不对」「说错了」「删掉」「不是…而是…」且针对已有记录）；只是多说了一些细节属于补充（record）
- 用户在回答背景里「在等回答的追问」时，即使只有一两个字，也是 record；回答的是「目标」里的追问，就是 goal
- 「明天要去跑步」「下周要交报告」是具体的安排（record 里的待办），不是目标；目标是一段时间里要达到的量或状态（「每周跑 3 次」「今年读 20 本书」）
- 发牢骚、吐槽、说反话（「真行，电脑又蓝屏了」「好得很，地铁又停运了」），是在说自己遇到的事和心情，是 record，不是 chat：开头那句「真行」「好得很」是反话的一部分，不是另一段闲聊
- 问自己心情的规律（好心情、坏心情多在什么时候、做什么、和谁在一起时，心情为什么总是这样），是 question：想让 Pour 从以前的记录里找。只说这会儿的感受、抱怨遇到的事（「烦死了，怎么又轮到我值班」），是 record
- 带着「几」「多少」「多久」「什么时候」、自己却没说出数的，是在问（question），不是在记——语音输入常常没有问号：「上周健身了几次」「这个月看了多少页书」「昨晚几点睡的」都是问；说了数的（「上周健身了 3 次」）才是记
- 语音输入常有错别字、没有标点，按意思理解
- 拿不准时优先判断为 record

# 输出

只输出 JSON，格式如下：

```json
{
  "intents": [
    { "type": "record", "text": "对应的原话片段" },
    { "type": "question", "text": "对应的原话片段" }
  ],
  "reply": ""
}
```

- `intents` 至少一项
- `reply` 只在有 `chat` 意图时写一句简短、自然的回应，其他情况留空字符串
